- One inbox under a portable Org directory, two capture templates, an agenda, and searches by tag; Org looks clean and behaves predictably.
- =SPC m= in an Org buffer lists the structure commands; =SPC o a= opens the agenda from anywhere.
- Leans on [[id:afa6b7fd-742a-4c15-86a6-32e3e8027b0e][the platform chapter]] for the Org directory and [[id:e5942eb0-4389-447d-9317-d9178adcaaae][the leader]] for =SPC m=.
- Declares no package and needs none of the optional chapters:
  + queries, grouped lists and the document look are [[id:c41f7a2e-6d38-4f15-9b07-2e8d3a6c1f94][Org extras]];
  + linked notes are [[id:f48e8f01-88da-4e33-8398-c00ab346b8bb][the Org-roam chapter]]'s;
  + PDFs and their notes are [[id:78b654e1-a93e-4e31-b0d8-f266215b5b12][the reading chapter]]'s.
- The directory and capture templates are a minimal personal policy; the defaults are distilled from Lambda-Emacs by Colin McLear (=lem-setup-org-base=, =lem-setup-org-settings=), without his personal files and export workflows.

* Org loads on first use :decision:
:PROPERTIES:
:ID: 6a1d4e90-2f7b-4c63-8e15-b93c07d2a4f8
:END:

- Org takes longer to load than most of the rest of the configuration, and a session that opens no Org file has no use for it.
- So startup sets Org's options and never loads Org: =(featurep 'org)= is nil until the first Org file, capture, agenda or query.
  + [[file:../tests/verify-config.el][The startup verifier]] checks that first, before anything of its own can load Org.
- Everything here that Org must see waits for it without loading it:
  + =setopt= on an option whose library is not loaded yet only sets the value, and Org's =defcustom= then keeps it;
  + =add-hook= works on a hook whose library is not loaded;
  + what needs Org itself sits in =with-eval-after-load=.
- Startup sets these values, rather than a =with-eval-after-load=, because of the order that decides who wins.
  + Customize's file and a =private.el= function on =after-init-hook= run after this chapter ([[id:6c9aefe0-32af-453b-a075-6ed429993d3a][machine-specific settings]]).
  + A form that waited for Org would run after them, and undo them.
- Two costs follow.
  + =setopt= can check a value's type only once the option's definition has loaded, so a wrong value warns at the first Org file and not at startup; the verifier loads Org and checks each option this chapter sets.
  + =setopt= loads a library when Customize's own index lists it for that name, so =org-agenda-time-grid= and =org-agenda-custom-commands= use =setq=.

* Where notes live

- =kittymacs-org-directory= comes from [[id:afa6b7fd-742a-4c15-86a6-32e3e8027b0e][the platform chapter]], so a machine can override it in =private.el=.

* How Org looks and behaves

- Markup is hidden and headings are indented, so a document reads like a document.
  + Indenting also hides every star of a heading but the last.
- Editing inside folded text is refused rather than silently mangling it.
- New headings go after the current subtree's content.
- =RET= follows links; =C-a= and =C-e= respect heading stars.
- Source blocks keep their indentation exactly as written; their language's colours and =TAB= are already the default.
- Files open unfolded.
  + Org 9.7 spells that =nofold= and no longer accepts =nil=; the verifier checks the type, so the symbol matters.
- =org-habit= and =org-tempo= are loaded with Org.
- =<= is not auto-paired in Org: it starts structure templates such as =<s=.

* Table cells that wrap
:PROPERTIES:
:ID: 0c6f3e0e-5b1a-4d8e-9f39-6a2c1e7d4b52
:END:

- Org has no setting for wrapping text inside a table cell.
  + =org-table-wrap-region= (=M-RET= in a table) wraps one region once, by hand.
  + A width cookie such as =<20>= with =org-table-shrink= cuts the text off on screen instead of wrapping it.
- So kittymacs wraps cells itself, as a command and on every save: a long cell flows onto continuation rows below it, at most as wide as its column's cookie.
- A table opts in with a row of width cookies, such as =| <12> | <30> |=.
  + The widths have to come from somewhere, and a table without cookies is never touched, so a plain table can't be rewritten by surprise.
  + A cookie may also give the alignment, as in =<r12>=; a column without one never wraps.
- Horizontal rules (hlines) mark where one entry ends and the next starts; the rows between two rules are one entry.
  + Each run joins an entry's rows column by column, then fills them again, so editing any line of a cell and saving re-flows it, and a second run changes nothing.
  + A table with no rule at all is left alone: its rows would merge into one entry.
- =~code~=, ==verbatim== and links are never split across rows; a word wider than its column stays whole on its own row.
- A table followed by =#+TBLFM:= is skipped, because adding or removing rows would shift the rows its formulas name.
- The rewrite happens only when the wrapped table differs from what is there, so saving an already-wrapped file neither moves point nor touches undo.
  + When it does rewrite, point stays in the same cell: the same entry, row of that entry, column and place in the field.
- =kittymacs-org-table-wrap-on-save= is on; a file can switch it off with =# -*- kittymacs-org-table-wrap-on-save: nil -*-= on its first line.
- =SPC m W= wraps the table at point now.

#+begin_src emacs-lisp
(declare-function org-at-table-p "org")
(declare-function org-table-align "org-table")
(declare-function org-table-begin "org-table")
(declare-function org-table-end "org-table")
(declare-function org-at-table-hline-p "org")
(declare-function org-table-current-column "org-table")
(declare-function org-table-goto-column "org-table")
(declare-function org-table-to-lisp "org-table")
(declare-function orgtbl-to-orgtbl "org-table")
(defvar org-table-line-regexp)

(defcustom kittymacs-org-table-wrap-on-save t
  "Non-nil means wrap the cells of opted-in Org tables before saving.
A table opts in with a row of width cookies; see `kittymacs-org-table-wrap'."
  :type 'boolean
  :safe #'booleanp
  :group 'org-table)

(defconst kittymacs--org-table-cookie-regexp "\\`<\\([lrc]?\\)\\([0-9]*\\)>\\'"
  "A width or alignment cookie: <12>, <r>, <l20>.")

(defun kittymacs--org-table-cookie-row-p (row)
  "Non-nil if ROW holds width or alignment cookies and nothing else."
  (and (listp row)
       (seq-some (lambda (cell) (string-match-p "\\`<[lrc]?[0-9]+>\\'\\|\\`<[lrc]>\\'" cell))
                 row)
       (seq-every-p (lambda (cell) (or (string-empty-p cell)
                                       (string-match-p kittymacs--org-table-cookie-regexp cell)))
                    row)))

(defun kittymacs--org-table-words (text)
  "Split TEXT at spaces into the words that may not be broken across rows.
A link, or a ~code~ or =verbatim= span starting a word, is one word even
when it contains spaces.  Every other character belongs to some word, so
joining the words with single spaces gives TEXT back with its runs of
whitespace collapsed."
  (let ((pos 0)
        (link "\\[\\[[^]]*\\]\\(?:\\[[^]]*\\]\\)?\\]")
        words)
    (while (string-match
            (concat "[-({'\"]*\\(?:" link "\\|~[^~]*~\\|=[^=]*=\\|[^ \t]\\)"
                    "\\(?:" link "\\|[^ \t]\\)*")
            text pos)
      (push (match-string 0 text) words)
      (setq pos (match-end 0)))
    (nreverse words)))

(defun kittymacs--org-table-fill (text width)
  "Break TEXT into lines at most WIDTH wide; a longer word gets a line alone."
  (let (lines line)
    (dolist (word (kittymacs--org-table-words text))
      (if (and line (> (+ (string-width line) 1 (string-width word)) width))
          (progn (push line lines) (setq line word))
        (setq line (if line (concat line " " word) word))))
    (when line (push line lines))
    (or (nreverse lines) (list ""))))

(defun kittymacs--org-table-wrap-entry (rows widths)
  "Join ROWS, one entry's lines, column by column and fill them to WIDTHS.
A cookie row among them is kept, unwrapped, ahead of the filled rows."
  (let* ((cookies (seq-filter #'kittymacs--org-table-cookie-row-p rows))
         (rows (seq-remove #'kittymacs--org-table-cookie-row-p rows)))
    (append
     cookies
     (when rows
       (let* ((cells (apply #'seq-mapn
                            (lambda (&rest column)
                              (string-join (seq-remove #'string-empty-p column) " "))
                            rows))
              (columns (seq-mapn #'kittymacs--org-table-fill cells widths))
              (height (apply #'max (mapcar #'length columns))))
         (mapcar (lambda (i) (mapcar (lambda (lines) (or (nth i lines) "")) columns))
                 (number-sequence 0 (1- height))))))))

(defun kittymacs--org-table-wrapped (rows)
  "The table ROWS, from `org-table-to-lisp', with its cells wrapped.
Nil when the table has not opted in, has no hline, or is already wrapped."
  (let* ((width (apply #'max (mapcar (lambda (row) (if (listp row) (length row) 0)) rows)))
         (rows (mapcar (lambda (row)
                         (if (listp row)
                             (append row (make-list (- width (length row)) ""))
                           row))
                       rows))
         (cookies (seq-find #'kittymacs--org-table-cookie-row-p rows)))
    (when (and cookies (memq 'hline rows))
      (let ((widths (mapcar (lambda (cell)
                              (if (and (string-match kittymacs--org-table-cookie-regexp cell)
                                       (not (string-empty-p (match-string 2 cell))))
                                  (string-to-number (match-string 2 cell))
                                most-positive-fixnum))
                            cookies))
            (entries (list nil)))
        (dolist (row rows)
          (if (eq row 'hline)
              (push nil entries)
            (push row (car entries))))
        (let ((wrapped
               (cdr (seq-mapcat (lambda (entry)
                                  (cons 'hline
                                        (kittymacs--org-table-wrap-entry (reverse entry) widths)))
                                (nreverse entries)))))
          (unless (equal wrapped rows)
            wrapped))))))

(defun kittymacs--org-table-position ()
  "Where point is in its table: (ENTRY ROW COLUMN OFFSET).
ENTRY counts the hlines above point, ROW the lines since the last one (nil
on an hline), COLUMN is the field and OFFSET how far into it point is."
  (let ((line (line-beginning-position))
        (entry 0)
        (row 0))
    (save-excursion
      (goto-char (org-table-begin))
      (while (< (point) line)
        (if (org-at-table-hline-p)
            (setq entry (1+ entry) row 0)
          (setq row (1+ row)))
        (forward-line 1)))
    (if (org-at-table-hline-p)
        (list entry nil 0 0)
      (let ((column (org-table-current-column)))
        (list entry row column
              (max 0 (- (point) (save-excursion (org-table-goto-column column) (point)))))))))

(defun kittymacs--org-table-goto-position (position)
  "Move to POSITION, from `kittymacs--org-table-position', in the table at point.
Rows an entry no longer has, and offsets past a field's end, are clamped."
  (pcase-let ((`(,entry ,row ,column ,offset) position)
              (end (org-table-end)))
    (goto-char (org-table-begin))
    (while (and (> entry 0) (< (point) end))
      (when (org-at-table-hline-p) (setq entry (1- entry)))
      (forward-line 1))
    (when row
      (while (and (> row 0)
                  (save-excursion (forward-line 1)
                                  (and (< (point) end) (not (org-at-table-hline-p)))))
        (forward-line 1)
        (setq row (1- row)))
      (org-table-goto-column column)
      (forward-char (min offset (- (save-excursion (skip-chars-forward "^|\n") (point))
                                   (point)))))))

(defun kittymacs-org-table-wrap ()
  "Wrap the cells of the table at point to its columns' width cookies.
The table opts in with a row of cookies such as | <12> | <30> |; the rows
between two hlines are one entry, refilled as a whole each time.  A table
without cookies or hlines, or with a #+TBLFM line, is left alone.  Point
stays in the same cell."
  (interactive)
  (unless (org-at-table-p) (user-error "Not in an Org table"))
  (let* ((beg (copy-marker (org-table-begin)))
         (end (org-table-end))
         (wrapped (save-excursion
                    (goto-char end)
                    (unless (looking-at-p "[ \t]*#\\+TBLFM:")
                      (kittymacs--org-table-wrapped (org-table-to-lisp))))))
    (when wrapped
      (let ((position (kittymacs--org-table-position)))
        (delete-region beg end)
        (goto-char beg)
        (insert (orgtbl-to-orgtbl wrapped nil) "\n")
        (goto-char beg)
        (org-table-align)
        (goto-char beg)
        (kittymacs--org-table-goto-position position)))
    (set-marker beg nil)))

(defun kittymacs-org-table-wrap-all ()
  "Run `kittymacs-org-table-wrap' on every table in the buffer.
Point stays where it was, in or out of a table."
  (interactive)
  (let ((origin (point-marker))
        here)
    (save-excursion
      (goto-char (point-min))
      (while (re-search-forward org-table-line-regexp nil t)
        (when (org-at-table-p)
          (let ((inside (and (>= origin (org-table-begin)) (< origin (org-table-end)))))
            (when inside (goto-char origin))
            (kittymacs-org-table-wrap)
            (when inside (setq here (point)))
            (goto-char (org-table-end))))))
    (goto-char (or here origin))
    (set-marker origin nil)))

(defun kittymacs--org-table-wrap-before-save ()
  "Wrap opted-in tables, when `kittymacs-org-table-wrap-on-save' says to."
  (when kittymacs-org-table-wrap-on-save
    (kittymacs-org-table-wrap-all)))

(defun kittymacs--org-table-wrap-setup ()
  "Wrap this Org buffer's opted-in tables whenever it is saved."
  (add-hook 'before-save-hook #'kittymacs--org-table-wrap-before-save nil t))

(add-hook 'org-mode-hook #'kittymacs--org-table-wrap-setup)

* Tasks and the agenda

- A task is =TODO=, then maybe =NEXT= or =WAITING=, then =DONE= or =CANCELED=.
  + =WAITING= and =CANCELED= ask for a note.
- Finishing a task records the time in a drawer.
- A parent cannot be done while its children, or its checkboxes, are not.
- The agenda:
  + starts on today, weeks on Monday;
  + hides done scheduled items;
  + offers a =d= dashboard: today's agenda, tasks due within five days, and the next actions; =n= lists the next actions alone;
  + opens on =SPC o a= as that dashboard, and on =SPC o A= as Org's own menu.
- Log mode is on from the start, listing closed and clocked items.
  + =t= used to mean that, before the option's type asked for the list itself.
- Refiling completes across every agenda file to eight levels deep, and may create a parent after asking.
- A capture refreshes an open agenda.
- =kittymacs-org-agenda-refresh= (=SPC m g= in an agenda buffer) runs the search again, whether Org or Org QL ([[id:c41f7a2e-6d38-4f15-9b07-2e8d3a6c1f94][Org extras]]) made the list.
  + =org-agenda-redo= only rebuilds Org's own agenda views; an Org QL list needs =org-ql-view-refresh=.
  + It asks a variable that only an Org QL list has, so it works the same with Org QL absent.

* Finding headings by tag

- Org has three ways in, and [[id:c41f7a2e-6d38-4f15-9b07-2e8d3a6c1f94][Org extras]] adds queries across files:

| Keys        | Searches           | Gives                                            |
|-------------+--------------------+--------------------------------------------------|
| =C-c / m=   | this buffer        | the outline, folded to the matching headings     |
| =SPC s h=   | this buffer        | a jump list in which each heading shows its tags |
| =SPC o A=, =m= | the agenda files | an agenda list of the matching headings        |

- =SPC s h= and =SPC s a= are Consult's commands for Org headings and agenda entries, bound here because they search Org.

** Where tags come from :concept:
:PROPERTIES:
:ID: a69bc4c2-0743-423c-bcd0-13393bd211b1
:END:

- A heading's own tags end its line: =* Services :decision:=.
- =#+filetags:= at the top of a file tags every heading in it.
- A heading inherits the tags of its file and of the headings above it.
- So a file tag matches every heading of its file; a tag for a kind of heading, such as =decision= or =assignment=, is the precise one to search for.

** Org's match syntax

- =C-c / m=, and =SPC o A= then =m=, read it:
  + =decision+nixos=: both tags;
  + =machine|module=: either tag;
  + =nixos-assignment=: the first tag without the second.
- =C-c C-c= clears the highlighting a match leaves.

* Export and files

- Exports get smart quotes, tolerate broken links and omit the HTML postamble.
- ODT export produces =.docx=; a table exports as CSV by default.
- Office documents and HTML open in their default application; PDFs open in Emacs.
- =SPC m w= wraps the region in a source, quote or example block, or inserts an empty one.
  + Org's own =org-insert-structure-template=, also on =C-c C-,=.

#+begin_src emacs-lisp
(setopt org-export-with-smart-quotes t

* Prose in a proportional font
:PROPERTIES:
:ID: f6d962c5-5db6-42b7-a605-fd922ddca879
:END:

- Org buffers set prose in =variable-pitch=, the prose font from [[id:0286f652-e861-4e61-9ca6-91e225c8939d][the appearance chapter]], and keep code, tables, dates, drawers and keywords in =fixed-pitch=, the editing font.
  + Columns in tables and source blocks still line up.
  + =org-indent= and =org-hide= stay fixed too: the indentation and the hidden heading stars are counted in characters, and must be as wide as the stars they stand for.
- Headings are semi-bold rather than the theme's bold: in a proportional font, bold headings over every short section are heavier than they read in a fixed one.
- It is done with buffer-local face remapping rather than by changing the faces:
  + only Org buffers change; the agenda is not an Org buffer, so its columns hold;
  + a remap is laid over whatever the theme defines, so =SPC t t= keeps it;
  + no remap gives a height, so =C-x C-+= grows prose and code together.
    The =mixed-pitch= package fixes its faces at the editing font's size in points, so scaling would leave code behind, and it changes the cursor, which is Meow's to set.
- =pdf-text-mode= is an Org mode, so a PDF read as text is set in the prose font as well.
- =SPC t P= toggles it in the current buffer; set =kittymacs-org-prose= to nil in =private.el= to keep Org in the editing font.
- A terminal frame has one font, so there the mode changes only the headings' weight.

#+begin_src emacs-lisp
(defcustom kittymacs-org-prose t
  "Whether Org buffers set prose in `variable-pitch'.
See `kittymacs-org-prose-mode'."
  :type 'boolean
  :group 'kittymacs)

(defconst kittymacs-org-fixed-pitch-faces
  '(org-block org-block-begin-line org-block-end-line org-code org-verbatim
    org-table org-formula org-meta-line org-document-info-keyword
    org-drawer org-special-keyword org-property-value org-date org-checkbox
    org-latex-and-related org-indent org-hide org-modern-symbol)
  "Org faces kept in `fixed-pitch' by `kittymacs-org-prose-mode'.")

(defvar-local kittymacs--org-prose-cookies nil
  "Face remappings made by `kittymacs-org-prose-mode' in this buffer.")

(define-minor-mode kittymacs-org-prose-mode
  "Set prose in `variable-pitch', keeping code, tables and metadata fixed.
Headings are semi-bold.  The faces are remapped in this buffer only."
  :lighter nil
  (mapc #'face-remap-remove-relative kittymacs--org-prose-cookies)
  (setq kittymacs--org-prose-cookies nil)
  (variable-pitch-mode (if kittymacs-org-prose-mode 1 -1))
  (when kittymacs-org-prose-mode
    (dolist (face kittymacs-org-fixed-pitch-faces)
      (push (face-remap-add-relative face :inherit 'fixed-pitch)
            kittymacs--org-prose-cookies))
    (dotimes (level 8)
      (push (face-remap-add-relative (intern (format "org-level-%d" (1+ level)))
                                     :weight 'semi-bold)
            kittymacs--org-prose-cookies))))

(defun kittymacs--org-prose-maybe ()
  "Turn on `kittymacs-org-prose-mode' when `kittymacs-org-prose' is set."
  (when kittymacs-org-prose
    (kittymacs-org-prose-mode 1)))

(add-hook 'org-mode-hook #'kittymacs--org-prose-maybe)

(keymap-set kittymacs-toggle-map "P" (cons "prose font" #'kittymacs-org-prose-mode))
