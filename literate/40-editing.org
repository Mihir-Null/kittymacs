- Selection-first modal editing: Meow's Normal-state grammar, its things, and the state each buffer starts in.
  + The key grammar is adapted from Colin McLear's Meow setup (GPL-3.0-or-later).
- Meow is an external package; this chapter configures it and hands =SPC= to [[id:e5942eb0-4389-447d-9317-d9178adcaaae][the leader]].
  + Every key under =SPC= lives in [[id:53ad53ed-155f-47dc-973d-7be18de2893c][the keys chapter]]; each package chapter defines its own =SPC m= menu next to the package.
  + [[file:../lisp/keybindings.org][The cheat sheet]] lists the keys on one page.
- Read [[*How Meow thinks]] first; every other keys chapter assumes it.

* How Meow thinks :concept:
:PROPERTIES:
:ID: 6236e09e-cd28-4033-b157-b2b75a30e706
:END:

- Meow is modal, like Vim, but the order is reversed:
  + Vim: say *what to do*, then *what to do it to* (=d w=, delete a word);
  + Meow: first *select* something, optionally extend it, then *act* on it (=w= marks a word, =d= deletes the selection).
- The selection is visible before you act:
  + you always see what a command will touch;
  + Meow can print hints on screen while you extend with =e= or a digit.
- Meow's *states*, shown in the mode line:

| State  | Keys                                                                                                   |
|--------+--------------------------------------------------------------------------------------------------------|
| Normal | select and act; this is where you live                                                                 |
| Insert | type text; =i=, =a=, =c= and =A=/=I= enter it, =ESC= leaves                                           |
| Motion | read-only application buffers (Dired, Magit, Help) keep their own keys; only =j=/=k= and the leader are added |
| Beacon | Meow's multiple-cursor mode; unchanged here, see =M-x meow-tutor=                                      |

- Run =M-x meow-tutor= (=SPC h t=) once: it teaches the grammar interactively in an hour.

* The grammar

- Meow ships no default Normal-state keys; every configuration defines its own.
  + This one keeps the layout Meow's own documentation and =meow-tutor= describe, so upstream help transfers.
- Shifted keys:
  + =H= =J= =K= =L= move like =h= =j= =k= =l= while *extending* the current selection;
  + =B=, =E= and =W= work on symbols where =b=, =e= and =w= work on words.
- Digits pick one of the numbered expansion hints Meow draws after a movement; =-= is a negative argument.
- Motion state gets only =j= and =k=; application buffers keep the rest of their keys.

| Family | Keys                                                                                        |
|--------+---------------------------------------------------------------------------------------------|
| Move   | =h= =j= =k= =l=, =b= =e= (word), =g= =G= (buffer start, end)                                |
| Select | =w= word, =x= line, =o= =O= block, =f= find, =t= till, =n= search, =v= visit, =,= =.= =[= =]= thing, =;= reverse, =:= go to line |
| Act    | =a= =A= =i= =I= insert, =c= change, =d= =D= delete, =s= kill, =r= replace, =R= overwrite, =m= join, =p= yank, =y= copy, =u= =U= undo, =z= pop selection, =q= quit, ='= repeat, =&= =%= query-replace |
| Grab   | ~=~ grab, =X= swap, =Y= sync: keep a second selection in sync (see =meow-tutor=)            |

#+begin_src emacs-lisp
(defun kittymacs-meow-setup ()
  "Install the QWERTY selection grammar and the Motion-state basics."
  ;; Motion state: application buffers keep their own keys; only j/k move.
  (meow-motion-define-key
   '("j" . meow-next)
   '("k" . meow-prev))
  (meow-normal-define-key
   ;; Numbered expansion hints and counts.
   '("0" . meow-expand-0)
   '("9" . meow-expand-9)
   '("8" . meow-expand-8)
   '("7" . meow-expand-7)
   '("6" . meow-expand-6)
   '("5" . meow-expand-5)
   '("4" . meow-expand-4)
   '("3" . meow-expand-3)
   '("2" . meow-expand-2)
   '("1" . meow-expand-1)
   '("-" . negative-argument)
   ;; Move; the shifted key extends the selection instead.
   '("h" . meow-left)
   '("H" . meow-left-expand)
   '("j" . meow-next)
   '("J" . meow-next-expand)
   '("k" . meow-prev)
   '("K" . meow-prev-expand)
   '("l" . meow-right)
   '("L" . meow-right-expand)
   '("b" . meow-back-word)

   '("e" . meow-next-word)
   '("E" . meow-next-symbol)
   '("g" . beginning-of-buffer)
   '("G" . end-of-buffer)
   ;; Select a thing: word, symbol, line, block, or by character.
   '("w" . meow-mark-word)
   '("W" . meow-mark-symbol)
   '("x" . meow-line)
   '("o" . meow-block)

* Things, starting states and hint colours

- A *thing* is what =,= and =.= select: a word, a pair of brackets, a string.
  + Angle brackets are added to the built-in set on =<=.
- =meow-mode-state-list= decides the state a buffer starts in; each package chapter adds its entries next to the package:
  + Dired and Magit start in Motion;
  + shells and terminals in Insert: their keys belong to the program.
- =:= goes to a line through =consult-goto-line=; Meow uses the system clipboard.
- Once everything is set, Meow is enabled globally and the leader attached.
- The numbered expansion hints keep their colours from the theme (=meow-use-dynamic-face-color=, left at its default of =t=):
  + Meow mixes the cursor colour into the region colour for the hint backgrounds, recomputed each time a theme is enabled;
  + so the hints stand out from plain text and follow =SPC t t=.
- Neither doom-themes nor the Sonokai port styles these faces: switching the option off, as the setup this was adapted from did, leaves the hints indistinguishable from text.

#+begin_src emacs-lisp
(use-package meow
  :ensure t
  :custom
  (meow-use-cursor-position-hack t)
  (meow-use-clipboard t)
  (meow-goto-line-function #'consult-goto-line)
  :config
  (meow-thing-register 'angle '(regexp "<" ">") '(regexp "<" ">"))
  (add-to-list 'meow-char-thing-table '(?< . angle))
  (kittymacs-meow-setup)
  (meow-global-mode 1)
  (kittymacs-leader-enable))

#+end_src

* Things from the syntax tree

- In a Tree-sitter mode (see [[id:560fcdca-6cb8-49d9-bf27-eb78f32b9285][the languages chapter]]) the buffer has a real parse tree; =meow-tree-sitter= turns its nodes into Meow things:
  + =, f= selects inside the current function, =. f= the whole function;
  + =a= is a class, =t= a test, =y= an entry, =,= a parameter, =/= a comment.
- Without a grammar, these keys report that there is no parser.

#+begin_src emacs-lisp
(use-package meow-tree-sitter
  :ensure t
  :after meow
  :config
  (meow-tree-sitter-register-defaults))

#+end_src

* Check

- The mode line names the state: Normal in a file, Motion in Dired or Magit, Insert in a terminal.
- =w= on a word, then =d=: the word is selected, then deleted.
- =x=, then =3=: the line is selected, then grows to the hint numbered 3; the hints are coloured, not plain text.
- =i=, type, =ESC=: Insert state and back to Normal.
- =, <= inside =<...>=: the text between the angle brackets is selected.
- =, f= in a Tree-sitter buffer: the inside of the current function is selected.
- =SPC= in Normal state opens the leader; =C-h k SPC f f= describes the real command.
- =SPC h t=: Meow's tutorial.
- =just test-packages=: the leader tests load Meow; the verifier checks that =meow-global-mode= is on and that =SPC= is the leader in Normal and Motion states.
