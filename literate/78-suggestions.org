#+TITLE: Suggestions: Copilot's ghost text and next edits
#+FILETAGS: :code:
#+STARTUP: overview
#+PROPERTY: header-args:emacs-lisp :tangle ../lisp/kittymacs-suggestions.el :eval never :comments no :padline no :mkdirp yes

- A model that suggests code as you type, in grey after the cursor, and the next edit you will probably make, anywhere in the file; =TAB= takes either.
- Off until you turn it on: =SPC t a= in one buffer, or =kittymacs-suggestions= for every programming buffer ([[*Off until you turn it on]]).
- One package, [[https://github.com/copilot-emacs/copilot.el][copilot.el]], talking to GitHub's own language server; a GitHub Copilot plan (the student plan works) and a login.
- Leans on [[id:a1607a41-b741-428a-9de3-c16e7c8d3ecc][the editing chapter]] for Meow's states, [[id:a210c7c3-84da-4560-9346-156f5d28e253][Corfu]] for the popup it makes room for, and [[id:53ad53ed-155f-47dc-973d-7be18de2893c][the keys chapter]] for =SPC t a= and =SPC a c=.
- The conversation with an agent is [[id:94d55283-5011-4f98-a7f0-8c6bcb51aab9][the agents chapter]]; this one never opens a chat.
- Read [[*Three kinds of help]] first.

* Three kinds of help :concept:
:PROPERTIES:
:ID: f3f00286-b32c-4a85-8352-eb652110ad7a
:END:

- A model can help with code at three distances from the cursor:

| Kind              | Predicts                                    | Answers in    | Here                 |
|-------------------+---------------------------------------------+---------------+----------------------|
| Ghost text        | the rest of what you are typing, at point   | a blink       | =copilot-mode=       |
| Next edit         | the change your last edits imply, anywhere  | half a second | =copilot-nes-mode=   |
| Agent             | a plan, carried out with tools, over files  | minutes       | =SPC a a=, agent-shell |

- Ghost text sees the code around the cursor; it finishes a line or a block.
- A next edit sees what you just changed: rename a parameter, and it proposes the three uses below; add a field, and it proposes the constructor argument.
  + It can replace and delete text, not only insert it, so it is drawn as a change over the text it replaces.
  + This is the step between completion and an agent: it infers what you are doing, not just the next word, and still waits for one key.
- Both come from one process, GitHub's =copilot-language-server=, which copilot.el starts once and shares between buffers.
  + It speaks LSP, like the language servers in [[id:560fcdca-6cb8-49d9-bf27-eb78f32b9285][the languages chapter]], but copilot.el is its own client: Eglot does not ask for inline completions.

* Off until you turn it on :decision:
:PROPERTIES:
:ID: 99006880-bab0-4757-bc07-1ceff2abd921
:END:

- A buffer with suggestions on is sent to GitHub, and so is code from the other buffers that have them on; nothing is sent from a buffer where they are off.
  + So the default is off, and turning it on is a choice you make once, in =private.el=, or per buffer with =SPC t a=.
- =kittymacs-suggestions= decides whether a programming buffer starts with them.
  + Only buffers visiting a file: =*scratch*= and other scratch buffers stay off, and so the server does not start with Emacs.
  + The value is read as each buffer opens, so Customize, which loads last, and =setopt= at any time both work.
- =kittymacs-suggestions-excluded-files= is a list of patterns for files that never get them, even from =SPC t a=: =private.el=, anything encrypted, =~/.ssh=, =.env= files and =authinfo=.
  + It is checked before the mode turns on, not before each request: the mode itself sends the buffer to the server.

#+begin_src emacs-lisp
(defgroup kittymacs-suggestions nil
  "Code suggestions from GitHub Copilot."
  :group 'kittymacs)

(defcustom kittymacs-suggestions nil
  "Whether programming buffers that visit a file start with suggestions.
Suggestions send the buffer to GitHub.  `SPC t a' turns them on or off
in one buffer whatever this says."
  :type 'boolean)

(defcustom kittymacs-suggestions-excluded-files
  '("/private\\.el\\'" "\\.gpg\\'" "\\.age\\'" "/\\.ssh/" "/\\.env\\(\\.[^/]*\\)?\\'" "authinfo")
  "Patterns for file names that never get suggestions.
A buffer whose file name matches one is never sent to GitHub."
  :type '(repeat regexp))

#+end_src

* copilot.el and its server :decision:
:PROPERTIES:
:ID: 4fce3be1-6aba-43c7-ac39-431526c56ce6
:END:

- copilot.el is the most complete client for Copilot in Emacs, and the only one with next edits:
  + it is maintained, and releases often;
  + it uses GitHub's official server, through the standard =textDocument/inlineCompletion= request;
  + the alternatives are gone (Supermaven closed in 2025) or quiet (codeium.el); minuet-ai.el speaks to any model, but its next edits are experimental and Claude needs an API key, not a subscription.
- The Lisp comes from MELPA. The server is a program, =copilot-language-server=, which copilot.el looks for on =PATH=.
  + With Nix, either of this flake's modules installs it when =programs.kittymacs.suggestions.enable= is on ([[id:9e0c1f52-7a43-4d0e-b1a8-63c2f5d48e17][the option]]).
  + It is off there by default and not in the shared tool list: nixpkgs marks it unfree, and a host that turns it on allows that one package.
  + Without Nix, =M-x copilot-install-server= installs it with =npm= into =var/cache/copilot/=; copilot.el looks on =PATH= first and there second.
- copilot.el loads the first time a buffer turns suggestions on, never at startup.
  + The modes, =copilot-complete= and the install commands are autoloaded by the package; =:commands= adds the account commands, which are not.
- Two of its options differ from the defaults:
  + =copilot-install-dir= is under =var/=, with everything else Emacs writes;
  + its indentation warning is off: for a mode it has no table entry for, it uses =tab-width=, and says so in a =*Warnings*= window.
- The server version is left alone: =copilot-lsp-server-version= is nil, so whatever the host's Nix pins is used without a warning. Next edits need 1.434.0 or newer.
- The server starts with Emacs's environment, so a proxy and its certificates reach it as they reach the agent; a TLS-inspecting proxy also needs =NODE_EXTRA_CA_CERTS= in that environment.
- copilot.el also has a chat and an agent mode. They are not bound to any key: the agent is [[id:94d55283-5011-4f98-a7f0-8c6bcb51aab9][Claude Code]], and two chats would be one too many.

#+begin_src emacs-lisp
(use-package copilot
  :ensure t
  :defer t
  :commands (copilot-login copilot-logout copilot-diagnose)
  :custom
  (copilot-install-dir (expand-file-name "copilot/" kittymacs-cache-dir))
  (copilot-indent-offset-warning-disable t)
  (copilot-enable-predicates '(kittymacs-suggestions-typing-p copilot--buffer-changed))
  (copilot-disable-display-predicates '(kittymacs-suggestions-popup-p)))

#+end_src

- The two predicates are [[*Meow decides when you are typing]] and [[*Corfu's popup goes first]].

* Turning suggestions on
:PROPERTIES:
:ID: 87843d58-c4bb-4931-9db3-d1a04d500c7a
:END:

- One function turns on both modes in a buffer, after two checks:
  + the file is not excluded;
  + the server is installed. Without it, a message says how to get it, once per buffer, rather than an error in a hook every time a file opens.
- Next edits ride on =copilot-mode=, which starts the server and keeps it in step with the buffer; on its own =copilot-nes-mode= shows nothing.
- =SPC t a= is =kittymacs-suggestions-toggle=: both modes on or off in this buffer.
- =SPC a c= is =kittymacs-suggestions-complete=: ghost text at point now, turning suggestions on first if they are off.
  + copilot.el's =copilot-complete= works in a buffer without the mode, which would send an excluded file; this goes through the same two checks.

#+begin_src emacs-lisp
(defun kittymacs--suggestions-excluded-p ()
  "Return non-nil if this buffer's file must never be sent to GitHub."
  (and buffer-file-name
       (seq-some (lambda (pattern) (string-match-p pattern buffer-file-name))
                 kittymacs-suggestions-excluded-files)))

(defun kittymacs--suggestions-start ()
  "Turn on ghost text and next edits in this buffer; return non-nil if on."
  (require 'copilot)
  (cond
   ((kittymacs--suggestions-excluded-p)
    (message "Suggestions stay off for %s (kittymacs-suggestions-excluded-files)"
             (file-name-nondirectory buffer-file-name))
    nil)
   ((not (ignore-errors (copilot-server-executable)))
    (message "Suggestions need copilot-language-server on PATH, or M-x copilot-install-server")
    nil)
   (t
    (copilot-mode 1)
    (copilot-nes-mode 1)
    t)))

(defun kittymacs--suggestions-maybe-start ()
  "Turn suggestions on in a programming buffer if `kittymacs-suggestions' is set."
  (when (and kittymacs-suggestions buffer-file-name (not buffer-read-only))
    (kittymacs--suggestions-start)))

(add-hook 'prog-mode-hook #'kittymacs--suggestions-maybe-start)

(defun kittymacs-suggestions-toggle ()
  "Turn Copilot's ghost text and next edits on or off in this buffer."
  (interactive)
  (if (bound-and-true-p copilot-mode)
      (progn
        (copilot-nes-mode -1)
        (copilot-mode -1)
        (message "Suggestions off in this buffer"))
    (when (kittymacs--suggestions-start)
      (message "Suggestions on in this buffer"))))

(defun kittymacs-suggestions-complete ()
  "Ask Copilot for ghost text at point now.
Turns suggestions on in this buffer first if they are off, so an
excluded file is never sent."
  (interactive)
  (when (or (bound-and-true-p copilot-mode)
            (kittymacs--suggestions-start))
    (copilot-complete)))

#+end_src

* Meow decides when you are typing :meow:
:PROPERTIES:
:ID: 7a95b623-226a-4f31-a97b-2fd2cb8d183c
:END:

- Ghost text is asked for only in Insert state.
  + copilot.el's default asks only in Evil's insert state; where Evil is missing that test counts as passed, so in Meow it would ask after every Normal-state command too.
  + In a buffer where Meow is off, it asks as you type.
- Next edits are not limited to Insert: they follow edits, and a Normal-state edit (=d= on a selection, =c=) is an edit too.
- The keys while something is shown:

| Key     | With ghost text shown     | With a next edit shown           |
|---------+---------------------------+----------------------------------|
| =TAB=   | accept it all             | jump to it; again, apply it      |
| =C-TAB= | accept the next word      |                                  |
| =M-n=   | next suggestion           |                                  |
| =M-p=   | previous suggestion       |                                  |
| =C-g=   | clear it, as any key does | dismiss it                       |

- Ghost text's keys live on the text itself (a =keymap= overlay property), so they win over every mode's keys while it is shown and vanish with it.
- Next edits' keys are a minor mode's. Meow's Normal and Insert maps bind neither =TAB= nor =C-g=, so they fall through to it in both states, and to the usual command when nothing is pending.

#+begin_src emacs-lisp
(defun kittymacs-suggestions-typing-p ()
  "Return non-nil while you type: in Meow's Insert state, or where Meow is off.
A member of `copilot-enable-predicates'."
  (or (not (bound-and-true-p meow-mode))
      (bound-and-true-p meow-insert-mode)))

#+end_src

* Corfu's popup goes first :decision:
:PROPERTIES:
:ID: 3d1c8a7e-5b0f-4a2e-9c61-8f2b7e4d9a15
:END:

- [[id:a210c7c3-84da-4560-9346-156f5d28e253][Corfu]] opens its popup on its own as you type a symbol, and binds =TAB= to insert the chosen candidate.
- Ghost text's =TAB= is on an overlay, which outranks Corfu's map, so with both on screen =TAB= would take the ghost text and drop the candidate you were looking at.
- So the two take turns:
  + while the popup is open, ghost text is not drawn (=copilot-disable-display-predicates=);
  + when the popup opens over ghost text already drawn, the ghost text is cleared;
  + the next command after the popup closes asks again.
- In practice Corfu finishes the symbol you are typing, and Copilot proposes what comes after it.

#+begin_src emacs-lisp
(defun kittymacs-suggestions-popup-p ()
  "Return non-nil while a completion popup is open.
A member of `copilot-disable-display-predicates'."
  (bound-and-true-p completion-in-region-mode))

(defun kittymacs--suggestions-yield-to-popup ()
  "Clear Copilot's ghost text when a completion popup opens."
  (when (and completion-in-region-mode (bound-and-true-p copilot-mode))
    (copilot-clear-overlay)))

(add-hook 'completion-in-region-mode-hook #'kittymacs--suggestions-yield-to-popup)

(provide 'kittymacs-suggestions)
;;; kittymacs-suggestions.el ends here
#+end_src

* Check

- Once: =copilot-language-server= on =PATH= (=M-: (executable-find "copilot-language-server")=), then =M-x copilot-login=, and enter the code it copies at the page it opens.
- =SPC t a= in a Python or Lisp file: the echo area says "Suggestions on in this buffer"; =M-x copilot-diagnose= reports the server and your account.
- In Insert state, type the start of a function: grey text follows the cursor; =TAB= takes it, =C-TAB= one word, =M-n= another suggestion.
- =ESC= to Normal and wait: no new grey text appears.
- Type a symbol until Corfu's popup opens: the grey text goes; =TAB= inserts Corfu's candidate.
- Rename a parameter and leave Insert: a next edit appears at one of its uses; =TAB= jumps there, =TAB= again applies it, =C-g= dismisses it.
- =SPC C p=, then =SPC t a= in =private.el=: the echo area says suggestions stay off.
- =SPC a c= in a file with suggestions off: they turn on, and grey text appears at point.
- With =(setopt kittymacs-suggestions t)= in =private.el=, every programming file you open starts with them; =*scratch*= does not.
