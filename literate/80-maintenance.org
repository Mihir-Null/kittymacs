#+TITLE: Maintenance: the loop, the builder, and machine overrides
#+FILETAGS: :core:
#+STARTUP: overview
#+PROPERTY: header-args:emacs-lisp :eval never :comments no :padline no :mkdirp yes

- How to change kittymacs: edit a chapter, tangle, check, restart; the [[file:../justfile][justfile]] is the reference card once this page is read.
- Writes two files, each from its own heading:
  + [[*Machine-specific settings]] → =lisp/private.example.el=, the template for your =private.el=;
  + [[*Building from inside Emacs]] → =lisp/kittymacs-literate.el=, the =SPC C= commands.
- The build uses only the Org that ships with Emacs; startup never tangles, so a fresh clone runs without a build step.

* The loop :concept:
:PROPERTIES:
:ID: 12926a91-6016-43ae-9309-c28a293ce78e
:END:

1. *Edit a chapter.* Prose and code block together; a block without a bullet saying why is unfinished.
2. *Tangle*: =just tangle=, or =SPC C t= inside Emacs.
   + Every =literate/NN-name.org= writes the files its =:tangle= headers name ([[*How a chapter becomes files]]).
3. *Check*: =just check=, before every commit. In turn:
   + =tangle-check= :: tangles into a temporary directory and fails if any committed generated file differs;
   + =doc-test= :: every page follows [[id:7edccfdc-3c38-489a-bc9e-4c002b432ab4][the conventions]]: IDs, tags, links, a closing Check;
   + =test= :: the suites that need no packages: the builder, every operating system's platform branch, the Tree-sitter policy.
4. *Restart Emacs*, then commit the chapter and its generated file together.
- One decision per commit, with its generated files.
- For a quick experiment, evaluate a block with =C-c C-c= or a form with =SPC e e=: it changes the running Emacs without rebuilding anything.

** The recipes

| Recipe            | Needs              | Does                                                                         |
|-------------------+--------------------+------------------------------------------------------------------------------|
| =tangle=          | Emacs              | write every generated file from its chapter                                  |
| =tangle-check=    | Emacs              | fail if a generated file differs from its chapter                            |
| =doc-test=        | Emacs              | check IDs, tags and links on every page                                      |
| =test=            | Emacs              | builder, platform and Tree-sitter tests                                      |
| =check=           | Emacs              | the three above; the default recipe                                          |
| =install=         | Emacs, network     | start the configuration once in batch, installing its packages into =var/elpa= |
| =compile=         | installed packages | byte-compile every module, to catch load errors                               |
| =test-packages=   | installed packages | leader and Org-roam tests, and the startup verifier                          |
| =frames-test=     | a display          | the frame-policy tests, in a graphical Emacs                                 |
| =lint=            | Nix tools          | =deadnix=, =statix= and =nixfmt= over the generated Nix                      |
| =eval=            | Nix                | evaluate the flake and both example hosts; nothing is built                  |
| =nix-check=       | Nix                | =lint= and =eval=                                                            |
| =all=             | Nix, network       | everything CI runs on Linux, in order                                        |
| =update=          | Nix, network       | =update-flake=, =update-packages=, =update-grammars=                         |

- =nix develop= gives a shell with Emacs, =just= and the Nix linters ([[id:d25a5063-1439-4ae0-8fbe-b0162d05a0e0][the Nix chapter]]); outside it, any Emacs 30.1 or later runs the Emacs recipes.
- On Windows, =just= runs recipes with the =sh= Git for Windows installs.
- =test-packages= reads =KITTYMACS_TEST_PACKAGES=, defaulting to this checkout's =var/elpa=.

** Updating

- =just update= runs three recipes; each also works alone:
  + =update-flake= :: =nix flake update=: moves nixpkgs, and so the Emacs and tools the Nix modules install. Commit =flake.lock=.
  + =update-packages= :: a batch Emacs refreshes the archives and upgrades every package in =var/elpa=, without loading the configuration.
  + =update-grammars= :: rebuilds every Tree-sitter grammar at the revision [[id:560fcdca-6cb8-49d9-bf27-eb78f32b9285][the languages chapter]] pins; needs =git= and a C compiler.
- =var/= is not tracked, so only =flake.lock= (and a changed pin) reaches a commit.
- Run =just test-packages= after =update-packages=: the verifier is what notices an upstream change.

* How a chapter becomes files :concept:
:PROPERTIES:
:ID: d57943d1-4bdf-4776-a19c-d6120fbd87a5
:END:

- Org Babel's /tangle/ copies a chapter's source blocks into files; kittymacs uses only that.
- Header arguments, set once per chapter by its =#+PROPERTY: header-args= line:
  + =:tangle ../lisp/kittymacs-NAME.el= :: where the blocks go, relative to the chapter; chapters live in =literate/=, so every target starts with =../=;
  + =:padline no= :: no blank line between blocks; Babel drops a block's trailing blank line, so a block that should follow one says =:padline yes=;
  + =:comments no= :: no links back to the chapter in the output; the file header names its chapter instead;
  + =:eval never= :: =C-c C-c= cannot run a block by accident;
  + =:mkdirp yes= :: create the directory if needed.
- A chapter writing several files sets =:tangle= in each heading's property drawer instead, as this one does; blocks under that heading go to that file.
- A block's own arguments win over the page's: =:tangle no= marks an example to read, not to load.
- Inside a block, a line starting with =*= or =#+= is written =,*= or =,#+=; Babel strips the comma.

** The builder :decision:
:PROPERTIES:
:ID: d702f35a-3b2f-4cb5-9b4c-c176f0711db0
:END:

- [[file:../tools/tangle.el][tools/tangle.el]] runs in =emacs -Q --batch=: no personal startup, no packages, no file-local variables, and no block is ever evaluated.
- It finds the chapters by name: every =literate/NN-name.org=; adding the file is enough, there is no list to register it in.
- Before writing anything it checks every target:
  + Emacs Lisp may go only to =early-init.el=, =init.el= or a file directly in =lisp/=, never =lisp/private.el=, which is yours;
  + Nix may go only to =flake.nix= or =nix/=, at most one directory deep;
  + a block's language must match its target's;
  + no two chapters may write one file;
  + a =lisp/kittymacs-*.el= or =nix/**.nix= that no chapter writes is an error: startup would go on loading a module whose source is gone, and the flake importing a file nothing explains.
- It tangles into a temporary directory, checks that every Lisp file's parentheses balance, and only then copies the files that changed.
  + =--check= copies nothing and fails on any difference: the guard against a hand edit to a generated file, or a forgotten tangle.
- Chapters and outputs are UTF-8 with LF line endings on every platform; =.gitattributes= keeps Git from converting them.
- After renaming or deleting a chapter, delete its old generated file too; the orphan check says which.

** Add a chapter

1. Create =literate/NN-name.org= with the header of a neighbouring chapter: a fresh =:ID:=, a kind tag, and =:tangle ../lisp/kittymacs-name.el=.
   + The two digits are the load order ([[id:40302e33-d2b2-4c0b-9bc3-1f9e121307e1][startup]] has the list).
2. Add =(require 'kittymacs-name)= to =init.el= in the startup chapter, where it belongs in that order.
3. Give a package with its own buffers a =:meow:= heading: its starting state and a =kittymacs-define-localleader= form for =SPC m= ([[id:e5942eb0-4389-447d-9317-d9178adcaaae][the leader]]).
4. Add a row to [[id:52a45bf9-9521-4e0d-9867-1c54721844a3][the reading guide]]'s table; =just doc-test= fails until you do.

* What CI proves
:PROPERTIES:
:ID: b01690a2-51c1-471b-9c70-39cb2c3e1e64
:END:

- [[file:../.github/workflows/ci.yml][The CI workflow]] runs the recipes above on every push and pull request; it never deploys anything.
  + =tangle= job :: =just check=: the chapters match the generated files, and the package-free tests pass.
  + =startup= job :: a fresh clone runs =just install=, =just compile= and =just test-packages= on Emacs 30.1 and 31.1 on Linux, plus informational macOS and Windows runs.
  + =nix= job :: =just nix-check= in =nix develop=, then the home-manager module's clone options read as a device would see them.
- A weekly run repeats the fresh install without the package cache, so upstream breakage shows up even when nothing here changed.
- =just frames-test= is the one suite CI cannot run: it needs a graphical session.
- Dependabot proposes weekly updates to the workflow's actions.

* Why the generated files are committed :decision:
:PROPERTIES:
:ID: 023e8794-b0b7-4bf3-8b37-b5ceb7c6f6c4
:END:

- Startup loads plain Lisp, never Org: a clone starts with no build step, and a broken chapter cannot stop Emacs from starting.
- Nix sees only files Git tracks, so the generated =.nix= must be committed too.
- The cost: every change shows twice in a diff.
  + =.gitattributes= marks the generated files =linguist-generated=, so GitHub folds them and review happens on the chapter.
  + Locally, =git diff -- '*.org'= is the diff you read.

* Machine-specific settings
:PROPERTIES:
:header-args:emacs-lisp: :tangle ../lisp/private.example.el :eval never :comments no :padline no :mkdirp yes
:END:

- =lisp/private.el= holds what belongs to one account or machine: paths, fonts, opt-in language servers, your own keys.
  + =SPC C p= creates it from =lisp/private.example.el=, written below, and opens it.
  + Git ignores it, and no chapter may tangle to it, so rebuilding never replaces it.
- =M-x customize= saves to =var/etc/custom.el=, also ignored; back both up yourself.

** When private.el is read, and why that needs two forms :concept:
:PROPERTIES:
:ID: cf00615b-7150-4504-9adf-199876070b0b
:END:

- =init.el= loads =private.el= early, right after the defaults and platform chapters, because most chapters read a =kittymacs-= option while they load.
  + The languages chapter picks packages to install from =kittymacs-language-packages=; the appearance chapter loads =kittymacs-theme=.
- Early has a price: a later chapter that sets a package's option replaces your value.
  + The terminal chapter sets =ghostel-enable-osc52= to =nil=; a top-level =setopt= of it in =private.el= would be undone a moment later.
- So the example uses two forms:
  + a =kittymacs-= option :: at top level with =setopt=; it works before the option's chapter loads, because the chapter's =defcustom= keeps an existing value;
  + any other package's option :: inside the =after-init-hook= function at the end, which Emacs runs once =init.el= has finished; depth 90 puts it after the chapters' own functions.
- A chapter that sets an option only as its package loads (in =:config= or =with-eval-after-load=) needs your =setopt= wrapped in =with-eval-after-load= inside the hook: forms waiting for a package run in registration order, and by then every chapter has registered its own.
- Tabspaces is the exception: it turns on at depth 95, after your function, so it reads your settings.
- Customize needs neither form: =init.el= loads =custom.el= after every chapter.
- [[file:../ARCHITECTURE.md][ARCHITECTURE.md]] ("Customize and =private.el= get the last word") has the reasoning; the startup verifier replays a real startup and checks that both kinds of override survive.

** The example

- Only comments: uncomment what you need.

#+begin_src emacs-lisp

;; Generated from literate/80-maintenance.org; edit the Org source, then tangle.

;; Copy to private.el for account and machine settings that should not be
;; committed.  init.el loads private.el early, before most chapters, because
;; they read the kittymacs options below while they load.  Set those at top
;; level with `setopt'.  A package option that a chapter also sets must go in
;; the `after-init-hook' function at the end of this file instead: the chapter
;; runs after this file and would replace a top-level value.

;; Identity

;;       user-mail-address "you@example.com")

;; Paths
;; (setopt kittymacs-project-directory (expand-file-name "~/src/"))
;; (setopt kittymacs-org-directory (expand-file-name "~/Documents/my-org/"))

;; Linked notes, read when the Org-roam chapter loads.  The exclusions are

;; (setopt kittymacs-org-roam-directory (expand-file-name "~/notes/"))
;; (setopt kittymacs-org-roam-excluded-directories
;;         '(".git" ".cache" "cache" "caches" "archive"))
;; A project becomes a graph of its own with a .dir-locals.el at its root,
;; not with settings here; see literate/71-org-roam.org:
;;   ((nil . ((kittymacs-org-roam-project . t)
;;            (kittymacs-org-roam-excluded-directories . ("secrets")))))

;; Terminal
;; MSYS2's location, when it is not the normal C:/msys64/.
;; (setopt kittymacs-msys2-root "D:/Tools/msys64/")
;;
;; Where the escape key goes while a full-screen program is drawing in the

;; macOS
;; Swap Command and Option, or give the right Option key to Emacs too:

  + The icon font is a separate option, used only for Nerd Font icons.

* Building from inside Emacs
:PROPERTIES:
:header-args:emacs-lisp: :tangle ../lisp/kittymacs-literate.el :eval never :comments no :padline no :mkdirp yes
:END:

- The =SPC C= menu, which [[id:53ad53ed-155f-47dc-973d-7be18de2893c][the keys chapter]] binds; this module holds its commands.

| Key       | Command                      | Does                                                   |
|-----------+------------------------------+--------------------------------------------------------|
| =SPC C c= | =kittymacs-literate-open=    | open [[id:52a45bf9-9521-4e0d-9867-1c54721844a3][the reading guide]]                               |
| =SPC C f= | =kittymacs-find-config-file= | find a chapter by name                                 |
| =SPC C s= | =kittymacs-search-config=    | search every chapter with ripgrep                      |
| =SPC C p= | =kittymacs-open-private-file= | open =private.el=, creating it from the example first |
| =SPC C t= | =kittymacs-literate-tangle=  | =just tangle=, in a clean Emacs                        |
| =SPC C k= | =kittymacs-literate-check=   | =just tangle-check=, in a clean Emacs                  |
| =SPC C u= | =kittymacs-open-custom-file= | open the Customize file                                |
| =SPC C a= | =kittymacs-open-architecture= | open =ARCHITECTURE.md=, the design record             |

- Every path is relative to =user-emacs-directory=, so the commands work from any buffer.

#+begin_src emacs-lisp
;;; kittymacs-literate.el --- Edit and build the literate source -*- lexical-binding: t; -*-
;; Generated from literate/80-maintenance.org; edit the Org source, then tangle.
;;; Commentary:
;; Development addition: keep authoring explicit and startup independent of Org.
;;; Code:

(require 'kittymacs-defaults)

(defun kittymacs-literate-open (&rest _)
  "Open the literate configuration's reading guide."
  (interactive)
  (find-file (expand-file-name "literate/index.org" user-emacs-directory)))
(defun kittymacs-find-config-file ()
  "Open one of the literate chapters."
  (interactive)
  (let ((default-directory (expand-file-name "literate/" user-emacs-directory)))
    (call-interactively #'find-file)))

(defun kittymacs-search-config ()
  "Search the configuration sources with ripgrep."
  (interactive)
  (consult-ripgrep (expand-file-name "literate/" user-emacs-directory)))

(defun kittymacs-open-private-file ()
  "Open private.el, creating it from the example if needed."
  (interactive)
  (let ((private (expand-file-name "private.el" kittymacs-lisp-dir))
        (example (expand-file-name "private.example.el" kittymacs-lisp-dir)))
    (when (and (not (file-exists-p private)) (file-exists-p example))
      (copy-file example private))
    (find-file private)))

(defun kittymacs-open-custom-file ()
  "Open the file where Customize saves settings."
  (interactive)
  (find-file custom-file))

(defun kittymacs-open-architecture ()
  "Open ARCHITECTURE.md, the design record."
  (interactive)
  (find-file (expand-file-name "ARCHITECTURE.md" user-emacs-directory)))
#+end_src

- =SPC C t= and =SPC C k= run =tools/tangle.el= in a separate =emacs -Q= process, exactly as =just= does, and show its output in =*kittymacs literate build*=.
  + Unsaved chapters are refused first, so a build never reads a stale file.
  + A successful tangle still needs a restart: the running Emacs keeps the modules it loaded.

#+begin_src emacs-lisp
(defun kittymacs-literate--build (write)
  "Run the isolated literate builder; WRITE selects generation over checking."
  (let ((source-dir (expand-file-name "literate/" user-emacs-directory))
        (output (get-buffer-create "*kittymacs literate build*")))
    (dolist (buffer (buffer-list))
      (when-let* ((file (buffer-file-name buffer)))
        (when (and (file-in-directory-p file source-dir)
                   (buffer-modified-p buffer))
          (user-error "Save %s before building the literate configuration" file))))
    (with-current-buffer output
      (let ((inhibit-read-only t)) (erase-buffer)))
    (let ((status
           (call-process (expand-file-name invocation-name invocation-directory)
                         nil (list output t) nil
                         "-Q" "--batch" "-l"
                         (expand-file-name "tools/tangle.el" user-emacs-directory)
                         "--" (if write "--write" "--check"))))
      (display-buffer output)
      (unless (equal status 0)
        (user-error "Literate build failed; see %s" (buffer-name output)))
      (message (if write
                   "Lisp regenerated. Restart Emacs to apply configuration changes."
                 "Literate sources and deployed Lisp agree.")))))
(defun kittymacs-literate-tangle ()
  "Regenerate deployed Lisp from saved literate sources."
  (interactive)
  (kittymacs-literate--build t))
(defun kittymacs-literate-check ()
  "Check that deployed Lisp matches saved literate sources without writing it."
  (interactive)
  (kittymacs-literate--build nil))
(provide 'kittymacs-literate)
;;; kittymacs-literate.el ends here
#+end_src
