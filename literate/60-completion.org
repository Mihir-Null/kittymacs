- Two kinds of completion: in the /minibuffer/, whenever Emacs asks for a file, buffer, command or anything else; and /in the buffer/, as you type. Plus templates.
- The packages are the "minad stack" by Daniel Mendler and Omar Antolín: each does one thing and uses Emacs's own completion machinery rather than replacing it.
- Distilled from Lambda-Emacs by Colin McLear (=lem-setup-completion=).
- Leans on [[id:3fd783cd-deb8-48aa-bb44-0d9b16535365][the defaults chapter]] for its directories; [[id:53ad53ed-155f-47dc-973d-7be18de2893c][the keys chapter]] binds the commands under =SPC=; [[id:8545f3ea-11d0-420b-a823-22a344e56f1e][the help chapter]] is the other half of discovery.

| Package                                | Does                                             | Reach it                        |
|----------------------------------------+--------------------------------------------------+---------------------------------|
| Vertico                                | shows minibuffer candidates as a list            | any prompt                      |
| Orderless                              | matches space-separated words in any order       | typing in any prompt            |
| Marginalia                             | adds a column of context to each candidate       | any prompt                      |
| Consult                                | searches and jumps, with live preview            | =SPC s s=, =SPC s d=, =SPC b b= |
| Embark                                 | acts on a candidate or the thing at point        | =C-.=                           |
| Corfu                                  | pops up completions in the buffer as you type    | typing                          |
| Cape                                   | adds in-buffer completion sources                | =SPC c p=                       |
| =flyspell-correct=, =consult-flyspell= | puts spelling corrections through the same stack | =C-;=, =SPC s p=                |
| Yasnippet                              | expands text templates                           | =C-'=, =SPC i s=                |

* The candidate list: Vertico

- Vertico shows the candidates as a list:
  + candidates cycle at the end;
  + the list keeps a fixed height;
  + file candidates sort by history, length and name, then directories before files;
  + =ESC= quits; =M-RET= exits with exactly what you typed.
- The extensions are part of Vertico itself:
  + =vertico-directory= makes =DEL= delete a whole path component and tidies shadowed paths;
  + =vertico-repeat= resumes the last completion session (=SPC s l=);
  + =vertico-buffer= puts the list in a side window at the top of the frame, 12 lines high, which [[id:f1d045c2-e2dc-4514-ab17-dd982ed6be00][the frames chapter]] keeps attached to the editing frame.
- The module needs only the defaults module's directories, loaded first.

(defun kittymacs-vertico-directories-first (files)
  "Sort FILES by history, length and name, then put directories first."
  (let ((sorted (vertico-sort-history-length-alpha files)))
    (nconc (seq-filter (lambda (file) (string-suffix-p "/" file)) sorted)
           (seq-remove (lambda (file) (string-suffix-p "/" file)) sorted))))

(use-package vertico
  :ensure t
  :demand t
  :bind (:map vertico-map
         ("<escape>" . minibuffer-keyboard-quit)
         ("M-RET" . vertico-exit))
  :custom
  (vertico-cycle t)
  (vertico-resize nil)
  (vertico-multiform-categories
   '((file (vertico-sort-function . kittymacs-vertico-directories-first))))
  :config
  (vertico-mode 1)
  (vertico-multiform-mode 1))

(use-package vertico-directory

* Minibuffer settings

- A few settings from the Vertico README:
  + mark multi-selection prompts;
  + keep the cursor out of the prompt text;
  + allow a minibuffer command to start another (Embark relies on that).
- File and buffer names, and completion in general, ignore case.
- A /multi-selection/ prompt, from =completing-read-multiple=, accepts several answers separated by commas, but on Emacs 30 nothing on screen says so.
  + The advice below prefixes such prompts with =[CRM]=.
  + Emacs 31 shows its own indicator (the option =crm-prompt=), so the advice is added only on older versions; otherwise the prompt would carry two.

#+begin_src emacs-lisp
(defun kittymacs--crm-indicator (args)
  "Prefix a `completing-read-multiple' prompt with [CRM]."
  (cons (concat "[CRM] " (car args)) (cdr args)))
(when (< emacs-major-version 31)
  (advice-add #'completing-read-multiple :filter-args #'kittymacs--crm-indicator))

(setopt resize-mini-windows t
        enable-recursive-minibuffers t
        minibuffer-prompt-properties '(read-only t cursor-intangible t face minibuffer-prompt)
        read-file-name-completion-ignore-case t
        read-buffer-completion-ignore-case t
        completion-ignore-case t)
(add-hook 'minibuffer-setup-hook #'cursor-intangible-mode)

#+end_src

* Searching and jumping: Consult

- Consult supplies the commands the leader's search and buffer menus call.
  + They preview the candidate as you move through the list, after a 0.2 s pause for searches, files, bookmarks and themes.
  + =M-n= inserts the thing at point.
- Ripgrep results appear after two characters.
- Xref (go to definition, find references) and the register preview go through Consult too.
- Two commands written here:
  + =kittymacs-search-symbol-at-point= (=SPC s .=) searches the buffer's lines for the symbol at point;
  + =kittymacs-search-manuals= (=SPC h s=) searches the Emacs, Org and completion-stack Info manuals.
- =consult-dir= (=C-x C-d=, =SPC f D=) picks a directory; inside a Vertico prompt =C-x C-d= switches the prompt there and =C-x C-j= jumps to a file in it.

#+begin_src emacs-lisp
(use-package consult
  :ensure t
  :bind (("C-x b" . consult-buffer)
         ("M-y" . consult-yank-pop)
         ("M-g g" . consult-goto-line)
         ("M-g i" . consult-imenu))
  :hook (completion-list-mode . consult-preview-at-point-mode)
  :custom
  (consult-async-min-input 2)
  (consult-ripgrep-args
   "rg --null --line-buffered --color=never --max-columns=1000 --path-separator / --smart-case --no-heading --with-filename --line-number --search-zip")
  (register-preview-delay 0.5)
  (register-preview-function #'consult-register-format)
  (xref-show-xrefs-function #'consult-xref)
  (xref-show-definitions-function #'consult-xref)
  :config
  (consult-customize
   consult-ripgrep consult-git-grep consult-grep
   consult-bookmark consult-recent-file consult-xref
   consult-source-bookmark consult-source-recent-file
   consult-source-project-recent-file consult-theme
   :preview-key '(:debounce 0.2 any))
  (advice-add #'register-preview :override #'consult-register-window))

* Acting on things: Embark

- Embark turns the thing at point, or the current minibuffer candidate, into a menu of actions:
  + =C-.= on a file name offers to open, delete, copy or rename it;
  + on a symbol it offers help and definitions.
- which-key draws the menu, so it looks like the leader.
  + When Embark switches to its completing-read prompter, the which-key popup is hidden first.
- =C-h B= lists every key bound in the current context: the fastest way to explore a mode.
- Extra file actions: =x= opens the file externally, =D= opens Dired in its directory, =g= runs ripgrep there.

| Key     | Where                 | Does                              |
|---------+-----------------------+-----------------------------------|
| =C-.=   | everywhere            | act on the target                 |
| =C->=   | everywhere            | act on every candidate            |
| =M-.=   | everywhere            | the default action for the target |
| =C-S-o= | completion minibuffer | act                               |
| =;=     | =*Completions*= list  | act                               |
| =C-h B= | everywhere            | list the bindings in this context |

#+begin_src emacs-lisp
;; Embark's variable, bound dynamically below even before Embark has loaded.
(defvar embark-indicators)

(defun kittymacs-embark-which-key-indicator ()
  "Show Embark's action keymap with which-key."
  (lambda (&optional keymap targets _prefix)
    (if (null keymap)
        (which-key-hide-popup)
      (which-key-show-keymap
       (if (eq (plist-get (car targets) :type) 'embark-become)
           "Become"
         (format "Act on %s '%s'%s"
                 (plist-get (car targets) :type)
                 (embark--truncate-target (plist-get (car targets) :target))
                 (if (cdr targets) "..." "")))))))

(defun kittymacs--embark-hide-which-key (function &rest args)
  "Hide the which-key popup before the completing-read prompter takes over."
  (which-key-hide-popup)
  (let ((embark-indicators (remq #'kittymacs-embark-which-key-indicator embark-indicators)))
    (apply function args)))

(defun kittymacs-embark-dired-here (file)
  "Open Dired in FILE's directory."
  (dired (file-name-directory file)))

(defun kittymacs-embark-ripgrep-here (file)
  "Run ripgrep in FILE's directory."
  (let ((default-directory (file-name-directory file)))
    (consult-ripgrep)))

  (keymap-set embark-file-map "x" #'embark-open-externally)

* Completion in the buffer: Corfu

- Corfu pops up after a short pause while you type; a second pause (1 s) shows documentation for the highlighted candidate.
- The icons in the margin come from [[id:0286f652-e861-4e61-9ca6-91e225c8939d][the appearance chapter]].
- Corfu also runs in minibuffers that offer completion at point, such as =M-:=.
- In Eshell the popup appears only on request, with =TAB=, as it would in Bash or Zsh.
- =RET= and =TAB= differ, as Corfu's manual suggests:
  + =RET= is =corfu-send=: it inserts the candidate and, in Eshell or a comint shell such as =M-x shell=, also runs the line, so you do not press =RET= twice;
  + =TAB= only inserts, so you can complete a file name and keep typing the command;
  + outside shells =corfu-send= does exactly what =corfu-insert= does.

| Key           | Does                                         |
|---------------+----------------------------------------------|
| =C-j= / =C-k= | next / previous candidate                    |
| =RET=         | insert, and run the line in a shell          |
| =TAB=         | insert only                                  |
| =ESC=         | dismiss                                      |
| =M-SPC=       | insert a separator, to add an Orderless word |
| =M-l=         | show the candidate's location                |
| =M-/=         | =dabbrev-completion=, outside the popup      |
| =C-M-/=       | =dabbrev-expand=, outside the popup          |

#+begin_src emacs-lisp
(defun kittymacs--corfu-in-minibuffer ()
  "Enable Corfu in minibuffers that offer completion at point, such as M-:."
  (when (where-is-internal #'completion-at-point (list (current-local-map)))
    (corfu-mode 1)))

(defun kittymacs--corfu-in-shells ()
  "In Eshell, complete only on request, like an ordinary shell."
  (setq-local corfu-auto nil
              corfu-quit-no-match t
              corfu-quit-at-boundary t)
  (corfu-mode 1))

  + File names and language keywords are always on.

* Templates: Yasnippet

- Snippets are text templates with fields.
- Type a key and press =C-'= to expand, or pick one with =SPC i s=; =SPC i S= starts a new one.
- Your own snippets live under =var/etc/snippets/<major-mode>/=.
  + Set =kittymacs-snippets-dir= in =private.el= to keep them somewhere else, such as a directory you back up.
- Snippets do not expand inside Org source blocks.
- Yasnippet loads a second after startup.
  + It has no autoload cookies, so the two commands =SPC i= binds are declared to work before then.
- Its =backquote-change= warning is suppressed.

#+begin_src emacs-lisp
(defcustom kittymacs-snippets-dir (expand-file-name "snippets/" kittymacs-etc-dir)
  "Directory of personal snippets, one subdirectory per major mode."
  :type 'directory
  :group 'kittymacs)

(defun kittymacs--yas-not-in-org-src ()
  "Do not expand snippets inside Org source blocks."
  (setq-local yas-buffer-local-condition '(not (org-in-src-block-p t))))

(use-package yasnippet
  :ensure t
  :defer 1
  ;; No autoload cookies upstream: declare the two commands SPC i binds, so
  ;; they work in the second before the deferred load has happened.
  :commands (yas-insert-snippet yas-new-snippet)
  :bind (:map yas-minor-mode-map
         ("C-'" . yas-expand))
  :custom
  (yas-snippet-dirs (list kittymacs-snippets-dir))
  :config
  (make-directory kittymacs-snippets-dir t)
  (add-hook 'org-mode-hook #'kittymacs--yas-not-in-org-src)
  (with-eval-after-load 'warnings
    (push '(yasnippet backquote-change) warning-suppress-types))
  (yas-global-mode 1))

* Meow and completion :meow:
:PROPERTIES:
:ID: 0d3c69ce-4f58-421d-98d3-183b5350faba
:END:

- Nothing special is needed, and there is no =SPC m= menu: completion has no buffers of its own to start in a state.
- The minibuffer always starts in Insert state, so typing filters immediately; =ESC= quits it.
- Corfu's popup reads =C-j=/=C-k= before Meow sees them.
- Embark's =C-.= works in every state.
- The leader reaches the Consult commands above:
  + =SPC s= for searches;
  + =SPC b= for buffers;
  + =SPC f= for files.

* Check

- =SPC SPC= then =th lin=: =thing-at-point= style commands match, words in any order.
- =SPC s s=, type a word, move through the list: the buffer scrolls to each match.
- =SPC f f=, move to a file, =C-.=: which-key lists the actions.
- In a Lisp buffer, type =(def= and wait: Corfu opens; =C-j= moves down.
- In Eshell, type =ls ~/= and press =TAB=: the popup opens only now; =RET= on a candidate runs the line.
- =C-h B=: every key bound here, searchable.
- =just test-packages=: the startup verifier replays a real startup with the installed packages and fails on any warning.
