Ownership: *user configuration*. [[https://github.com/Alexander-Miller/treemacs][Treemacs]] by Alexander Miller is the file tree;
this chapter scopes it to the project you are in, points its state files at
=var/=, and gives it the icons, Git colours and Meow state the rest of this
configuration uses.

* What this gives you

=SPC t d= opens a sidebar down the left of the frame showing the directory
structure of the project you are working in. Move with =j= and =k=, open a
directory with =TAB=, open a file with =RET=. It follows you: change to a
buffer from another project and the tree switches to that project, without
being asked. Files are coloured by their Git status, and the tree notices
changes on disk — including the ones Magit makes when you stage or commit.

It is a *panel*, not a buffer you edit, so it stays inside the current frame
rather than becoming an OS window of its own ([[file:45-frames.org][the frames chapter]] explains that
distinction). =SPC o t= jumps into it, =q= leaves it, and =SPC f t= reveals
whatever file you are editing.

* The tree

Everything Treemacs writes goes under =var/=, like every other package here:
without this it would create =.cache/= beside =init.el=, which Git does not
ignore.

The sidebar is 35 columns and stays put; =SPC m w= sets a width and =SPC m t w=
unlocks dragging. =treemacs-is-never-other-window= keeps =other-window=,
=ace-window= and =C-x o= out of the tree, which matters here because a frame
normally holds one buffer and the tree: without it, every "other window"
lands in the sidebar. Single-child directories are collapsed into one line
so a deep package path does not cost five rows, which needs Python 3; where
there is none, the tree simply shows every level.

The tree hides nothing but the =.git= directory itself. Dotfiles are shown,
and so are files that Git ignores, such as build output or a local
=private.el=: a sidebar that silently leaves out files which exist on disk
is more confusing than one that shows a few extra. Treemacs can hide ignored
files with =treemacs-hide-gitignored-files-mode=; it is off by default, and
switched off explicitly below so that the choice is written down. Note the
=-1=: a minor mode called from Lisp with =nil= is turned *on*, not off.

#+begin_src emacs-lisp
(use-package treemacs
  :ensure t
  :commands (treemacs treemacs-select-window treemacs-find-file
             treemacs-add-and-display-current-project-exclusively)
  :custom
  ;; State, not cache: the workspace layout is worth keeping between sessions.
  (treemacs-persist-file (expand-file-name "treemacs/persist" kittymacs-etc-dir))
  (treemacs-last-error-persist-file
   (expand-file-name "treemacs/persist-at-last-error" kittymacs-cache-dir))
  (treemacs-width 35)
  (treemacs-width-is-initially-locked t)
  (treemacs-position 'left)
  (treemacs-display-in-side-window t)
  (treemacs-is-never-other-window t)
  (treemacs-follow-after-init t)
  (treemacs-file-follow-delay 0.2)
  (treemacs-project-follow-cleanup t)
  (treemacs-collapse-dirs (if (executable-find "python3") 3 0))
  (treemacs-indent-guide-style 'line)
  (treemacs-show-hidden-files t)
  (treemacs-hide-dot-git-directory t)
  (treemacs-silent-refresh t)
  (treemacs-silent-filewatch t)
  (treemacs-sorting 'alphabetic-asc)
  (treemacs-eldoc-display 'simple)
  (treemacs-no-png-images (not (display-graphic-p)))
  :config
  ;; Watch the filesystem, mark the current file in the fringe, draw the
  ;; indent guides, and show the project you are in and only that project.
  (treemacs-filewatch-mode 1)
  (treemacs-follow-mode 1)
  (treemacs-project-follow-mode 1)
  (treemacs-indent-guide-mode 1)
  (treemacs-fringe-indicator-mode 'always)

  ;; Git status colours.  The extended variants colour directories as well as
  ;; files and parse the status asynchronously in Python; `deferred' renders
  ;; the tree first and colours it a moment later, which feels quicker on a
  ;; large repository.  Without Python 3, the simple variant colours files.
  (pcase (cons (and (executable-find "git") t)
               (and treemacs-python-executable t))
    ('(t . t) (treemacs-git-mode 'deferred))
    ('(t . nil) (treemacs-git-mode 'simple)))
  ;; Show files that Git ignores, too.
  (treemacs-hide-gitignored-files-mode -1)

  ;; The sidebar is a panel that serves the buffer beside it; dimming it as
  ;; an "inactive window" only makes the tree harder to read.
  (with-eval-after-load 'dimmer
    (add-to-list 'dimmer-buffer-exclusion-regexps "\\*Treemacs")))

#+end_src

* Icons, workspaces and Magit

Three small packages connect Treemacs to what this configuration already
runs. *Nerd Font icons* replace the default PNG icons so the tree matches the
completion, Corfu and Dired icons; the check is the same one [[file:50-appearance.org][the appearance
chapter]] uses, so a machine without the font gets the plain theme instead of
boxes. *Workspaces* — [[file:68-navigation.org][the navigation chapter]] gives each tab its own set of
buffers, and =treemacs-tab-bar= gives each tab its own tree to match, so
switching workspace switches the sidebar with it. *Magit* closes the one gap
in filesystem watching: staging and committing change Git's index rather than
your files, so Treemacs would not otherwise notice that the colours changed.

#+begin_src emacs-lisp
(use-package treemacs-nerd-icons
  :ensure t
  :after treemacs
  :demand t
  :config
  (when (kittymacs-icons-available-p)
    (treemacs-load-theme "nerd-icons")))

(use-package treemacs-tab-bar
  :ensure t
  :after treemacs
  :demand t
  :config
  (treemacs-set-scope-type 'Tabs))

(use-package treemacs-magit
  :ensure t
  :after (treemacs magit)
  :demand t)

#+end_src

* Meow in the tree

The tree is an application buffer, so it starts in *Motion* state: Treemacs's
own keys are the interface and Meow adds only =j=/=k= and the leader. Treemacs
already reads =h= and =l= as collapse and expand, which is the same shape as
Dired here.

The menu below labels what a new user looks for. =SPC m ?= opens Treemacs's
own help, which lists every key it has — the same convention =?= follows in
every other mode menu in this configuration.

#+begin_src emacs-lisp
(with-eval-after-load 'meow
  (add-to-list 'meow-mode-state-list '(treemacs-mode . motion)))

(kittymacs-define-localleader 'treemacs-mode
  "f" (cons "new file" #'treemacs-create-file)
  "d" (cons "new directory" #'treemacs-create-dir)
  "r" (cons "rename" #'treemacs-rename-file)
  "D" (cons "delete" #'treemacs-delete-file)
  "y" (cons "copy" #'treemacs-copy-file)
  "m" (cons "move" #'treemacs-move-file)
  "p" (cons "copy path" #'treemacs-copy-absolute-path-at-point)
  "P" (cons "copy relative path" #'treemacs-copy-relative-path-at-point)
  "o" (cons "open elsewhere" #'treemacs-visit-node-ace)
  "x" (cons "open outside Emacs" #'treemacs-visit-node-in-external-application)
  "g" (cons "refresh" #'treemacs-refresh)
  "w" (cons "set width" #'treemacs-set-width)
  "h" (cons "show hidden files" #'treemacs-toggle-show-dotfiles)
  "b" (cons "bookmark" #'treemacs-add-bookmark)
  "!" (cons "shell command here" #'treemacs-run-shell-command-for-current-node)
  "a" (cons "add project" #'treemacs-add-project-to-workspace)
  "k" (cons "remove project" #'treemacs-remove-project-from-workspace)
  "u" (cons "parent directory" #'treemacs-root-up)
  "q" (cons "close the tree" #'treemacs-quit)
  "?" (cons "menu" #'treemacs-common-helpful-hydra))

(provide 'kittymacs-treemacs)

#+end_src

* Try it

- =SPC t d= in any file of a project. =j= and =k= move, =TAB= opens a directory,
  =RET= opens a file in the window beside the tree.
- Open a file from a different project (=SPC p p=): the tree follows.
- Edit a file and save it: its name changes colour. Stage it with =SPC v s=
  then =s=, and the colour changes again without a refresh.
- =SPC f t= from any buffer points the tree at the file you are editing.
- =SPC m ?= lists every key Treemacs has, in a menu.
