#+TITLE: kittymacs: the reading guide
#+FILETAGS: :meta:
#+STARTUP: overview
#+PROPERTY: header-args :tangle no :eval never

- kittymacs is an Emacs configuration written as a book: each chapter explains one part of the editor and is the source of the Lisp that configures it.
  + The blocks are /tangled/ (copied out) into =lisp/*.el= and the two startup files, which is what Emacs loads.
  + You read and edit the chapters; Emacs runs the generated files.
- A word you do not know: follow its link, or see [[*Vocabulary]].
- How a chapter is written, tagged and linked: [[id:7edccfdc-3c38-489a-bc9e-4c002b432ab4][the conventions]]. How to change one: [[id:9ea539a0-f1a3-4d05-aa10-6f2d2ff3e335][the loop]].

* Start here

- Three ideas hold it together:
  1. *Meow* is the editing model: select something, then act on it ([[id:a1607a41-b741-428a-9de3-c16e7c8d3ecc][editing]]).
  2. *=SPC= is a real keymap*, not a translation trick: press it, wait, and which-key shows every group; =SPC m= is the menu for the current mode ([[id:e5942eb0-4389-447d-9317-d9178adcaaae][leader]], [[id:53ad53ed-155f-47dc-973d-7be18de2893c][keys]]).
  3. *Frames, not windows*: new editing surfaces are OS windows, so your window manager arranges them ([[id:f1d045c2-e2dc-4514-ab17-dd982ed6be00][frames]]).
- Read one more thing: [[file:../lisp/keybindings.org][the cheat sheet]]; =SPC h ?= opens it from inside Emacs.
- =SPC h t= (=M-x meow-tutor=) teaches the grammar in ten minutes.
- In a chapter, =TAB= on a heading folds or unfolds it, =S-TAB= shows the outline, and =C-c '= edits a code block in its own buffer.

* Three layers

- *Emacs* supplies the mechanisms: keymaps, hooks, faces, =package.el=, =use-package=, which-key, project.el, Dired, Org, Tree-sitter, Eglot.
- *Packages* supply the features chosen: Meow, the completion stack, Magit, ghostel, doom-modeline and the rest.
  + Each is declared in the chapter that uses it with =use-package … :ensure t=, so a fresh clone installs what it needs.
- *This configuration* is only the policy: which packages, how they are set, and the =SPC= tree that ties them together.
  + Much of it is distilled from [[https://codeberg.org/Lambda-Emacs/lambda-emacs][Lambda-Emacs]] and Colin McLear's configuration; each chapter says what it took.

* Vocabulary

- chapter :: an Org file =literate/NN-name.org=: one part of the editor explained, and the source of its module.
- tangle :: copy a chapter's code blocks into the files they name; kittymacs's only build step.
- module :: a generated =lisp/kittymacs-NAME.el=, loaded by a =require= in =init.el=.
- state :: Meow's mode of the moment: /Normal/ (select and act), /Insert/ (type), /Motion/ (a package's own keys, plus =j=, =k= and =SPC=).
- thing :: what Meow can select as a unit: a word, a line, a sentence, a pair of brackets, a syntax-tree node.
- leader :: =SPC= in Normal and Motion state: the keymap every command group hangs from.
- localleader :: =SPC m=: the current major mode's own menu.
- frame :: an Emacs OS window; kittymacs opens one where Emacs would split a window.
- which-key :: the popup listing the keys that can follow the prefix you typed.
- graph :: an Org-roam set of linked notes with its own index: your personal notes, or a project such as this checkout.
- private.el :: your settings for this machine, read early and never committed.
