it, narrow it and let it copy between directories.

* What this gives you

=SPC d= opens the directory of the current file. Move with =j= and =k=,
enter a directory with =l= or =RET=, go up with =h=. Mark files with =m=,
then copy, rename or delete the marks. Type =/= to narrow the listing as
you type. =SPC m= shows the actions that matter, labelled.

* Behaviour

Entering a directory, or going up with =h=, reuses the buffer instead of
leaving a trail of Dired buffers: =dired-kill-when-opening-new-dired-buffer=
applies to Dired's own =dired-up-directory= as well as to =RET=, and going up
also puts point on the directory you came from. Copies and deletes recurse without asking per directory, and when
two Dired windows are visible the other one is the default target, which
makes copying between directories a two-step affair. Directories sort
first: GNU =ls= does this with a switch, and on Windows and Android, where
Emacs lists directories itself, a variable does.

#+begin_src emacs-lisp
(setopt dired-kill-when-opening-new-dired-buffer t
        dired-recursive-copies 'always
        dired-recursive-deletes 'always
        dired-dwim-target t
        dired-ls-F-marks-symlinks t
        dired-clean-confirm-killing-deleted-buffers nil
        dired-create-destination-dirs 'ask
        wdired-allow-to-change-permissions t)

;; Windows has no `ls' at all.  Android has one, but every subprocess there
;; is started through an executable loader that traces its children, so the
;; cheapest listing is the one that starts no process: Emacs's own `ls-lisp'
;; reads the directory itself and sorts directories first without GNU `ls'.
(if (memq system-type '(windows-nt android))
    (setopt ls-lisp-use-insert-directory-program nil
            ls-lisp-dirs-first t
            dired-listing-switches "-lah")
  ;; macOS ships BSD ls, which has neither -v nor --group-directories-first;
  ;; Homebrew's coreutils installs GNU ls as gls, and Dired uses it when present.
  (let ((gls (and (eq system-type 'darwin) (executable-find "gls"))))
    (when gls
      (setopt insert-directory-program gls))
    (setopt dired-listing-switches
            (if (or gls (eq system-type 'gnu/linux))
                "-lahv --group-directories-first"
              "-lah"))))

(use-package dired
  :ensure nil
  :bind (:map dired-mode-map
         ("h" . dired-up-directory)
         ("l" . dired-find-file)))

#+end_src

* Extensions

=diredfl= colours the listing by file type. =dired-narrow= filters the
listing as you type. =dired-ranger= copies files to a clipboard so you can
paste them in another directory, the way graphical file managers do. Large
copies run in the background.

#+begin_src emacs-lisp
(use-package diredfl
  :ensure t
  :hook (dired-mode . diredfl-mode))

(use-package dired-narrow
  :ensure t
  :bind (:map dired-mode-map
         ("/" . dired-narrow)))

(use-package dired-ranger
  :ensure t
  :after dired
  :commands (dired-ranger-copy dired-ranger-move dired-ranger-paste))

(use-package async
  :ensure t
  :after dired
  :config
  (dired-async-mode 1))

#+end_src

* A file tree at the side

The sidebar that shows a project's directory structure is [[file:65-treemacs.org][Treemacs]], on the same
=SPC t d= as before. Dired remains the place to *operate* on files — mark a
dozen, rename them all, copy between two directories — and Treemacs the place
to *see* where they are. =SPC f t= points the tree at the file you are editing;
=SPC m o= in the tree opens a directory in Dired.

* Meow in Dired

Dired starts in Motion state so its own keys work; =j= and =k= move by
line, and the leader is available. The localleader labels the operations a
new user looks for.

#+begin_src emacs-lisp
(with-eval-after-load 'meow
  (add-to-list 'meow-mode-state-list '(dired-mode . motion)))

(kittymacs-define-localleader 'dired-mode
  "c" (cons "copy" #'dired-do-copy)
  "r" (cons "rename / move" #'dired-do-rename)
  "d" (cons "delete" #'dired-do-delete)
  "m" (cons "mark" #'dired-mark)
  "u" (cons "unmark" #'dired-unmark)
  "U" (cons "unmark all" #'dired-unmark-all-marks)
  "t" (cons "toggle marks" #'dired-toggle-marks)
  "+" (cons "new directory" #'dired-create-directory)
  "n" (cons "new file" #'dired-create-empty-file)
  "/" (cons "narrow" #'dired-narrow)
  "w" (cons "edit names (wdired)" #'wdired-change-to-wdired-mode)
  "y" (cons "copy to clipboard" #'dired-ranger-copy)
  "p" (cons "paste" #'dired-ranger-paste)
  "P" (cons "move here" #'dired-ranger-move)
  "s" (cons "sort" #'dired-sort-toggle-or-edit)
  "!" (cons "shell command" #'dired-do-shell-command)
  "z" (cons "compress" #'dired-do-compress-to)
  "(" (cons "toggle details" #'dired-hide-details-mode)
  "g" (cons "refresh" #'revert-buffer)
  "?" (cons "menu" #'casual-dired-tmenu))

(provide 'kittymacs-dired)

#+end_src

* Try it

- =SPC d=, then =/= and type part of a name.
- Mark two files with =m=, press =SPC m y=, go elsewhere, =SPC m p=.
- =SPC m w= turns the listing into an editable buffer: rename by typing, =C-c C-c= to apply.
