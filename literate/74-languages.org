#+TITLE: Languages: Tree-sitter and Eglot
#+FILETAGS: :code:
#+STARTUP: overview
#+PROPERTY: header-args:emacs-lisp :eval never :comments no :padline no :mkdirp yes

- Tree-sitter major modes wherever Emacs has one and its grammar loads, the classic modes everywhere else, and Eglot on demand under =SPC l=.
- Tree-sitter, Eglot, Flymake and xref are Emacs facilities; grammars, compilers and language-server executables are separate dependencies, which this chapter never assumes.
  + Building a grammar waits for your answer to Emacs's question, and starting a language server for =SPC l e=; startup only configures and checks.
- Leans on [[id:afa6b7fd-742a-4c15-86a6-32e3e8027b0e][the platform chapter]] for =kittymacs-msys2-root=; [[id:53ad53ed-155f-47dc-973d-7be18de2893c][the keys chapter]] binds =SPC l=; [[id:a1607a41-b741-428a-9de3-c16e7c8d3ecc][the editing chapter]] turns the parse tree into Meow things.
- Read [[id:97c04bd3-1404-4b0a-8018-20d77bc671bc][the programming chapter]] first: it is what every programming buffer gets regardless of language.

* Tree-sitter grammars
:PROPERTIES:
:header-args:emacs-lisp: :tangle ../lisp/kittymacs-treesit.el :eval never :comments no :padline no :mkdirp yes
:END:

- Writes [[file:../lisp/kittymacs-treesit.el][lisp/kittymacs-treesit.el]].
- Emacs 31 does most of the work; this module turns it on and fills three gaps:
  + the Tree-sitter modes that come from packages, which register nothing themselves;
  + a grammar that is still missing, which leaves the classic mode in charge instead of a mode without highlighting;
  + a command that builds the usual grammars ahead of time.

** What Emacs 31 does by itself :concept:
:PROPERTIES:
:ID: 82195aec-3196-4977-852c-79c71b01d852
:END:

- Every Tree-sitter mode Emacs ships declares three things when Emacs starts, before its library loads:
  1. a remap from its classic mode, in =treesit-major-mode-remap-alist=: =python-mode= → =python-ts-mode=;
  2. for a language with no classic mode, an =auto-mode-alist= entry for a =-maybe= function: =.yaml= → =yaml-ts-mode-maybe=, which chooses =yaml-ts-mode= when the mode is enabled or its grammar loads;
  3. once its library loads, a grammar recipe pinned to the commit its queries were written against: =(python URL :commit "bffb65a…")=.
- Two options act on those declarations:
  + =treesit-enabled-modes= :: =t= copies every remap into =major-mode-remap-alist=, where Emacs looks when it chooses a mode for a file;
  + =treesit-auto-install-grammar= :: =ask= offers to clone and compile a missing grammar the first time a mode needs it.
- So the remap table, the file mappings and the grammar pins all belong to Emacs; kittymacs keeps none of its own for the languages Emacs ships, except Markdown, which Emacs ships undeclared ([[*Markdown, which Emacs ships unwired]]).
- =M-x describe-variable RET treesit-major-mode-remap-alist= lists them: 26 remaps on Emacs 31.1, from Bash, C and CMake to Rust, TOML and YAML.

** Where compiled grammars live

- The checkout stays source-only; compiled parser libraries belong in the disposable cache.
- =kittymacs-treesit-grammar-directory= defaults to =tree-sitter/= under =kittymacs-cache-dir= (=var/cache/tree-sitter/=).
- It is put first in =treesit-extra-load-path= before every availability check and every install.
  + Emacs installs a grammar it is asked for into the first writable directory of that list, so the prompt and the commands below all build into the cache.
  + A change through Customize or =setopt= after startup applies from the next check, with no restart.
- Set it in =private.el= to choose the location before startup.

#+begin_src emacs-lisp
;;; kittymacs-treesit.el --- Tree-sitter on Emacs's own machinery -*- lexical-binding: t; -*-
;; Generated from literate/74-languages.org; edit the Org source, then tangle.

;;; Commentary:
;; Emacs 31's Tree-sitter modes map their own file types, pin their own
;; grammars and offer to install a missing one.  Turn them all on, keep their
;; grammars in the cache, register the modes that come from packages the same
;; way, and leave the classic mode in charge while a grammar is missing.

;;; Code:

(require 'seq)
(require 'treesit)
(defgroup kittymacs-treesit nil
  "Tree-sitter modes and grammars."
  :group 'kittymacs)
(defcustom kittymacs-treesit-grammar-directory
  (expand-file-name "tree-sitter/" kittymacs-cache-dir)
  "Writable directory for compiled Tree-sitter grammar libraries."
  :type 'directory
  :group 'kittymacs-treesit)

(defun kittymacs-treesit--sync-grammar-directory ()
  "Put the currently configured grammar directory first in the search path."
  (setq treesit-extra-load-path
        (cons kittymacs-treesit-grammar-directory
              (delete kittymacs-treesit-grammar-directory
                      treesit-extra-load-path))))

(kittymacs-treesit--sync-grammar-directory)
#+end_src

** Every Tree-sitter mode is on; a missing grammar is offered once :decision:
:PROPERTIES:
:ID: 0a7aaddc-ecdf-4349-9218-e4a1d058379f
:END:

- =treesit-enabled-modes= is =t=: a file opens in its Tree-sitter mode whenever Emacs has one.
- =treesit-auto-install-grammar= is =ask=: the first file that needs a missing grammar asks whether to build it.
  + Building needs Git and a C compiler; nothing is downloaded at startup.
  + Answering no, or a build that fails, hands the file to its classic mode ([[*A missing grammar leaves the classic mode in charge]]).
- Set =treesit-enabled-modes= to a list of modes in =private.el= to choose them one by one, or =treesit-auto-install-grammar= to =never= to stop the question.

#+begin_src emacs-lisp
(setopt treesit-auto-install-grammar 'ask)
(setopt treesit-enabled-modes t)
#+end_src

** Grammars for modes from packages :decision:
:PROPERTIES:
:ID: 71972b31-dcaf-438f-a8e3-242fdc8809c3
:END:

- Emacs pins the grammars of its own modes; kittymacs pins only the grammars of modes it installs from a package, today =nix= for =nix-ts-mode=.
- Each recipe names an exact commit, like Emacs's own, so a grammar is rebuilt from the same source on every machine.
  + A recipe that followed the repository's head could change the parse tree under the mode's queries, or emit a parser ABI this Emacs cannot load.
- The recipes identify source only: nothing is downloaded or compiled at startup.
- Each entry has the shape of =treesit-language-source-alist=: =(LANGUAGE REPOSITORY [KEYWORD VALUE]…)=, with =:commit= and, on Windows, =:cc=.
- They are written into Emacs's own =treesit-language-source-alist=, replacing any entry for the same language, so Emacs's installer and its prompt use them.

#+begin_src emacs-lisp
(defun kittymacs-treesit--nix-source ()
  "Return the pinned Nix recipe, with a local Windows compiler when present."
  (let ((compiler
         (when (and (eq system-type 'windows-nt)
                    (boundp 'kittymacs-msys2-root))
           (file-name-concat kittymacs-msys2-root "ucrt64" "bin" "gcc.exe"))))
    (append
     '(nix "https://github.com/nix-community/tree-sitter-nix"
           :commit "ea1d87f7996be1329ef6555dcacfa63a69bd55c6")
     (when (and compiler (file-executable-p compiler))
       (list :cc compiler)))))
(defcustom kittymacs-treesit-language-source-alist
  `(,(kittymacs-treesit--nix-source))
  "Pinned grammar recipes for Tree-sitter modes that Emacs does not ship.

Each entry has the shape accepted by `treesit-language-source-alist':
\(LANGUAGE REPOSITORY [KEYWORD VALUE]...), with :commit naming an exact
commit."
  :type '(repeat sexp)
  :group 'kittymacs-treesit)
(defun kittymacs-treesit-apply-pinned-sources ()
  "Put the pinned recipes into `treesit-language-source-alist'."
  (dolist (source kittymacs-treesit-language-source-alist)
    (setf (alist-get (car source) treesit-language-source-alist)
          (cdr source))))
#+end_src

*** Building the Nix grammar on Windows :windows:
:PROPERTIES:
:ID: 829db0d6-d4e5-4346-9114-1205a00cac3c
:END:

- On Windows the Nix recipe names MSYS2's UCRT64 GCC by absolute path (=ucrt64/bin/gcc.exe= under =kittymacs-msys2-root=), when that file is executable.
- A per-recipe compiler choice: it does not change =PATH= or =exec-path= for Emacs or its child processes.
- Other platforms, and Windows without that GCC, keep Emacs's normal compiler discovery, as do the recipes Emacs ships.

** Registering a mode from a package

- A Tree-sitter mode from a package declares none of what Emacs's own modes do, so kittymacs declares it for them:
  + the remap from its classic mode, added to =treesit-major-mode-remap-alist=, and to =major-mode-remap-alist= when =treesit-enabled-modes= enables the mode;
  + the offer to build its grammar, made before the mode starts, as Emacs's own modes make it.
- [[*Nix, Racket and Guile packages][The language packages]] call it for =nix-ts-mode=; calling it again for the same mode replaces the earlier registration.

#+begin_src emacs-lisp
(defun kittymacs-treesit-register-mode (classic-mode treesit-mode language)
  "Treat TREESIT-MODE, from a package, like a Tree-sitter mode Emacs ships.
Files that open in CLASSIC-MODE open in TREESIT-MODE while
`treesit-enabled-modes' enables it, and TREESIT-MODE offers to build the
grammar for LANGUAGE before it starts, as `treesit-auto-install-grammar'
says."
  (add-to-list 'treesit-major-mode-remap-alist
               (cons classic-mode treesit-mode))
  (when (or (eq treesit-enabled-modes t)
            (memq treesit-mode treesit-enabled-modes))
    (add-to-list 'major-mode-remap-alist (cons classic-mode treesit-mode)))
  (advice-add treesit-mode :before
              (lambda (&rest _) (treesit-ensure-installed language))
              '((name . kittymacs-treesit-ensure-grammar))))
#+end_src

** Markdown, which Emacs ships unwired :decision:
:PROPERTIES:
:ID: 999217f2-b036-42b7-ab61-791e980119cc
:END:

- Emacs 31.1 ships =markdown-ts-mode= and pins its two grammars, =markdown= and =markdown-inline=, but declares none of the rest: no autoload, no =.md= entry in =auto-mode-alist=, no remap.
  + Left alone, a =.md= file opens in =fundamental-mode= and =M-x markdown-ts-mode= does not exist until something loads the library.
- So kittymacs declares what the other modes declare for themselves:
  + an autoload for the mode and for =markdown-ts-mode-maybe=;
  + =.md=, =.markdown= and the other usual extensions → =markdown-ts-mode-maybe=, which chooses the mode when it is enabled or both grammars load, and =text-mode= otherwise;
  + the remap =markdown-mode= → =markdown-ts-mode=, so a file the =markdown-mode= package claims also opens in the Tree-sitter mode, and the fallback below recognises the mode.
- The mode offers to build both grammars itself, so it needs no registration ([[*Registering a mode from a package]]).
- With no grammar, the file goes to =markdown-mode= when that package is installed and to =text-mode= otherwise, as =markdown-ts-mode-maybe= would choose.
- Remove this section once an Emacs release declares Markdown like its other modes.

#+begin_src emacs-lisp
(autoload 'markdown-ts-mode "markdown-ts-mode" "Major mode for Markdown." t)
(autoload 'markdown-ts-mode-maybe "markdown-ts-mode")
(add-to-list 'auto-mode-alist
             '("\\.\\(?:md\\|markdown\\|mkd\\|mdown\\|mkdn\\|mdwn\\)\\'"
               . markdown-ts-mode-maybe))
(add-to-list 'treesit-major-mode-remap-alist
             '(markdown-mode . markdown-ts-mode))
(when (or (eq treesit-enabled-modes t)
          (memq 'markdown-ts-mode treesit-enabled-modes))
  (add-to-list 'major-mode-remap-alist '(markdown-mode . markdown-ts-mode)))
#+end_src

** A missing grammar leaves the classic mode in charge :decision:
:PROPERTIES:
:ID: 09fd36a6-44f3-45a7-bef3-e3bb2b156a31
:END:

- Without its grammar a Tree-sitter mode still starts, with no highlighting and no indentation rules: worse than the classic mode it replaced.
  + That happens when the offer to build is declined, when the build fails, and when this Emacs has no Tree-sitter support.
  + A few modes, =mhtml-ts-mode= among them, signal an error instead, and leave the buffer half set up.
- So after Emacs chooses a mode for a file, kittymacs checks it: a Tree-sitter mode that made no parser, or that failed with an error, is replaced by its classic mode.
  + An error from any other mode is passed on unchanged.
  + A Tree-sitter mode that itself hands the file to a classic mode, as =bash-ts-mode= does with a Zsh script, is left alone: only the mode the buffer ends up in counts.
  + The classic mode is the one the remap came from; a language with no classic mode, such as YAML, gets what its =-maybe= function chooses when the mode is not enabled: =fundamental-mode=, or =text-mode= for Markdown.
  + The mode is then left out of =treesit-enabled-modes= for the rest of the session, so the next file of that kind opens straight in the classic mode, without asking again.
  + That one setting uses =customize-set-variable= rather than =setopt=: the option's type lists only the modes Emacs ships, so =setopt= would warn about a list that also holds =nix-ts-mode=.
  + A file over =treesit-max-buffer-size= also makes no parser; it gets the classic mode, but the Tree-sitter mode stays enabled for other files.
- Emacs's own warning ("Cannot activate tree-sitter…") is still written to =*Warnings*= but no longer pops up; a one-line message says which mode took over.
- The check wraps =set-auto-mode-0=, the function that applies the mode Emacs chose for a file, once; =M-x python-ts-mode= typed by hand is not second-guessed.

#+begin_src emacs-lisp
(defconst kittymacs-treesit--uninstalled-classic-modes
  '((markdown-ts-mode . text-mode))
  "Modes to use for a Tree-sitter mode whose classic mode is not installed.
A mode not listed gets `fundamental-mode'.")
(defun kittymacs-treesit--classic-mode (treesit-mode)
  "Return the mode to use instead of TREESIT-MODE while its grammar is missing."
  (let ((classic (car (rassq treesit-mode treesit-major-mode-remap-alist))))
    (if (and classic (fboundp classic))
        classic
      (alist-get treesit-mode kittymacs-treesit--uninstalled-classic-modes
                 #'fundamental-mode))))
(defun kittymacs-treesit--disable (treesit-mode)
  "Leave TREESIT-MODE out of `treesit-enabled-modes' for this session."
  (customize-set-variable
   'treesit-enabled-modes
   (remq treesit-mode
         (if (eq treesit-enabled-modes t)
             (seq-uniq (mapcar #'cdr treesit-major-mode-remap-alist))
           treesit-enabled-modes))))
(defun kittymacs-treesit--fall-back
    (set-auto-mode-0 mode &optional keep-mode-if-same)
  "Apply MODE with SET-AUTO-MODE-0; leave a Tree-sitter mode with no parser.
KEEP-MODE-IF-SAME is passed on.  Return what SET-AUTO-MODE-0 returns, or
the mode that replaced the Tree-sitter one."
  (let* ((warning-suppress-types (cons '(treesit) warning-suppress-types))
         (target (major-mode-remap mode))
         failure
         (applied
          (condition-case err
              (funcall set-auto-mode-0 mode keep-mode-if-same)
            (error (if (rassq target treesit-major-mode-remap-alist)
                       (progn (setq failure err) nil)
                     (signal (car err) (cdr err))))))
         (treesit-mode
          (seq-find (lambda (m) (rassq m treesit-major-mode-remap-alist))
                    (if failure (list major-mode target) (list major-mode)))))
    (cond
     ((and treesit-mode
           (or failure (and applied (not (eq applied :keep))))
           (null (treesit-parser-list)))
      (let ((classic (kittymacs-treesit--classic-mode treesit-mode)))
        (unless (> (buffer-size) treesit-max-buffer-size)
          (kittymacs-treesit--disable treesit-mode))
        (funcall classic)
        (message "%s: no Tree-sitter grammar loaded, using %s"
                 treesit-mode classic)
        major-mode))
     (failure (signal (car failure) (cdr failure)))
     (t applied))))
#+end_src

** Building grammars ahead of time

- The prompt builds a grammar the first time a file needs it; =M-x kittymacs-treesit-install-grammars= builds the usual ones in one go, for a new machine or an Emacs upgrade.
  + =kittymacs-treesit-languages= lists them: the languages of the files this configuration is mostly used on, and the extra grammars their modes need (=jsdoc= inside JavaScript, =gomod= for =go.mod=, =markdown-inline= inside Markdown).
  + With =C-u= it asks which languages to build, from every recipe Emacs and kittymacs know, and rebuilds them even when they load.
- Emacs registers a mode's recipe only when the mode's library loads, so the command first loads the library of every Tree-sitter mode, then puts the kittymacs pins back on top.
- Afterwards =treesit-enabled-modes= is set to =t= again, so a mode left out earlier in the session ([[*A missing grammar leaves the classic mode in charge]]) is back for the next file.
- =just update-grammars= runs the same command in batch and rebuilds every listed grammar: run it after an Emacs upgrade, whose modes may pin newer commits.
- Git and a working C compiler must already be on the machine.

#+begin_src emacs-lisp
(defcustom kittymacs-treesit-languages
  '(bash cmake css dockerfile go gomod html javascript jsdoc json markdown
         markdown-inline nix python rust toml tsx typescript yaml)
  "Grammars that `kittymacs-treesit-install-grammars' builds by default."
  :type '(repeat symbol)
  :group 'kittymacs-treesit)
(defun kittymacs-treesit--load-recipes ()
  "Load every Tree-sitter mode's library, so its grammar recipe is known."
  (dolist (mode (seq-uniq (mapcar #'cdr treesit-major-mode-remap-alist)))
    (when (autoloadp (symbol-function mode))
      (autoload-do-load (symbol-function mode) mode)))
  (kittymacs-treesit-apply-pinned-sources))
(defun kittymacs-treesit-install-grammars (languages &optional rebuild)
  "Build the grammars for LANGUAGES into `kittymacs-treesit-grammar-directory'.
A grammar that already loads is skipped unless REBUILD is non-nil.
Interactively, build `kittymacs-treesit-languages'; with a prefix argument,
choose the languages and rebuild them.  Return the languages built."
  (interactive
   (progn
     (kittymacs-treesit--load-recipes)
     (if current-prefix-arg
         (list (mapcar #'intern
                       (completing-read-multiple
                        "Build grammars: "
                        (mapcar (lambda (source) (symbol-name (car source)))
                                treesit-language-source-alist)
                        nil t))
               t)
       (list kittymacs-treesit-languages nil))))
  (kittymacs-treesit--sync-grammar-directory)
  (unless (treesit-available-p)
    (user-error "This Emacs build does not include Tree-sitter support"))
  (kittymacs-treesit--load-recipes)
  (let (built)
    (dolist (language languages)
      (unless (assq language treesit-language-source-alist)
        (user-error "No grammar recipe for %s" language))
      (when (or rebuild (not (treesit-language-available-p language)))
        (treesit-install-language-grammar
         language kittymacs-treesit-grammar-directory)
        (push language built)))
    (setopt treesit-enabled-modes t)
    (nreverse built)))
#+end_src

** What loading the module does

1. Registers the pinned recipes with Emacs: source locations only, no grammar is built.
2. Wraps =set-auto-mode-0= with the fallback, guarded, so reloading the module never stacks a second wrapper.

* Language servers and language packages

- Writes [[file:../lisp/kittymacs-languages.el][lisp/kittymacs-languages.el]].
- Requires the Tree-sitter module above, whose =kittymacs-treesit-register-mode= the Nix package uses.
- A small built-in Eglot command surface, without assuming which language servers or runtimes each machine has.

** Two opt-ins, both empty by default :decision:
:PROPERTIES:
:ID: 807bd21b-7328-4a3d-82b1-e450bf6184e9
:END:

- Machines differ in which runtimes and servers they have, so nothing language-specific happens until =private.el= asks for it, before this module loads.
- The two options:
  + =kittymacs-language-packages= :: a set of =nix=, =racket= and =guile=: the editing packages to install and configure; built-in modes and Eglot need no entry;
  + =kittymacs-eglot-auto-start-modes= :: major modes in which opening a file runs =eglot-ensure=; add a mode only after installing its server on each machine.
- With the empty defaults no extra package is installed and opening a file starts no server: =SPC l e= (=M-x eglot=) starts one.

#+begin_src emacs-lisp
;;; kittymacs-languages.el --- Selective language tooling -*- lexical-binding: t; -*-

;; servers each machine owns.  Language packages and automatic LSP startup remain
;; explicit opt-ins that can be set in private.el before this module loads.

  :group 'kittymacs)

  "Optional language packages to install and configure.

Supported values are `nix', `racket', and `guile'.  Built-in modes and Eglot do
not need to be listed here."
  :type '(set (const nix) (const racket) (const guile))
  :group 'kittymacs-languages)

The default is nil: start Eglot explicitly with `M-x eglot' (SPC l e)

** Eglot, the built-in client

- Eglot talks to the server; Emacs's own xref and Flymake show its navigation and diagnostics.
- =:commands= declares Eglot's commands as autoloads, so the =SPC l= keys load it on first use.
- =eglot-autoshutdown= stops a server once its last buffer is killed.

#+begin_src emacs-lisp
(use-package eglot
  :ensure nil
  :commands (eglot eglot-ensure eglot-shutdown eglot-reconnect
                   eglot-rename eglot-code-actions eglot-format
                   eglot-format-buffer eglot-find-declaration
                   eglot-find-implementation eglot-find-typeDefinition)
  :custom
  (eglot-autoshutdown t))
#+end_src

** Starting servers automatically, per mode

- =kittymacs-eglot-apply-auto-start-modes= puts =eglot-ensure= on the hook of each listed mode.
- It remembers the hooks it touched, so applying a changed list removes obsolete hooks as well as adding new ones.
  + Interactive: run it after changing the list in a live session.
- Applied once at load: with the empty default it installs nothing.

#+begin_src emacs-lisp
(defvar kittymacs--eglot-auto-start-hooks nil
  "Mode hooks currently managed by `kittymacs-eglot-apply-auto-start-modes'.")
(defun kittymacs-eglot-apply-auto-start-modes ()
  "Apply `kittymacs-eglot-auto-start-modes' to their corresponding hooks."
  (interactive)
  (dolist (hook kittymacs--eglot-auto-start-hooks)
    (remove-hook hook #'eglot-ensure))
  (setq kittymacs--eglot-auto-start-hooks nil)
  (dolist (mode kittymacs-eglot-auto-start-modes)
    (let ((hook (intern (format "%s-hook" mode))))
      (add-hook hook #'eglot-ensure)
      (push hook kittymacs--eglot-auto-start-hooks))))
(kittymacs-eglot-apply-auto-start-modes)
#+end_src

** Nix, Racket and Guile packages

- Each package is requested only when its symbol is in =kittymacs-language-packages=:
  + =nix= :: =nix-mode= for =.nix= files, and =nix-ts-mode=, its Tree-sitter version, [[*Registering a mode from a package][registered]] with the pinned Nix grammar;
  + =racket= :: =racket-mode= for =.rkt= files;
  + =guile= :: Geiser and its Guile adapter.
- None installs the runtime itself (Nix, Racket, Guile) or a language server; those are platform dependencies.
- =nix-mode= stays alongside =nix-ts-mode=: it maps =.nix= files, and it is the mode a Nix file falls back to while the grammar is missing.

#+begin_src emacs-lisp
;; Keep non-built-in language modes deliberate.  Set
;; `kittymacs-language-packages' in private.el before startup to enable these.
(when (memq 'nix kittymacs-language-packages)
  (use-package nix-mode
    :ensure t
    :mode "\\.nix\\'")
  (use-package nix-ts-mode
    :ensure t
    :defer t
    :init
