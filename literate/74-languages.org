This layer replaces Lambda's moving grammar recipes and unconditional remaps with pinned recipes and availability checks. Installing parsers and starting language servers remain explicit actions.

** Keep compiled grammars in the writable cache

The configuration checkout stays source-only. Compiled parser libraries belong under the disposable kittymacs cache. The current directory is placed first before every grammar availability check and explicit installation, so changing this option through Customize or =setopt= after startup takes effect immediately. Set it in =private.el= to choose the location before startup.

(defcustom kittymacs-treesit-grammar-directory
  (expand-file-name "tree-sitter/" kittymacs-cache-dir)
  "Writable directory for compiled Tree-sitter grammar libraries."
  :type 'directory
  :group 'kittymacs-treesit)

(defun kittymacs-treesit--sync-grammar-directory ()
  "Put the currently configured grammar directory first in the search path."
  (setq treesit-extra-load-path
        (cons kittymacs-treesit-grammar-directory
              (delete kittymacs-treesit-grammar-directory
                      treesit-extra-load-path))))

** Select a native Windows compiler locally

The Nix grammar recipe uses MSYS2's UCRT64 GCC by absolute path when it is available on Windows. This is a per-recipe compiler choice: it does not change =PATH= or =exec-path= for Emacs or child processes. Other platforms retain Emacs's normal compiler discovery.

#+name: kittymacs-treesit-nix-source-1
#+begin_src emacs-lisp
(defun kittymacs-treesit--nix-source ()
  "Return the pinned Nix recipe, with a local Windows compiler when present."
  (let ((compiler
         (when (and (eq system-type 'windows-nt)
                    (boundp 'kittymacs-msys2-root))
           (file-name-concat kittymacs-msys2-root "ucrt64" "bin" "gcc.exe"))))
    (append
     '(nix "https://github.com/nix-community/tree-sitter-nix"
           "ea1d87f7996be1329ef6555dcacfa63a69bd55c6")
     (when (and compiler (file-executable-p compiler))
       (list "src" compiler)))))
#+end_src

** Describe candidate mode replacements

This table is a set of possibilities. The availability check below decides which remaps can actually be installed.

The first column must name the mode Emacs really chooses for a file, or the remap never fires. For shell scripts that is =sh-mode=: there is no =bash-mode=. =sh-mode= edits every Bourne-family and C-shell dialect, while =bash-ts-mode= only understands Bash, but the remap is still safe, because =bash-ts-mode= checks the script's shell when it starts and hands anything that is not Bash or plain =sh= straight back to =sh-mode=. For JSON the built-in mode is =js-json-mode=; =json-mode= is a separate package this configuration does not install. The YAML, TypeScript and Typst rows name third-party modes and only matter when one of those packages is installed.

#+name: kittymacs-treesit-06-1
#+begin_src emacs-lisp
(defconst kittymacs-treesit-mode-remaps
  '((yaml-mode yaml-ts-mode yaml)
    (sh-mode bash-ts-mode bash)
    (typescript-mode typescript-ts-mode typescript)
    (js-json-mode json-ts-mode json)
    (css-mode css-ts-mode css)
    (python-mode python-ts-mode python)
    (typst-mode typst-ts-mode typst)
    (nix-mode nix-ts-mode nix))
  "Classic mode, Tree-sitter mode, and grammar triples managed here.")
#+end_src

** Handle exact Git revisions

Some Emacs versions treat a revision like a branch during shallow clone. The local adapter handles raw commit identifiers with a detached fetch and retains the ordinary path for other references.

#+name: kittymacs-treesit-09-1
#+begin_src emacs-lisp
(defun kittymacs-treesit--git-clone-revision
    (original-function url revision workdir)
  "Clone URL at exact REVISION into WORKDIR for `treesit'.

Emacs 30 documents REVISION as a tag or branch and implements it with
`git clone --branch', which cannot accept a raw commit hash.  Exact commits are
the reproducible unit needed here, so fetch a single detached commit when the
recipe contains a 40-character hash.  Delegate every other recipe to
ORIGINAL-FUNCTION unchanged."
  (if (and (stringp revision)
           (string-match-p (rx string-start (= 40 xdigit) string-end)
                           revision))
      (progn
        (message "Cloning pinned Tree-sitter revision")
        (treesit--call-process-signal
         "git" nil t nil "init" "--quiet" workdir)
        (treesit--call-process-signal
         "git" nil t nil "-C" workdir "remote" "add" "origin" url)
        (treesit--call-process-signal
         "git" nil t nil "-C" workdir "fetch" "--depth" "1" "--quiet"
         "origin" revision)
        (treesit--call-process-signal
         "git" nil t nil "-C" workdir "checkout" "--detach" "--quiet"
         "FETCH_HEAD"))
    (funcall original-function url revision workdir)))
#+end_src

** Keep classic modes as a working fallback

A replacement is installed only when both the target mode and its grammar work. Refreshing removes stale choices if a parser becomes unavailable.

#+name: kittymacs-treesit-10-1
#+begin_src emacs-lisp
(defun kittymacs-treesit-refresh-mode-remaps (&rest _)
  "Refresh managed mode remaps for the grammars available right now.

Any unconditional remaps inherited from Lambda are removed first.  A remap is
then added only when its target mode exists and its grammar loads successfully."
  (interactive)
  (let ((managed-modes (mapcar #'car kittymacs-treesit-mode-remaps)))
    (setq major-mode-remap-alist
          (cl-remove-if
           (lambda (remap) (memq (car remap) managed-modes))
           major-mode-remap-alist)))
  (dolist (spec kittymacs-treesit-mode-remaps)
    (pcase-let ((`(,classic-mode ,treesit-mode ,language) spec))
      (when (and (fboundp treesit-mode)
                 (kittymacs-treesit--language-available-p language))
        (add-to-list 'major-mode-remap-alist
                     (cons classic-mode treesit-mode) t))))
  major-mode-remap-alist)
#+end_src

** Install one parser on request

This interactive command checks the selected recipe and delegates compilation to Emacs. Git and a working compiler must already be available.

#+name: kittymacs-treesit-11-1
#+begin_src emacs-lisp
(defun kittymacs-treesit-install-language-grammar (language)
  "Install pinned grammar LANGUAGE, then refresh conditional remaps."
  (interactive
   (list
    (intern
     (completing-read
      "Install pinned grammar: "
      (mapcar (lambda (source) (symbol-name (car source)))
              kittymacs-treesit-language-source-alist)
      nil t))))
  (unless (assq language kittymacs-treesit-language-source-alist)
    (user-error "No pinned Tree-sitter recipe for %s" language))
  (kittymacs-treesit--sync-grammar-directory)
  (unless (treesit-available-p)
    (user-error "This Emacs build does not include Tree-sitter support"))
  (kittymacs-treesit-apply-pinned-sources)
  (treesit-install-language-grammar
   language kittymacs-treesit-grammar-directory)
  (kittymacs-treesit-refresh-mode-remaps))
#+end_src

** Install the pinned set on request

This bulk command is an explicit maintenance action. Normal startup only configures recipes and checks availability.

#+name: kittymacs-treesit-12-1
#+begin_src emacs-lisp
(defun kittymacs-treesit-install-all-grammars ()
  "Install every missing pinned grammar and refresh mode remaps."
  (interactive)
  (kittymacs-treesit--sync-grammar-directory)
  (unless (treesit-available-p)
    (user-error "This Emacs build does not include Tree-sitter support"))
  (kittymacs-treesit-apply-pinned-sources)
  (dolist (source kittymacs-treesit-language-source-alist)
    (let ((language (car source)))
      (unless (kittymacs-treesit--language-available-p language)
        (treesit-install-language-grammar
         language kittymacs-treesit-grammar-directory))))
  (kittymacs-treesit-refresh-mode-remaps))
#+end_src

** Reconcile opt-in hooks

Track the hooks installed by this module so changing the opt-in list removes obsolete hooks as well as adding new ones.

#+name: kittymacs-languages-06-1
#+begin_src emacs-lisp
(defun kittymacs-eglot-apply-auto-start-modes ()
  "Apply `kittymacs-eglot-auto-start-modes' to their corresponding hooks."
  (interactive)
  (dolist (hook kittymacs--eglot-auto-start-hooks)
    (remove-hook hook #'eglot-ensure))
  (setq kittymacs--eglot-auto-start-hooks nil)
  (dolist (mode kittymacs-eglot-auto-start-modes)
    (let ((hook (intern (format "%s-hook" mode))))
      (add-hook hook #'eglot-ensure)
      (push hook kittymacs--eglot-auto-start-hooks))))
#+end_src
