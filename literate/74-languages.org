#+TITLE: Languages: Tree-sitter and Eglot
#+FILETAGS: :code:
#+STARTUP: overview
#+PROPERTY: header-args:emacs-lisp :eval never :comments no :padline no :mkdirp yes

- Tree-sitter major modes where a pinned grammar actually loads, the classic modes everywhere else, and Eglot on demand under =SPC l=.
- Tree-sitter, Eglot, Flymake and xref are Emacs facilities; grammars, compilers and language-server executables are separate dependencies, which this chapter never assumes.
  + Installing a parser and starting a language server stay explicit actions; startup only configures and checks.
- Leans on [[id:afa6b7fd-742a-4c15-86a6-32e3e8027b0e][the platform chapter]] for =kittymacs-msys2-root=; [[id:53ad53ed-155f-47dc-973d-7be18de2893c][the keys chapter]] binds =SPC l=; [[id:a1607a41-b741-428a-9de3-c16e7c8d3ecc][the editing chapter]] turns the parse tree into Meow things.
- Read [[id:97c04bd3-1404-4b0a-8018-20d77bc671bc][the programming chapter]] first: it is what every programming buffer gets regardless of language.

* Tree-sitter grammars
:PROPERTIES:
:header-args:emacs-lisp: :tangle ../lisp/kittymacs-treesit.el :eval never :comments no :padline no :mkdirp yes
:END:

- Writes [[file:../lisp/kittymacs-treesit.el][lisp/kittymacs-treesit.el]].
- Pins each grammar recipe to an exact revision, and switches a mode to its Tree-sitter version only when the grammar loads.

** Where compiled grammars live

- The checkout stays source-only; compiled parser libraries belong in the disposable cache.
- =kittymacs-treesit-grammar-directory= defaults to =tree-sitter/= under =kittymacs-cache-dir= (=var/cache/tree-sitter/=).
- It is put first in =treesit-extra-load-path= before every availability check and every explicit install.
  + So a change through Customize or =setopt= after startup applies from the next check, with no restart.
- Set it in =private.el= to choose the location before startup.

#+begin_src emacs-lisp
;;; kittymacs-treesit.el --- Portable Tree-sitter policy -*- lexical-binding: t; -*-
;; Generated from literate/74-languages.org; edit the Org source, then tangle.

;;; Commentary:
;; A grammar recipe that follows a repository's moving head can start emitting
;; a parser ABI newer than an older supported Emacs release can load.  Keep the
;; recipes reproducible here and only remap a classic major mode after Emacs
;; has successfully loaded the corresponding grammar.

;;; Code:

(require 'cl-lib)
(require 'rx)
(require 'treesit)
(defgroup kittymacs-treesit nil
  "Portable Tree-sitter policy for the starter configuration."
  :group 'kittymacs)
(defcustom kittymacs-treesit-grammar-directory
  (expand-file-name "tree-sitter/" kittymacs-cache-dir)
  "Writable directory for compiled Tree-sitter grammar libraries."
  :type 'directory
  :group 'kittymacs-treesit)

(defun kittymacs-treesit--sync-grammar-directory ()
  "Put the currently configured grammar directory first in the search path."
  (setq treesit-extra-load-path
        (cons kittymacs-treesit-grammar-directory
              (delete kittymacs-treesit-grammar-directory
                      treesit-extra-load-path))))

(kittymacs-treesit--sync-grammar-directory)
#+end_src

** Building the Nix grammar on Windows :windows:
:PROPERTIES:
:ID: 829db0d6-d4e5-4346-9114-1205a00cac3c
:END:

- On Windows the Nix recipe names MSYS2's UCRT64 GCC by absolute path (=ucrt64/bin/gcc.exe= under =kittymacs-msys2-root=), when that file is executable.
- A per-recipe compiler choice: it does not change =PATH= or =exec-path= for Emacs or its child processes.
- Other platforms, and Windows without that GCC, keep Emacs's normal compiler discovery.

#+begin_src emacs-lisp
(defun kittymacs-treesit--nix-source ()
  "Return the pinned Nix recipe, with a local Windows compiler when present."
  (let ((compiler
         (when (and (eq system-type 'windows-nt)
                    (boundp 'kittymacs-msys2-root))
           (file-name-concat kittymacs-msys2-root "ucrt64" "bin" "gcc.exe"))))
    (append
     '(nix "https://github.com/nix-community/tree-sitter-nix"
           "ea1d87f7996be1329ef6555dcacfa63a69bd55c6")
     (when (and compiler (file-executable-p compiler))
       (list "src" compiler)))))
#+end_src

** Pinned grammar revisions :decision:
:PROPERTIES:
:ID: 71972b31-dcaf-438f-a8e3-242fdc8809c3
:END:

- A recipe that follows a repository's moving head can start emitting a parser ABI newer than an older supported Emacs can load.
- So every recipe names an exact commit whose generated parser uses ABI 13 or 14, loadable by Emacs 30 and every newer release.
- The recipes identify source only: nothing is downloaded or compiled during startup.
- Pinned: =bash=, =cmake=, =css=, =elisp=, =go=, =html=, =javascript=, =json=, =make=, =markdown=, =nix=, =python=, =toml=, =tsx=, =typescript=, =typst=, =yaml=.
  + JavaScript, TSX and TypeScript name the source directory inside the repository (=src=, =tsx/src=, =typescript/src=).
  + The Nix entry comes from [[*Building the Nix grammar on Windows]].
- Each entry has the shape of =treesit-language-source-alist=: =(LANGUAGE REPOSITORY REVISION &optional SOURCE-DIRECTORY CC CXX)=.
- To move a pin: change the commit here, tangle, then rebuild.
  + =just update-grammars= rebuilds every grammar at its pinned revision: it runs =kittymacs-treesit-install-language-grammar= over =kittymacs-treesit-language-source-alist= in batch.

** A mode switches to Tree-sitter only when its grammar loads :decision:
:PROPERTIES:
:ID: 09fd36a6-44f3-45a7-bef3-e3bb2b156a31
:END:

- =kittymacs-treesit-mode-remaps= lists the possible switches; a remap is installed only when the Tree-sitter mode exists and Emacs can load its grammar.
  + A recipe alone is not a usable parser, so Emacs itself is asked whether the language loads.

| Classic mode      | Tree-sitter mode     | Grammar      |
|-------------------+----------------------+--------------|
| =yaml-mode=       | =yaml-ts-mode=       | =yaml=       |
| =sh-mode=         | =bash-ts-mode=       | =bash=       |
| =typescript-mode= | =typescript-ts-mode= | =typescript= |
| =js-json-mode=    | =json-ts-mode=       | =json=       |
| =css-mode=        | =css-ts-mode=        | =css=        |
| =python-mode=     | =python-ts-mode=     | =python=     |
| =typst-mode=      | =typst-ts-mode=      | =typst=      |
| =nix-mode=        | =nix-ts-mode=        | =nix=        |

- The first column must be the mode Emacs really chooses for a file, or the remap never fires.
  + Shell scripts open in =sh-mode=; there is no =bash-mode=.
  + =sh-mode= edits every Bourne-family and C-shell dialect, =bash-ts-mode= only Bash; the remap is still safe, because =bash-ts-mode= checks the script's shell when it starts and hands anything that is not Bash or plain =sh= back to =sh-mode=.
  + JSON's built-in mode is =js-json-mode=; =json-mode= is a separate package this configuration does not install.
- The YAML, TypeScript, Typst and Nix rows name third-party modes and only matter when one of those packages is installed.

#+begin_src emacs-lisp
(defconst kittymacs-treesit-mode-remaps
  '((yaml-mode yaml-ts-mode yaml)
    (sh-mode bash-ts-mode bash)
    (typescript-mode typescript-ts-mode typescript)
    (js-json-mode json-ts-mode json)
    (css-mode css-ts-mode css)
    (python-mode python-ts-mode python)
    (typst-mode typst-ts-mode typst)
    (nix-mode nix-ts-mode nix))
  "Classic mode, Tree-sitter mode, and grammar triples managed here.")
(defun kittymacs-treesit--language-available-p (language)
  "Return non-nil when LANGUAGE can be loaded by this Emacs build."
  (kittymacs-treesit--sync-grammar-directory)
  (and (treesit-available-p)
       (condition-case nil
           (treesit-language-available-p language)
         (error nil))))
#+end_src

** Emacs's installer uses the pins, at exact commits

- The pinned recipes are written into Emacs's own =treesit-language-source-alist=, replacing any entry for the same language, so Emacs's installer uses them too.
- Emacs 30 documents a recipe's revision as a tag or branch and clones it with =git clone --branch=, which cannot take a raw commit hash.
- An =:around= adapter on the clone helper handles a 40-character hash itself:
  1. =git init= the work directory and add the repository as =origin=;
  2. fetch that one commit with =--depth 1=;
  3. check out =FETCH_HEAD= detached.
- Any other revision goes to Emacs's own clone unchanged.

#+begin_src emacs-lisp
(defun kittymacs-treesit-apply-pinned-sources ()
  "Put the pinned recipes into `treesit-language-source-alist'."
  (dolist (source kittymacs-treesit-language-source-alist)
    (setf (alist-get (car source) treesit-language-source-alist)
          (cdr source))))
(defun kittymacs-treesit--git-clone-revision
    (original-function url revision workdir)
  "Clone URL at exact REVISION into WORKDIR for `treesit'.

Emacs 30 documents REVISION as a tag or branch and implements it with
`git clone --branch', which cannot accept a raw commit hash.  Exact commits are
the reproducible unit needed here, so fetch a single detached commit when the
recipe contains a 40-character hash.  Delegate every other recipe to
ORIGINAL-FUNCTION unchanged."
  (if (and (stringp revision)
           (string-match-p (rx string-start (= 40 xdigit) string-end)
                           revision))
      (progn
        (message "Cloning pinned Tree-sitter revision")
        (treesit--call-process-signal
         "git" nil t nil "init" "--quiet" workdir)
        (treesit--call-process-signal
         "git" nil t nil "-C" workdir "remote" "add" "origin" url)
        (treesit--call-process-signal
         "git" nil t nil "-C" workdir "fetch" "--depth" "1" "--quiet"
         "origin" revision)
        (treesit--call-process-signal
         "git" nil t nil "-C" workdir "checkout" "--detach" "--quiet"
         "FETCH_HEAD"))
    (funcall original-function url revision workdir)))
#+end_src

** Classic modes stay the fallback

- =kittymacs-treesit-refresh-mode-remaps= first removes every remap for the managed modes, then adds back only those whose mode and grammar both work now.
  + So a parser that stops loading takes its stale remap with it; the classic mode keeps working.
- Interactive, and returns the resulting =major-mode-remap-alist=.

#+begin_src emacs-lisp
(defun kittymacs-treesit-refresh-mode-remaps ()
  "Refresh managed mode remaps for the grammars available right now.

Remaps for the managed modes are removed first.  A remap is then added
only when its target mode exists and its grammar loads successfully."
  (interactive)
  (let ((managed-modes (mapcar #'car kittymacs-treesit-mode-remaps)))
    (setq major-mode-remap-alist
          (cl-remove-if
           (lambda (remap) (memq (car remap) managed-modes))
           major-mode-remap-alist)))
  (dolist (spec kittymacs-treesit-mode-remaps)
    (pcase-let ((`(,classic-mode ,treesit-mode ,language) spec))
      (when (and (fboundp treesit-mode)
                 (kittymacs-treesit--language-available-p language))
        (add-to-list 'major-mode-remap-alist
                     (cons classic-mode treesit-mode) t))))
  major-mode-remap-alist)
#+end_src

** Installing grammars is an explicit action

- =M-x kittymacs-treesit-install-language-grammar= offers the pinned languages, installs one into the grammar directory, then refreshes the remaps.
  + It refuses a language without a pinned recipe, and an Emacs built without Tree-sitter support.
- =M-x kittymacs-treesit-install-all-grammars= installs every pinned grammar that does not load yet, then refreshes the remaps.
- Both hand the build to Emacs's installer: Git and a working C compiler must already be on the machine.

#+begin_src emacs-lisp
(defun kittymacs-treesit-install-language-grammar (language)
  "Install pinned grammar LANGUAGE, then refresh conditional remaps."
  (interactive
   (list
    (intern
     (completing-read
      "Install pinned grammar: "
      (mapcar (lambda (source) (symbol-name (car source)))
              kittymacs-treesit-language-source-alist)
      nil t))))
  (unless (assq language kittymacs-treesit-language-source-alist)
    (user-error "No pinned Tree-sitter recipe for %s" language))
  (kittymacs-treesit--sync-grammar-directory)
  (unless (treesit-available-p)
    (user-error "This Emacs build does not include Tree-sitter support"))
  (kittymacs-treesit-apply-pinned-sources)
  (treesit-install-language-grammar
   language kittymacs-treesit-grammar-directory)
  (kittymacs-treesit-refresh-mode-remaps))
(defun kittymacs-treesit-install-all-grammars ()
  "Install every missing pinned grammar and refresh mode remaps."
  (interactive)
  (kittymacs-treesit--sync-grammar-directory)
  (unless (treesit-available-p)
    (user-error "This Emacs build does not include Tree-sitter support"))
  (kittymacs-treesit-apply-pinned-sources)
  (dolist (source kittymacs-treesit-language-source-alist)
    (let ((language (car source)))
      (unless (kittymacs-treesit--language-available-p language)
        (treesit-install-language-grammar
         language kittymacs-treesit-grammar-directory))))
  (kittymacs-treesit-refresh-mode-remaps))
#+end_src

** What loading the module does

1. Registers the pinned recipes with Emacs: source locations only, no parsers installed.
2. Computes the remaps from the parsers and modes this machine has now.
3. Adds the exact-revision adapter, guarded, so reloading the module never stacks a second wrapper around the clone helper.

#+begin_src emacs-lisp
(kittymacs-treesit-apply-pinned-sources)
(kittymacs-treesit-refresh-mode-remaps)
(unless (advice-member-p #'kittymacs-treesit--git-clone-revision

              #'kittymacs-treesit--git-clone-revision))

* Language servers and language packages
:PROPERTIES:
:header-args:emacs-lisp: :tangle ../lisp/kittymacs-languages.el :eval never :comments no :padline no :mkdirp yes
:END:

- Writes [[file:../lisp/kittymacs-languages.el][lisp/kittymacs-languages.el]].
- A small built-in Eglot command surface, without assuming which language servers or runtimes each machine has.

** Two opt-ins, both empty by default :decision:
:PROPERTIES:
:ID: 807bd21b-7328-4a3d-82b1-e450bf6184e9
:END:

- Machines differ in which runtimes and servers they have, so nothing language-specific happens until =private.el= asks for it, before this module loads.
- The two options:
  + =kittymacs-language-packages= :: a set of =nix=, =racket= and =guile=: the editing packages to install and configure; built-in modes and Eglot need no entry;
  + =kittymacs-eglot-auto-start-modes= :: major modes in which opening a file runs =eglot-ensure=; add a mode only after installing its server on each machine.
- With the empty defaults no extra package is installed and opening a file starts no server: =SPC l e= (=M-x eglot=) starts one.

** Eglot, the built-in client

- Eglot talks to the server; Emacs's own xref and Flymake show its navigation and diagnostics.
- =:commands= declares Eglot's commands as autoloads, so the =SPC l= keys load it on first use.
- =eglot-autoshutdown= stops a server once its last buffer is killed.

#+begin_src emacs-lisp
(use-package eglot
  :ensure nil
  :commands (eglot eglot-ensure eglot-shutdown eglot-reconnect
                   eglot-rename eglot-code-actions eglot-format
                   eglot-format-buffer eglot-find-declaration
                   eglot-find-implementation eglot-find-typeDefinition)
  :custom
  (eglot-autoshutdown t))
#+end_src

** Starting servers automatically, per mode

- =kittymacs-eglot-apply-auto-start-modes= puts =eglot-ensure= on the hook of each listed mode.
- It remembers the hooks it touched, so applying a changed list removes obsolete hooks as well as adding new ones.
  + Interactive: run it after changing the list in a live session.
- Applied once at load: with the empty default it installs nothing.

#+begin_src emacs-lisp
(defvar kittymacs--eglot-auto-start-hooks nil
  "Mode hooks currently managed by `kittymacs-eglot-apply-auto-start-modes'.")
(defun kittymacs-eglot-apply-auto-start-modes ()
  "Apply `kittymacs-eglot-auto-start-modes' to their corresponding hooks."
  (interactive)
  (dolist (hook kittymacs--eglot-auto-start-hooks)
    (remove-hook hook #'eglot-ensure))
  (setq kittymacs--eglot-auto-start-hooks nil)
  (dolist (mode kittymacs-eglot-auto-start-modes)
    (let ((hook (intern (format "%s-hook" mode))))
      (add-hook hook #'eglot-ensure)
      (push hook kittymacs--eglot-auto-start-hooks))))
(kittymacs-eglot-apply-auto-start-modes)
#+end_src

** Nix, Racket and Guile packages

- Each package is requested only when its symbol is in =kittymacs-language-packages=:
  + =nix= :: =nix-mode= for =.nix= files;
  + =racket= :: =racket-mode= for =.rkt= files;
  + =guile= :: Geiser and its Guile adapter.
- None installs the runtime itself (Nix, Racket, Guile) or a language server; those are platform dependencies.

#+begin_src emacs-lisp
;; Keep non-built-in language modes deliberate.  Set
;; `kittymacs-language-packages' in private.el before startup to enable these.
(when (memq 'nix kittymacs-language-packages)
  (use-package nix-mode
    :ensure t
    :mode "\\.nix\\'"))
(when (memq 'racket kittymacs-language-packages)
  (use-package racket-mode
    :ensure t
    :mode "\\.rkt\\'"))
(when (memq 'guile kittymacs-language-packages)
  (use-package geiser
    :ensure t
    :defer t)
  (use-package geiser-guile
    :ensure t
    :after geiser))
(provide 'kittymacs-languages)

* Check

- =M-x kittymacs-treesit-install-language-grammar RET python RET=, then open a =.py= file: the mode line shows =python-ts-mode=.
  + Without the grammar the same file opens in =python-mode=.
- =M-x kittymacs-treesit-refresh-mode-remaps=: the echo area shows the remaps this machine can use.
- =SPC l e= in a buffer whose server is installed: Eglot connects, and its diagnostics appear in the fringe.
- =just update-grammars= rebuilds every pinned grammar at its pinned revision, in batch, into the grammar directory.
- =just test= includes the offline Tree-sitter policy tests, [[file:../tests/kittymacs-treesit-tests.el][tests/kittymacs-treesit-tests.el]], which check:
  + the grammar directory defaults under the cache, and a directory chosen after load is searched before every probe and install;
  + the Nix recipe is exactly pinned, and on Windows uses MSYS2's GCC without touching =PATH=;
  + every remap has a recipe, and names the mode Emacs really chooses;
  + a remap needs both the mode and the grammar;
  + the installer explains when this Emacs cannot build grammars.
- One test parses a real Nix file; it runs only when =NIX_GRAMMAR_TEST_DIR= names a directory holding the compiled Nix grammar, and is skipped otherwise.
- =just test-packages= runs the verifier, which checks that =SPC l e= is =eglot=.
