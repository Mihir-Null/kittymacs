#+TITLE: Vocabulary: the book's words, and their HyWiki names
#+FILETAGS: :meta:
#+STARTUP: overview

- The words the book uses in its own sense, one heading each, so that a link, a backlink or a HyWiki word can point at one.
- Each heading has an =:ID:=, which the chapters link to, and a =:HYWIKI:= word, which your own HyWiki can borrow:
  + with Hyperbole on, the Action Key (=M-RET=) on <kittymacs-hywiki-adopt> makes each word a reference to its heading, in whichever HyWiki is current;
  + a word your wiki already has is kept as yours;
  + why the book lends words instead of being a wiki: [[id:75bf50f3-dc18-4c2d-8b2d-5279ef1c7a51][the book's words in your HyWiki]].
- The words are CamelCase, and the book's own carry a =Kittymacs= prefix, so they stand out in your notes and cannot be mistaken for a page you wrote.
- Back to [[id:52a45bf9-9521-4e0d-9867-1c54721844a3][the reading guide]].

* kittymacs
:PROPERTIES:
:ID: 890ecb00-20bf-435d-85cc-607cb010c1cc
:HYWIKI: Kittymacs
:END:

- An Emacs configuration written as a book; [[id:52a45bf9-9521-4e0d-9867-1c54721844a3][the reading guide]] is its first page.

* chapter
:PROPERTIES:
:ID: 63be800e-d1ee-4391-860b-3d5342c3f94e
:HYWIKI: KittymacsChapter
:END:

- An Org file =literate/NN-name.org=: one part of the editor explained, and the source of its module.
- Unnumbered pages, such as this one, are prose and tangle nothing ([[id:7edccfdc-3c38-489a-bc9e-4c002b432ab4][the conventions]]).

* state
:PROPERTIES:
:ID: 960b8c30-bde6-4c26-8b83-466c618bd19f
:HYWIKI: MeowState

- A key series button types its keys in the state you are in, so press =M-RET= on one in Normal state.

* Action Key
:PROPERTIES:
:ID: a58df224-49e5-4d42-ba27-e46143724c6f
:HYWIKI: ActionKey
:END:

- =M-RET= with Hyperbole on: do what the thing at point means; =C-u M-RET=, the Assist Key, explains or does the alternative ([[id:dd02e28d-87f3-4b22-a7fe-9cfa5636de04][Hyperbole]]).
- In Org it acts only on links and buttons, so =M-RET= keeps making headings and items.

* implicit button
:PROPERTIES:
:ID: 373e062c-c2ef-49c0-ae4e-51255ca4f84a
:HYWIKI: ImplicitButton
:END:

- Text Hyperbole recognizes as a button by its shape alone, with no markup and nothing stored: a file name in double quotes, a key series in braces, an action button in angle brackets, a URL.
- The book uses only these; explicit buttons store their actions in a hidden file ([[id:7edccfdc-3c38-489a-bc9e-4c002b432ab4][the conventions]] say why).

* key series
:PROPERTIES:
:ID: c1b6062a-8147-43b0-9c4b-d9ca14928ab3
:HYWIKI: KeySeries
:END:

- Keys in braces, such as {SPC h ?}: the Action Key types them for you.
- Inside Org's verbatim or code markup they are only text, so the book writes a key in braces where you are meant to press it, and as verbatim where it is only named.

* action button
:PROPERTIES:
:ID: 480e80e5-cea7-45e4-8349-14f061909d70
:HYWIKI: ActionButton
:END:

- A Lisp call or a variable in angle brackets, such as <emacs-init-time>: the Action Key evaluates it and shows the value.
- The *Check* of a chapter uses them for what it used to ask you to type after =M-:=.

* Koutline
:PROPERTIES:
:ID: 90d91772-5b26-4f8e-9a54-f3b4dc4d7b1e
:HYWIKI: Koutline
:END:

- Hyperbole's outline format, =.kotl=: every cell has a permanent ID and a relative label such as =2b3=, and a link to a cell survives the outline being reordered.
- [[file:book.kotl][The book's map]] is one.

* WikiWord
:PROPERTIES:
:ID: b21fc3b4-c89c-4c4a-8e55-eacf8e64a5fc
:HYWIKI: WikiWord
:END:

- A capitalized word that names a HyWiki page or referent; with HyWiki on, the Action Key on it goes there.
- In a HyWiki page, the Action Key on a capitalized word that names nothing yet makes a page for it.
