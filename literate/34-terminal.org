Ownership: *user configuration*. [[https://github.com/dakra/ghostel][ghostel]] by Daniel Kraus is the terminal
emulator; this chapter chooses its settings, wires it to the packages this
configuration already uses, and teaches it Meow's states. The integration
recipes follow ghostel's own manual.

* What this gives you

=SPC o e= opens a real terminal inside Emacs. Real means a program running
there cannot tell the difference from a terminal window: =htop=, =vim=, =less=,
=lazygit=, a TUI coding agent, a test runner that draws progress bars and asks
=y/n= — they all behave. The terminal knows where it is (=cd= moves Emacs's
directory with it), what you ran (=SPC m n= jumps between prompts), and what it
printed (links are clickable, colours are exact).

Ghostel is a thin Emacs layer over =libghostty-vt=, the terminal engine behind
[[https://ghostty.org/][Ghostty]]. The engine is a small native library, so the first =SPC o e= offers to
download it — about a megabyte, once per machine. Everything else is Emacs
Lisp.

* Where the native module lives

Ghostel keeps its native module next to its own package directory by default.
This configuration installs packages under =var/elpa/=, which =M-x package-upgrade=
rewrites, so the module is kept in =var/ghostel/= instead: upgrading ghostel
then never deletes a library that this Emacs has already mapped into memory.
It is also the one thing this chapter must decide *before* ghostel loads.

The module is downloaded on the first =SPC o e=, after asking. Nothing is
fetched when Emacs starts, and nothing is fetched when this file loads.

#+begin_src emacs-lisp
(defcustom kittymacs-terminal-module-directory
  (expand-file-name "ghostel/" kittymacs-var-dir)
  "Directory holding ghostel's native module.
Kept outside `package-user-dir' so upgrading the package never deletes a
module file this Emacs has already loaded."
  :type 'directory)

(defun kittymacs-terminal-module-installed-p ()
  "Return non-nil when ghostel's native module has been downloaded or built.
Nil also when this Emacs was built without dynamic module support, which
is what the terminal needs."
  (and module-file-suffix
       (file-exists-p
        (expand-file-name (concat "ghostel-module" module-file-suffix)
                          kittymacs-terminal-module-directory))))

#+end_src

** Not on Android

Ghostel asks two things of a platform that Android does not grant. It is
installed with =:vc=, so the first start clones it with =git=, which the Android
port does not ship. And it is a native module: upstream publishes prebuilt
modules for the desktop platforms, none for =android-aarch64=, and the Android
port is commonly built without dynamic module support at all — in which case
=module-file-suffix= is nil and no module could be loaded however it arrived.

Neither is worth an error message on every start, so ghostel is simply not
installed there and Eshell takes =SPC o e=. Eshell is Lisp, needs no module and
no subprocess to start, and where Termux is paired it runs Termux's programs
like any other shell. That is a genuine loss — Eshell is not a terminal and
will not run =htop= or a full-screen editor — and it is the honest one to take.

#+begin_src emacs-lisp
(defcustom kittymacs-terminal-ghostel
  (not (eq system-type 'android))
  "Whether ghostel provides the terminal.
Off on Android, which has neither `git' for ghostel's `:vc' checkout nor a
prebuilt native module.  `kittymacs-terminal-open' falls back to Eshell
whenever this is nil."
  :type 'boolean)
#+end_src

* The terminal

A terminal closes its buffer when the shell exits, but asks first if a command
is still running. Terminals opened with =SPC o p= carry their project's name;
set =ghostel-buffer-name-function= if you would rather they follow the title or
the directory. Five megabytes of scrollback is
kept and searchable with =consult-line= and =isearch= like any other buffer.

OSC 52 is left off: it lets a program running in the terminal write your
system clipboard, which is convenient over SSH and unpleasant when the output
you just =cat='d was hostile. Turn it on per machine in =private.el= if you
want it.

Ghostel is the one package here installed from its *repository* rather than an
archive, with =:vc=, which is upstream's own documented method. Both reasons are
practical: MELPA's ghostel build is broken at the time of writing — its index
advertises a tarball that answers 404 — and the Consult extension below has
never been published there at all. A =:vc= package is an ordinary Git checkout
under =var/elpa/=, about ten megabytes, cloned once; =M-x package-vc-upgrade=
updates it. Move both to =:ensure t= when MELPA carries them.

#+begin_src emacs-lisp
(use-package ghostel
  :vc (:url "https://github.com/dakra/ghostel" :lisp-dir "lisp" :rev :newest)
  :if kittymacs-terminal-ghostel
  :defer t
  :commands (ghostel ghostel-project ghostel-other ghostel-list-buffers
             ghostel-create ghostel-exec ghostel-compile ghostel-recompile)
  :custom
  (ghostel-module-directory kittymacs-terminal-module-directory)
  (ghostel-kill-buffer-on-exit t)
  (ghostel-query-before-killing 'auto)
  (ghostel-max-scrollback (* 5 1024 1024))
  (ghostel-scroll-on-input t)
  (ghostel-enable-osc52 nil)
  (ghostel-detect-password-prompts t)
  :config
  ;; Ghostel runs $SHELL, which native Windows does not set; follow the shell
  ;; the platform chapter picked instead of ghostel's /bin/sh fallback.
  (when (and (eq system-type 'windows-nt) (not (getenv "SHELL")))
    (setopt ghostel-shell (or explicit-shell-file-name shell-file-name)))

  ;; A shell inside the terminal can call these Emacs commands by name:
  ;;   ghostel_cmd find-file README.md
  ;;   ghostel_cmd magit-status
  ;; Only the listed commands can be reached, and every argument is a string.
  (dolist (command '(("magit-status" magit-status)
                     ("find-file-other-frame" find-file-other-frame)
                     ("treemacs-find-file" treemacs-find-file)))
    (add-to-list 'ghostel-eval-cmds command))

  ;; Integrations that ship with ghostel and only make sense once it is here:
  ;; ghostel: links in Org, bookmarks that reopen a terminal where it was,
  ;; terminals that survive a desktop session, and Lisp input methods
  ;; (Hangul, Quail) composing into the terminal rather than the buffer.
  (require 'ghostel-org nil t)
  (require 'ghostel-bookmark nil t)
  (require 'ghostel-desktop nil t)
  (when (require 'ghostel-ime nil t)
    (add-hook 'ghostel-mode-hook #'ghostel-ime-mode)))

#+end_src

* Meow in the terminal

A terminal is the one buffer where the keys are not ours: =d= must delete a
character in =vim=, not a selection. So terminals start in *Insert* state and
ghostel's semi-char mode forwards almost everything to the program. Emacs
keeps =C-c=, =C-x=, =C-u=, =C-h=, =M-x= and =M-:= (ghostel's
=ghostel-keymap-exceptions=), so =C-c C-SPC= still opens the leader.

Press =ESC= and the terminal *freezes*: Meow enters Normal state, ghostel
enters copy mode, and the whole scrollback becomes an ordinary read-only
buffer you can select, search and copy from with the grammar you already
know. Press =i= and it thaws — output resumes and the keys go back to the
shell. The two hooks below are what keep those two ideas in step; they are
buffer-local, so they only ever apply to a terminal.

#+begin_src emacs-lisp
(defun kittymacs-terminal--freeze ()
  "Freeze the terminal when Meow leaves Insert state.
The buffer becomes read-only, so Meow's grammar can select its output."
  (when (and (derived-mode-p 'ghostel-mode) (not buffer-read-only))
    (ghostel-readonly-enter)))

(defun kittymacs-terminal--thaw ()
  "Give the keyboard back to the terminal when Meow enters Insert state."
  (when (and (derived-mode-p 'ghostel-mode) buffer-read-only)
    (ghostel-semi-char-mode)))

(defun kittymacs-terminal--meow-setup ()
  "Keep Meow's state and ghostel's input mode in step in this buffer."
  (add-hook 'meow-insert-exit-hook #'kittymacs-terminal--freeze nil t)
  (add-hook 'meow-insert-enter-hook #'kittymacs-terminal--thaw nil t))

(add-hook 'ghostel-mode-hook #'kittymacs-terminal--meow-setup)

#+end_src

** Where the escape key goes

=ESC= is the one genuinely ambiguous key. In a shell it should leave Insert
state. In =vim=, =less=, =htop= or a full-screen coding agent it *is* the program's
most important key, and stealing it makes the program unusable.

Those programs all announce themselves the same way: they switch the terminal
to its /alternate screen/. So =auto= sends =ESC= to the program exactly while one
is running, and otherwise leaves Insert state. When the guess is wrong,
=SPC m ESC= toggles this buffer for as long as it lives. Outside a terminal
this command is plain =meow-insert-exit=, so nothing else changes.

#+begin_src emacs-lisp
(defcustom kittymacs-terminal-escape 'auto
  "Where the escape key goes in a terminal while Meow is in Insert state.
`auto'     to the program while it is drawing a full-screen interface
           (vim, less, htop, a TUI agent), and to Meow otherwise.
`terminal' always to the program.
`meow'     always to Meow, leaving Insert state."
  :type '(choice (const :tag "Full-screen programs only" auto)
                 (const :tag "Always the terminal" terminal)
                 (const :tag "Always Meow" meow)))

(defvar-local kittymacs-terminal--escape nil
  "This buffer's override of `kittymacs-terminal-escape', or nil to follow it.")

(defun kittymacs-terminal--escape-target ()
  "Return `terminal' or `meow': where the escape key should go here."
  (pcase (or kittymacs-terminal--escape kittymacs-terminal-escape)
    ('terminal 'terminal)
    ('meow 'meow)
    (_ (if (ghostel-alt-screen-p) 'terminal 'meow))))

(defun kittymacs-terminal-escape-dwim ()
  "Leave Meow's Insert state, or send escape to a full-screen program."
  (interactive)
  (if (and (derived-mode-p 'ghostel-mode)
           (eq (kittymacs-terminal--escape-target) 'terminal))
      (ghostel-send-key "escape")
    (call-interactively #'meow-insert-exit)))

(defun kittymacs-terminal-toggle-escape ()
  "Switch where the escape key goes in this terminal, and say where."
  (interactive)
  (unless (derived-mode-p 'ghostel-mode)
    (user-error "This is not a terminal buffer"))
  (setq kittymacs-terminal--escape
        (if (eq (kittymacs-terminal--escape-target) 'terminal) 'meow 'terminal))
  (message "Escape %s"
           (if (eq kittymacs-terminal--escape 'terminal)
               "now goes to the program in the terminal"
             "now leaves Insert state")))

#+end_src

Terminals start in Insert; a finished =ghostel-compile= run is a report, so it
starts in Motion like every other application buffer. Rebinding =ESC= in
Meow's Insert-state map is what lets the command above run at all: that map is
an emulation map and is consulted before the terminal's own keys.

#+begin_src emacs-lisp
(with-eval-after-load 'meow
  (dolist (entry '((ghostel-mode . insert)
                   (ghostel-compile-view-mode . motion)))
    (add-to-list 'meow-mode-state-list entry))
  (keymap-set meow-insert-state-keymap "<escape>" #'kittymacs-terminal-escape-dwim))

#+end_src

* Opening one

=SPC o e= and =SPC o p= are thin wrappers over =ghostel= and =ghostel-project=.
They exist for one reason: the native module is downloaded on first use, and a
user who declines that offer would otherwise meet
=Symbol's function definition is void: ghostel--new= rather than a sentence
saying what is missing and which command installs it.

** MSYS2 on Windows

PowerShell stays the ordinary shell. =SPC o m= is the separate, explicit
choice of an MSYS2 UCRT64 login shell, which is where a Windows machine keeps
its Unix tools. =MSYSTEM= selects the environment and =CHERE_INVOKING= keeps the
directory you were in; both are set for the child process only, so Emacs's own
environment is untouched. [[file:30-platform.org][The platform chapter]] owns =kittymacs-msys2-root=.

Unlike the terminal this replaces, nothing here has to translate paths or
substitute a POSIX helper: ghostel talks to Windows ConPTY directly.

#+begin_src emacs-lisp
(defun kittymacs-terminal--without-module (error)
  "Re-signal ERROR, or explain that the native module is missing."
  (if (kittymacs-terminal-module-installed-p)
      (signal (car error) (cdr error))
    (user-error "The terminal needs its native module: %s"
                (substitute-command-keys "\\[ghostel-download-module]"))))

(defun kittymacs-terminal-open (&optional arg)
  "Open a terminal.  With prefix ARG, open another one.
Ghostel offers to fetch its native module the first time; declining that
offer leaves the terminal unavailable, so say so in words.  Where ghostel
is not used at all, Eshell answers this key instead."
  (interactive "P")
  (if (not kittymacs-terminal-ghostel)
      (eshell arg)
    (condition-case error (ghostel arg)
      (void-function (kittymacs-terminal--without-module error)))))

(defun kittymacs-terminal-project (&optional arg)
  "Open a terminal at the current project's root.  ARG is passed through."
  (interactive "P")
  (if (not kittymacs-terminal-ghostel)
      (kittymacs-eshell-project)
    (condition-case error (ghostel-project arg)
      (void-function (kittymacs-terminal--without-module error)))))

(defun kittymacs-terminal-msys2 (&optional arg)
  "Open an MSYS2 UCRT64 login shell in a terminal.
With prefix ARG, create another one instead of reusing the existing buffer."
  (interactive "P")
  (unless (eq system-type 'windows-nt)
    (user-error "The MSYS2 terminal is for native Windows Emacs"))
  (let ((bash (expand-file-name "usr/bin/bash.exe" kittymacs-msys2-root)))
    (unless (file-executable-p bash)
      (user-error "MSYS2 Bash not found at %s; set `kittymacs-msys2-root' in private.el"
                  bash))
    (let ((ghostel-shell (list bash "--login" "-i"))
          (ghostel-environment (append '("MSYSTEM=UCRT64" "CHERE_INVOKING=1")
                                       ghostel-environment))
          (ghostel-buffer-name "*ghostel: msys2*"))
      (ghostel arg))))

#+end_src

* Integrations with the rest of this configuration

*Projects.* =ghostel-project= opens a terminal at the project root and names it
after the project, so =SPC o p= in any file lands where builds are run. It
joins the menu =C-x p p= offers when you switch project, on =t=; the key is
named here because =ghostel-project= has none in =project-prefix-map=, and
without one the menu shows the entry but cannot run it.

*Consult.* =consult-ghostel= picks a terminal with live preview, the way
=SPC b b= picks a buffer, and creates one when you type a name that does not
exist yet. It lives in ghostel's own repository and is fetched from there, as
above; [[file:60-completion.org][the completion chapter]] has already installed the Consult it needs. =consult-ghostel-history= completes against the *shell's own*
history — bash, zsh, fish and nushell — and types the choice at the prompt
without submitting it, so you can edit before running. Loading it also
teaches =consult-line= about soft-wrapped terminal rows, so a path that wrapped
mid-word is still findable.

#+begin_src emacs-lisp
(when kittymacs-terminal-ghostel
  (with-eval-after-load 'project
    (add-to-list 'project-switch-commands '(ghostel-project "Terminal" ?t) t)))

(use-package consult-ghostel
  :vc (:url "https://github.com/dakra/ghostel"
       :lisp-dir "extensions/consult-ghostel" :rev :newest)
  :if kittymacs-terminal-ghostel
  :after (ghostel consult)
  :demand t
  :bind (:map ghostel-semi-char-mode-map
         ("C-c h" . consult-ghostel-history)))

#+end_src

*Eshell.* [[file:35-shells.org][Eshell]] is a Lisp shell and cannot draw a full-screen program, so it
hands those to a real terminal: the commands in =eshell-visual-commands= (=htop=,
=less=, =vim=, =git log=) open in a ghostel buffer. =ghostel foo= at the Eshell
prompt does the same for anything else, once.

*M-M-x shell and REPLs.* Comint's own colour handling understands the eight
ANSI colours; ghostel's parser understands everything a modern program emits —
true colour, curly and coloured underlines, clickable =OSC 8= links, and the
directory the shell reports. It is a stream filter, not a terminal, so
full-screen programs still belong in =SPC o e=. It needs the native module, so
it is switched on only once that exists; a machine that has never opened a
terminal keeps Emacs's own handling and nothing breaks.

#+begin_src emacs-lisp
(with-eval-after-load 'eshell
  (when (require 'ghostel-eshell nil t)
    (ghostel-eshell-visual-command-mode 1)))

(defun kittymacs-terminal-comint-colours ()
  "Render this comint buffer's output with ghostel's terminal parser."
  (when (and (kittymacs-terminal-module-installed-p)
             (require 'ghostel-comint nil t))
    (ghostel-comint-mode 1)))

(add-hook 'shell-mode-hook #'kittymacs-terminal-comint-colours)

#+end_src

*Compiling.* =ghostel-compile= runs a build in a real terminal and then presents
it as a =compilation-mode= report: coloured output and progress bars while it
runs, =next-error= and clickable file references when it finishes, and =C-c C-j=
mid-run when the command turns out to want an answer. =SPC m t= runs it in any
programming buffer. Emacs's own =compile= is left alone, because it is what
=SPC m c=, Flymake and =project-compile= all go through; put
=(ghostel-compile-global-mode 1)= in =private.el= to route those through the
terminal too.

#+begin_src emacs-lisp
;; `ghostel-recompile' carries no autoload cookie, and `SPC m t' must work
;; before the terminal has ever been opened.
(autoload 'ghostel-compile "ghostel-compile" "Run a command in a terminal." t)
(autoload 'ghostel-recompile "ghostel-compile" "Re-run the last command." t)
(with-eval-after-load 'ghostel
  (require 'ghostel-compile nil t))

;; `kittymacs-define-localleader' replaces a mode's whole map, and prog-mode's
;; belongs to the programming chapter, so add to the map it built.
(when kittymacs-terminal-ghostel
  (with-eval-after-load 'kittymacs-programming
    (when-let* ((map (alist-get 'prog-mode kittymacs-localleader-alist)))
      (keymap-set map "t" (cons "compile in a terminal" #'ghostel-compile))
      (keymap-set map "T" (cons "recompile in a terminal" #'ghostel-recompile))
      (kittymacs-refresh-localleaders))))

#+end_src

*Themes.* Ghostel paints the terminal's sixteen colours from the active theme
and repaints them on Emacs's own =enable-theme-functions=, so =SPC t t= changes
the terminal with everything else. Nothing is needed here.

*Frames.* A terminal is a buffer you work in, so [[file:45-frames.org][frames-only mode]] gives it its
own OS window like any other. =SPC o e= from a second project therefore puts
its terminal beside that project's code, not on top of it.

* Try it

- =SPC o e=, then =htop=. =q= quits it. Now =SPC o e= and =vim=: =ESC= reaches vim,
  because vim is drawing a full screen; =:q= leaves, and =ESC= goes back to
  meaning Meow again.
- Run something long, press =ESC=: output freezes and you are in Normal state.
  Select a line with =x=, copy it with =y=, press =i= to thaw.
- =cd= somewhere in the terminal, then =SPC f f=: Emacs offers files from the
  directory the shell is in.
- Type =ghostel_cmd find-file README.md= in the terminal: Emacs opens the file.
- =SPC o E= lists every terminal with a preview; type a name that does not
  exist and you get a new one.
