#+TITLE: Defaults: files, text, interface and windows
#+FILETAGS: :core:
#+STARTUP: overview
#+PROPERTY: header-args:emacs-lisp :tangle ../lisp/kittymacs-defaults.el :eval never :comments no :padline no :mkdirp yes

- Emacs's out-of-the-box defaults date from another era: backups litter your directories, prompts want the whole word "yes", tabs are eight columns wide and the bell rings.
  + This chapter sets the defaults most people set, and adds a few small helpers the leader menus use.
  + Every chapter writes down only values that differ from Emacs's own: a setting that repeats a default would only make you wonder what it changes.
- Distilled from Lambda-Emacs by Colin McLear: its =lem-setup-settings=, =-buffers=, =-windows=, =-scratch=, =-server= and =-colors= modules.
- All built into Emacs, and it must stay that way: this module loads before =private.el= and host files, too early for anything to choose a package or leave it out.
  + Small packages that extend these settings are in [[id:b9e6e3ce-ecec-4178-933a-234c1349e7de][the basics chapter]].
- Nothing is specific to one machine or operating system.
- Leans on [[id:40302e33-d2b2-4c0b-9bc3-1f9e121307e1][the startup chapter]] for the =var/= directories.

| Area      | What you get                                                         |
|-----------+----------------------------------------------------------------------|
| Files     | saved while idle, backups and auto-saves out of sight, no lock files |
| Text      | spaces not tabs, four wide, eighty columns, UTF-8                    |
| Interface | =y= or =n=, no bell, no dialog boxes, smooth scrolling               |
| Undo      | about 16 MB per buffer, one edit per step                            |
| Windows   | undo layouts, move with Shift and the arrow keys                     |
| Repeat    | =C-x o o o=: one key repeats a command that has a repeat map         |
| Scratch   | survives restarts                                                    |
| Server    | =emacsclient= opens files in this Emacs                              |

* The kittymacs options

- Every option this configuration defines is in the =kittymacs= group or a subgroup of it.
  + =M-x customize-group RET kittymacs= lists them all in one place.
- The group is defined here because this module loads first, before any chapter adds an option.

#+begin_src emacs-lisp
;;; kittymacs-defaults.el --- Sane defaults -*- lexical-binding: t; -*-
;; Generated from literate/25-defaults.org; edit the Org source, then tangle.

;; Distilled from Lambda-Emacs by Colin McLear (GPL-3.0-or-later).

;;; Code:
(defgroup kittymacs nil
  "Options of the kittymacs Emacs configuration."
  :group 'emacs
  :prefix "kittymacs-")

#+end_src

* Where Emacs keeps its state

- Everything Emacs writes on its own (backups, history, caches, saved customizations) lives under =var/=, which Git ignores.
  + [[id:40302e33-d2b2-4c0b-9bc3-1f9e121307e1][The startup chapter]] defines the directories; the copies here apply only when this module is loaded on its own.
  + Two subdirectories separate throwaway caches (=var/cache/=) from state you might back up (=var/etc/=).
- The Customize file is state, not cache: preferences set through =M-x customize= persist there across restarts.
- Only its /name/ is decided here; =init.el= loads the file last, after every chapter has run.
  + The chapters set many of the same options with =setopt= and =use-package … :custom=, and whichever runs last wins.
  + So Customize always has the final word; [[id:40302e33-d2b2-4c0b-9bc3-1f9e121307e1][the startup chapter]] shows where.

#+begin_src emacs-lisp
;; The directories are defined in early-init.el (see the startup chapter);
;; these defaults only apply when a module is loaded on its own.
(defvar kittymacs-lisp-dir (expand-file-name "lisp/" user-emacs-directory))
(defvar kittymacs-var-dir (expand-file-name "var/" user-emacs-directory))
(defvar kittymacs-cache-dir (expand-file-name "cache/" kittymacs-var-dir))
(defvar kittymacs-etc-dir (expand-file-name "etc/" kittymacs-var-dir))

(dolist (directory (list kittymacs-var-dir kittymacs-cache-dir kittymacs-etc-dir))
  (make-directory directory t))

(setopt custom-file (expand-file-name "custom.el" kittymacs-etc-dir))

#+end_src

* Responsiveness

- Emacs runs Lisp and redraws on one thread, so anything slow here freezes typing.
- Redisplay favours input:
  + it skips fontifying while keys are waiting, and scrolling does not fontify text it passes over;
  + paragraphs are always left to right, which saves the bidirectional scan (right-to-left text displays with less accurate ordering);
  + font caches are not compacted during garbage collection, which matters with icon fonts;
  + the region shows only in the selected window (=highlight-nonselected-windows=).
- =read-process-output-max= reads 1 MB at a time, so an agent or language server needs fewer trips through the process filter.
  + =process-adaptive-read-buffering= is off, so Emacs does not delay reads from a process that sends small chunks.
- Auto-revert relies on file notifications: =auto-revert-avoid-polling= stops the stat of every buffer on each tick, and the interval only serves buffers without a watch.
  + A file on a network mount that another machine changes may revert late or not at all.

#+begin_src emacs-lisp
(setopt read-process-output-max (* 1024 1024)
        fast-but-imprecise-scrolling t
        redisplay-skip-fontification-on-input t
        highlight-nonselected-windows nil)
(setq process-adaptive-read-buffering nil
      inhibit-compacting-font-caches t
      bidi-inhibit-bpa t)
(setq-default bidi-paragraph-direction 'left-to-right)

#+end_src

* Files, saving and backups

- Backups and auto-save files go under the cache, not beside your files.
  + Backups are numbered copies, the newest ten kept, files under version control included.
- =auto-save-visited-mode= saves the file itself after 15 idle seconds: crashes lose little, and you rarely think about saving.
- Lock files are off: they confuse tools that watch a directory, and this is a single-user setup.
- =savehist= remembers minibuffer history across sessions.
- =so-long= keeps Emacs responsive when a file has enormous lines.
- Smaller choices:
  + files always end with a newline;
  + the large-file warning starts at 100 MB;
  + Emacs quits without asking about running processes;
  + a symlink visits its target (=find-file-visit-truename=);
  + read-only files open in =view-mode=.

#+begin_src emacs-lisp
(setopt require-final-newline t
        large-file-warning-threshold 100000000
        confirm-kill-processes nil
        find-file-visit-truename t
        view-read-only t)

(let ((backups (expand-file-name "backup/" kittymacs-cache-dir))
      (auto-saves (expand-file-name "auto-save/" kittymacs-cache-dir)))
  (make-directory backups t)
  (make-directory auto-saves t)
  (setopt backup-directory-alist `(("." . ,backups))
          auto-save-file-name-transforms `((".*" ,auto-saves t))
          auto-save-list-file-prefix (expand-file-name ".saves-" auto-saves)))
(setopt backup-by-copying t
        version-control t
        delete-old-versions t
        kept-new-versions 10
        kept-old-versions 0
        vc-make-backup-files t
        create-lockfiles nil)
(setopt auto-save-visited-interval 15)
(auto-save-visited-mode 1)

(setopt savehist-file (expand-file-name "savehist" kittymacs-cache-dir))
(savehist-mode 1)
(global-so-long-mode 1)
(setopt multisession-directory (expand-file-name "multisession/" kittymacs-cache-dir))

#+end_src

* Text and indentation

- Spaces, not tabs, four columns wide; lines wrapped at eighty.
  + All three are /buffer-local/ options: each buffer can have its own value, and =setopt= sets the default new buffers start with.
- =TAB= indents, or completes if the line is already indented.
- Sentences end with one space.
- UTF-8 everywhere.
- =subword-mode= lets word commands stop inside =CamelCase=.
- =visual-line-mode= wraps long lines at the window edge instead of scrolling sideways.
- The mark rings keep eight entries.

#+begin_src emacs-lisp
(setopt indent-tabs-mode nil
        tab-width 4
        fill-column 80
        tab-always-indent 'complete
        completion-cycle-threshold 3
        sentence-end-double-space nil
        global-mark-ring-max 8
        mark-ring-max 8)
(prefer-coding-system 'utf-8)
(global-subword-mode 1)
(global-visual-line-mode 1)

#+end_src

* The interface

- Prompts take =y= or =n=, always in the minibuffer: even a command started from the mouse never opens an operating-system dialog box.
- No bell, no blinking cursor.
- Line numbers, when shown, are relative and count screen lines; the fringe is one pixel on the left.
- Scrolling moves one line at a time, keeping a small margin; the mouse wheel never accelerates.
- The window under the mouse pointer is selected.
- Buffers visiting same-named files are told apart by their directory.
- Files changed on disk are reloaded automatically, without asking; so are non-file buffers such as Dired.
- A right click opens a context menu.
- A buffer that is not visiting a file still picks a major mode by its name.
  + =kittymacs-guess-major-mode= must be a named function, not a lambda: =get-buffer-create= copies the default into the new buffer's =major-mode= without calling it, and everything that inspects a mode expects a symbol there.

#+begin_src emacs-lisp
(setopt use-short-answers t
        use-file-dialog nil
        use-dialog-box nil
        ring-bell-function #'ignore
        display-line-numbers-type 'visual
        display-line-numbers-width-start t)
(blink-cursor-mode -1)
;; Builds without a window system (some CI Emacsen) have no fringe.el.
(when (fboundp 'fringe-mode)
  (fringe-mode '(1 . 0)))

(setopt scroll-step 1
        scroll-margin 3
        scroll-conservatively 101
        scroll-up-aggressively 0.01
        scroll-down-aggressively 0.01
        auto-window-vscroll nil
        hscroll-step 1
        hscroll-margin 1
        mouse-wheel-progressive-speed nil
        mouse-wheel-scroll-amount '(1 ((shift) . 2))
        mouse-autoselect-window t)
(context-menu-mode 1)

(setopt uniquify-buffer-name-style 'reverse
        uniquify-separator " • "
        uniquify-ignore-buffers-re "^\\*")

(setopt auto-revert-verbose nil
        auto-revert-interval 5
        auto-revert-avoid-polling t
        revert-without-query '(".*")
        global-auto-revert-non-file-buffers t)
(global-auto-revert-mode 1)

;; A buffer that is not visiting a file still picks a major mode by its name.
;; This has to be a named function, not a lambda: `get-buffer-create' copies
;; the default into the new buffer's `major-mode' without calling it, and
;; everything that inspects a mode -- `derived-mode-p', `symbol-name', the
;; `derived-mode-parent' property -- expects to find a symbol there.
(defun kittymacs-guess-major-mode ()
  "Choose a major mode for this buffer, by file name or by buffer name."
  (if buffer-file-name
      (fundamental-mode)
    (let ((buffer-file-name (buffer-name)))
      (set-auto-mode))))
(setopt major-mode #'kittymacs-guess-major-mode)

#+end_src

* Undo

- Undo keeps about 16 MB per buffer, because every buffer's history is scanned on each garbage collection, and no longer groups several edits into one step, which made undoing feel unpredictable.
- Meow's =u= undoes; =U= undoes only inside the selection.

#+begin_src emacs-lisp
(fset 'undo-auto-amalgamate #'ignore)
(setopt undo-limit 16777216
        undo-strong-limit 25165824
        undo-outer-limit 134217728)

#+end_src

* Windows inside a frame

- [[id:f1d045c2-e2dc-4514-ab17-dd982ed6be00][The frames chapter]] makes new editing surfaces separate OS windows; inside one frame you still sometimes split.
- =winner-mode= undoes window arrangements.
- Shift-arrows move between windows; window dividers are ten pixels wide.

#+begin_src emacs-lisp
(winner-mode 1)
(windmove-default-keybindings)
(setopt window-divider-default-right-width 10
        window-divider-default-bottom-width 10)
(window-divider-mode 1)

#+end_src

* Repeating a command with one key

- =repeat-mode= lets a run of related commands take one key each after the first: =C-x o o o= walks the windows, and =C-x u u= undoes twice.
  + A command repeats this way when Emacs or its package gives it a /repeat map/: window and buffer commands, smerge's conflict commands and diff-review's review commands all have one.
  + Each repeat names the keys that continue it in the echo area.
  + The repeat lasts until a key outside the map: =repeat-exit-timeout= stays nil.
- How it meets Meow, whose states [[id:a1607a41-b741-428a-9de3-c16e7c8d3ecc][the editing chapter]] explains:
  + right after a repeatable command, a single letter from that command's repeat map takes priority over Meow, because the repeat state lives in =overriding-terminal-local-map=, which Emacs consults before every other keymap;
  + any other key ends the repeat and does its usual job, so =j= right after =C-c _ n= in a review still runs Meow's =meow-next=;
  + the repeat follows the command, not the keys that ran it, so a command reached through a =SPC m= group repeats in the same way.
- Why on for everyone: [[file:../ARCHITECTURE.md][ARCHITECTURE.md]], "repeat-mode is on".

#+begin_src emacs-lisp
(repeat-mode 1)

#+end_src

* A scratch buffer that survives restarts

- The =*scratch*= buffer is a notepad: killing it only buries it.
- Its text is saved to the cache on exit and whenever Emacs has been idle for five minutes, then restored at the next start.
- =kittymacs-scratch-file= names the file.
- A batch start saves nothing, because nobody wrote in that buffer.
  + =just install= would otherwise leave an empty file, and [[id:0286f652-e861-4e61-9ca6-91e225c8939d][the appearance chapter]] takes a file to mean this person has already started Emacs.

#+begin_src emacs-lisp
(defcustom kittymacs-scratch-file (expand-file-name "scratch" kittymacs-cache-dir)
  "Where the *scratch* buffer's text is kept between sessions."
  :type 'file
  :group 'kittymacs)

(defun kittymacs--bury-scratch ()
  "Bury *scratch* instead of killing it."
  (if (eq (current-buffer) (get-buffer "*scratch*"))
      (progn (bury-buffer) nil)
    t))

(defun kittymacs--save-scratch ()
  "Save the text of *scratch* to `kittymacs-scratch-file', except in batch."
  (unless noninteractive
    (with-current-buffer (get-buffer-create "*scratch*")
      (write-region (point-min) (point-max) kittymacs-scratch-file nil 'quiet))))

(defun kittymacs--restore-scratch ()
  "Restore *scratch* from `kittymacs-scratch-file' when it exists."
  (when (file-readable-p kittymacs-scratch-file)
    (with-current-buffer (get-buffer-create "*scratch*")
      (erase-buffer)
      (insert-file-contents kittymacs-scratch-file))))

(add-hook 'kill-buffer-query-functions #'kittymacs--bury-scratch)
(add-hook 'after-init-hook #'kittymacs--restore-scratch)
(add-hook 'kill-emacs-hook #'kittymacs--save-scratch)
(run-with-idle-timer 300 t #'kittymacs--save-scratch)

#+end_src

* The Emacs server

- The server lets =emacsclient= open files in this instance from a shell or a file manager, which matters when frames are your windows.
- It starts whenever Emacs has a display or runs as a daemon, unless a server is already running.
  + A daemon gets one again from Emacs itself after =init.el=, because =startup.el= starts the server of every =--daemon= and =--fg-daemon=. This start only comes first.
- A server that cannot start warns, and the rest of =init.el= goes on, because an error here would stop it.
  + The socket lives in =$XDG_RUNTIME_DIR/emacs/= when the session sets that variable, and a Unix socket's name has a limit of about 108 bytes. A longer one makes both =server-running-p= and =server-start= signal =Service name too long=.
  + Then it tries once more in =emacs<uid>= under =TMPDIR= or =/tmp=, which is =server.el='s own choice for =server-socket-dir= without =XDG_RUNTIME_DIR=. =emacsclient= looks there too when the first socket is missing.
  + Any other error, or a second failure, is a warning that names the error and the directory.
  + A daemon on such a directory now starts on the shorter one, where before it stopped at this error.

#+begin_src emacs-lisp
(defvar server-socket-dir)
(declare-function server-running-p "server" (&optional name))

(defun kittymacs--server-start ()
  "Start the server unless one is running, and warn if it cannot.
A socket name the system finds too long gets one more try where `server.el'
puts the socket without `XDG_RUNTIME_DIR'."
  (let ((start (lambda () (unless (server-running-p) (server-start))))
        (warn (lambda (err)
                (display-warning
                 'kittymacs
                 (format "The Emacs server did not start in %s, so emacsclient cannot reach this Emacs: %s"
                         server-socket-dir (error-message-string err))))))
    (condition-case err
        (funcall start)
      (error
       (if (not (string-search "too long" (error-message-string err)))
           (funcall warn err)
         (setq server-socket-dir (expand-file-name (format "emacs%d" (user-uid))
                                                   (or (getenv "TMPDIR") "/tmp")))
         (condition-case err
             (funcall start)
           (error (funcall warn err))))))))

(when (or window-system (daemonp))
  (require 'server)
  (setopt server-client-instructions nil)
  (kittymacs--server-start))

#+end_src

* Cycling through your own buffers

- =SPC [= and =SPC ]= are Emacs's =previous-buffer= and =next-buffer=: they step through the buffers this window has shown.
- Buffers whose names start with =*= or a space are Emacs's own (=*Messages*=, =*Help*=, the home page), not ones you opened.
  + =switch-to-prev-buffer-skip-regexp= makes Emacs step over them.
- The option also applies when Emacs picks a window's buffer by itself, such as after you kill the one it showed: what appears is something you were working on.
- When nothing else is left, Emacs still shows one of its own buffers.

#+begin_src emacs-lisp
(setopt switch-to-prev-buffer-skip-regexp "\\`[ *]")

#+end_src

* Whether a buffer is remote
:PROPERTIES:
:ID: 8a8dfffa-09f1-454a-8888-cd2f08ccdf9b
:END:

- =kittymacs-remote-buffer-p= says whether this buffer's directory is on another machine.
  + [[id:8d3b7e15-6f42-4c09-a1e8-5b2d90c7f364][The remote chapter's guards]] put it in front of functions that would reach that machine with nobody asking.
- It lives here, not in the remote chapter, because modules that load earlier use it too.
  + The look advises doom-modeline with it, and smooth scrolling asks it on every wheel event.
  + When it lived in the remote chapter, a file visited before that chapter loaded ran the look's advice before the predicate existed, and a first install of a package from Git failed half done.
  + This module loads first, so the predicate exists before anything can call it.
- It never connects: =file-remote-p= with no second argument only reads the name.
- It ignores its arguments, so it can stand in front of any function as advice.

#+begin_src emacs-lisp
(defun kittymacs-remote-buffer-p (&rest _)
  "Return non-nil if this buffer's directory is on another machine.
This never connects.  The arguments are ignored, so it can stand in front of any
function as advice."
  (file-remote-p default-directory))

#+end_src

* Small helpers

- Commands the leader menus use:
  + =kittymacs-new-buffer= :: an empty =untitled= buffer in the default major mode; with a prefix argument, in a new frame;
  + =kittymacs-copy-file-name= :: shows this buffer's file name and copies it to the kill ring.

#+begin_src emacs-lisp
(defun kittymacs-new-buffer (&optional frame)
  "Create an empty buffer; with FRAME (prefix argument), show it in a new frame."
  (interactive "P")
  (let ((buffer (generate-new-buffer "untitled")))
    (with-current-buffer buffer
      (funcall (default-value 'major-mode)))
    (if frame
        (display-buffer buffer '(display-buffer-pop-up-frame))
      (switch-to-buffer buffer))))

(defun kittymacs-copy-file-name ()
  "Show this buffer's file name and copy it to the kill ring."
  (interactive)
  (if-let* ((name (buffer-file-name)))
      (let ((short (abbreviate-file-name name)))
        (message "%s" short)
        (kill-new short))
    (user-error "This buffer is not visiting a file")))

(provide 'kittymacs-defaults)

#+end_src

* Check

- Open a file, edit, wait five seconds: it is saved; =C-x C-s= is rarely needed.
- =M-x customize-variable RET fill-column=, set and save: the value persists in =var/etc/custom.el=.
- =M-x split-window-below= (=C-x 2= makes a frame while frames-only mode is on), then =C-c <left>=: winner brings the old layout back.
- =SPC [= and =SPC ]= cycle your own buffers, skipping =*Messages*=.
- With two windows: =C-x o o= moves to the second and back, and the echo area names =o= as the key that continues.
- Type in =*scratch*=, restart Emacs: the text is still there.
- =just test-packages= runs the startup verifier, which loads this module with the rest and fails on any warning.
