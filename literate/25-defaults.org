* What this gives you

Emacs's out-of-the-box defaults date from another era: backups litter your
directories, prompts want the whole word "yes", tabs are eight columns wide
and the bell rings. This chapter sets the defaults most people set, keeps all
of Emacs's own state files under =var/= so the repository stays clean, and
adds a few small helpers the leader menus use. Only values that differ from
Emacs's own are written down, here and in every chapter: a setting that
repeats a default would only make you wonder what it changes.

* The kittymacs options

Every option this configuration defines belongs to the =kittymacs= group, or
to a smaller group inside it, so =M-x customize-group RET kittymacs= lists
them all in one place. The group is defined here because this module loads
first, before any chapter adds an option to it.

#+begin_src emacs-lisp
(defgroup kittymacs nil
  "Options of the kittymacs Emacs configuration."
  :group 'emacs
  :prefix "kittymacs-")

#+end_src

* Where Emacs keeps its state

Everything Emacs writes on its own (backups, history, caches, saved
customizations) lives under =var/=, which Git ignores; [[file:10-startup.org][the startup chapter]]
defines the three directories. Two subdirectories separate throwaway caches
from state you might back up. The Customize file is state, not cache:
preferences you set through =M-x customize= persist there across restarts.

Only the file's /name/ is decided here. The file itself is loaded at the very
end of =init.el=, after every chapter has run, because the chapters set many
of the same options with =setopt= and =use-package ... :custom=, and whichever
setting runs last wins. Loading your saved choices last means Customize
always has the final word; [[file:10-startup.org][the startup chapter]] shows where.

#+begin_src emacs-lisp
;; The three directories are defined in early-init.el (see the startup chapter);
;; these defaults only apply when a module is loaded on its own.
(defvar kittymacs-var-dir (expand-file-name "var/" user-emacs-directory))
(defvar kittymacs-cache-dir (expand-file-name "cache/" kittymacs-var-dir))
(defvar kittymacs-etc-dir (expand-file-name "etc/" kittymacs-var-dir))

(dolist (directory (list kittymacs-var-dir kittymacs-cache-dir kittymacs-etc-dir))
  (make-directory directory t))

(setopt custom-file (expand-file-name "custom.el" kittymacs-etc-dir))

#+end_src

* Files, saving and backups

Backups and auto-save files go under the cache instead of beside your files.
=auto-save-visited-mode= saves the file itself after a few idle seconds, so
crashes lose little and you rarely think about saving. Lock files are off:
they confuse tools that watch a directory, and this is a single-user setup.
=savehist= remembers minibuffer history across sessions, and =so-long=
keeps Emacs responsive when a file has enormous lines.

#+begin_src emacs-lisp
(setopt require-final-newline t
        large-file-warning-threshold 100000000
        confirm-kill-processes nil
        find-file-visit-truename t
        view-read-only t)

(let ((backups (expand-file-name "backup/" kittymacs-cache-dir))
      (auto-saves (expand-file-name "auto-save/" kittymacs-cache-dir)))
  (make-directory backups t)
  (make-directory auto-saves t)
  (setopt backup-directory-alist `(("." . ,backups))
          auto-save-file-name-transforms `((".*" ,auto-saves t))
          auto-save-list-file-prefix (expand-file-name ".saves-" auto-saves)))
(setopt backup-by-copying t
        version-control t
        delete-old-versions t
        kept-new-versions 10
        kept-old-versions 0
        vc-make-backup-files t
        create-lockfiles nil)
(auto-save-visited-mode 1)

(setopt savehist-file (expand-file-name "savehist" kittymacs-cache-dir))
(savehist-mode 1)
(global-so-long-mode 1)
(setopt multisession-directory (expand-file-name "multisession/" kittymacs-cache-dir))

#+end_src

* Text and indentation

Spaces, not tabs, four columns wide, and lines wrapped at eighty. The first
three are /buffer-local/ options: every buffer can have its own value, and
=setopt= sets the default that each new buffer starts with. =TAB=
indents and, if the line is already indented, completes. Sentences end with
one space. UTF-8 everywhere. =subword-mode= lets word commands stop inside
=CamelCase=, and =visual-line-mode= wraps long lines at the window edge
instead of scrolling sideways.

#+begin_src emacs-lisp
(setopt indent-tabs-mode nil
        tab-width 4
        fill-column 80
        tab-always-indent 'complete
        completion-cycle-threshold 3
        sentence-end-double-space nil
        global-mark-ring-max 8
        mark-ring-max 8)
(prefer-coding-system 'utf-8)
(global-subword-mode 1)
(global-visual-line-mode 1)

#+end_src

=ws-butler= keeps whitespace tidy: it removes trailing whitespace only on
lines you changed, so a commit never touches lines you did not edit.

#+begin_src emacs-lisp
(use-package ws-butler
  :ensure t
  :hook ((text-mode prog-mode) . ws-butler-mode))

#+end_src

* The interface

Answer prompts with =y= or =n=, always in the minibuffer: even a command
started from the mouse never opens an operating-system dialog box. No bell,
no blinking cursor, and the mouse pointer hides while you type. Scrolling moves one line at a time and keeps a
small margin. Buffers visiting files with the same name are told apart by
their directory, files change on disk are reloaded automatically, and a
right click opens a context menu.

#+begin_src emacs-lisp
(setopt use-short-answers t
        use-file-dialog nil
        use-dialog-box nil
        ring-bell-function #'ignore
        display-line-numbers-type 'visual
        display-line-numbers-width-start t)
(blink-cursor-mode -1)
;; Builds without a window system (some CI Emacsen) have no fringe.el.
(when (fboundp 'fringe-mode)
  (fringe-mode '(1 . 0)))

(setopt scroll-step 1
        scroll-margin 3
        scroll-conservatively 101
        scroll-up-aggressively 0.01
        scroll-down-aggressively 0.01
        auto-window-vscroll nil
        hscroll-step 1
        hscroll-margin 1
        mouse-wheel-progressive-speed nil
        mouse-wheel-scroll-amount '(1 ((shift) . 2))
        mouse-autoselect-window t)
(context-menu-mode 1)

(setopt uniquify-buffer-name-style 'reverse
        uniquify-separator " • "
        uniquify-ignore-buffers-re "^\\*")

(setopt auto-revert-verbose nil
        auto-revert-interval 0.5
        revert-without-query '(".*")
        global-auto-revert-non-file-buffers t)
(global-auto-revert-mode 1)

;; A buffer that is not visiting a file still picks a major mode by its name.
;; This has to be a named function, not a lambda: `get-buffer-create' copies
;; the default into the new buffer's `major-mode' without calling it, and
;; everything that inspects a mode -- `derived-mode-p', `symbol-name', the
;; `derived-mode-parent' property -- expects to find a symbol there.
(defun kittymacs-guess-major-mode ()
  "Choose a major mode for this buffer, by file name or by buffer name."
  (if buffer-file-name
      (fundamental-mode)
    (let ((buffer-file-name (buffer-name)))
      (set-auto-mode))))
(setopt major-mode #'kittymacs-guess-major-mode)

#+end_src

Undo is unlimited in practice, and Emacs no longer groups several edits into
one undo step, which made undoing feel unpredictable. Meow's =u= undoes and
=U= undoes only inside the selection. When you have undone past a fork,
=SPC b u= draws the undo history as a tree: =f= and =b= move along it, =n=
and =p= change branch, =RET= keeps the state under point.

#+begin_src emacs-lisp
(fset 'undo-auto-amalgamate #'ignore)
(setopt undo-limit 67108864
        undo-strong-limit 100663296
        undo-outer-limit 1006632960)

(use-package vundo
  :ensure t
  :commands vundo
  :custom
  (vundo-glyph-alist vundo-unicode-symbols)
  (vundo-compact-display t)
  :config
  (with-eval-after-load 'meow
    (add-to-list 'meow-mode-state-list '(vundo-mode . motion))))

#+end_src

* Windows inside a frame

[[file:45-frames.org][The frames chapter]] makes new editing surfaces separate OS windows. Inside
one frame you still sometimes split. =winner-mode= undoes window
arrangements, =ace-window= jumps to a window by letter, and Shift-arrows move
between windows. Popper collects transient buffers such as help and
compilation output so one key toggles them; the frames chapter decides where
they appear.

#+begin_src emacs-lisp
(winner-mode 1)
(windmove-default-keybindings)
(setopt window-divider-default-right-width 10
        window-divider-default-bottom-width 10)
(window-divider-mode 1)

(use-package ace-window
  :ensure t
  :commands (ace-window ace-swap-window aw-flip-window))

(use-package popper
  :ensure t
  :demand t
  :bind (("M-`" . popper-toggle)
         ("C-`" . popper-cycle)
         ("C-M-`" . popper-toggle-type))
  :custom
  (popper-window-height 20)
  (popper-group-function #'popper-group-by-directory)
  (popper-reference-buffers
   '("\\*Messages\\*"
     "Output\\*$"
     "\\*Async Shell Command\\*"
     help-mode
     compilation-mode))
  :config
  (popper-mode 1)
  (popper-echo-mode 1))

#+end_src

* A scratch buffer that survives restarts

The =*scratch*= buffer is a notepad. Killing it only buries it, and its text
is saved to the cache on exit and every five minutes, then restored at the
next start. =kittymacs-scratch-file= names the file.

#+begin_src emacs-lisp
(defcustom kittymacs-scratch-file (expand-file-name "scratch" kittymacs-cache-dir)
  "Where the *scratch* buffer's text is kept between sessions."
  :type 'file
  :group 'kittymacs)

(defun kittymacs--bury-scratch ()
  "Bury *scratch* instead of killing it."
  (if (eq (current-buffer) (get-buffer "*scratch*"))
      (progn (bury-buffer) nil)
    t))

(defun kittymacs--save-scratch ()
  "Save the text of *scratch* to `kittymacs-scratch-file'."
  (with-current-buffer (get-buffer-create "*scratch*")
    (write-region (point-min) (point-max) kittymacs-scratch-file nil 'quiet)))

(defun kittymacs--restore-scratch ()
  "Restore *scratch* from `kittymacs-scratch-file' when it exists."
  (when (file-exists-p kittymacs-scratch-file)
    (with-current-buffer (get-buffer-create "*scratch*")
      (erase-buffer)
      (insert-file-contents kittymacs-scratch-file))))

(add-hook 'kill-buffer-query-functions #'kittymacs--bury-scratch)
(add-hook 'after-init-hook #'kittymacs--restore-scratch)
(add-hook 'kill-emacs-hook #'kittymacs--save-scratch)
(run-with-idle-timer 300 t #'kittymacs--save-scratch)

#+end_src

* The Emacs server

Running Emacs as a server lets =emacsclient= open files in this instance from
a shell or a file manager, which matters when frames are your windows. It
starts whenever Emacs has a display or runs as a daemon.

#+begin_src emacs-lisp
(when (or window-system (daemonp))
  (require 'server)
  (setopt server-client-instructions nil)
  (unless (server-running-p)
    (server-start)))

#+end_src

* Cycling through your own buffers

=SPC [= and =SPC ]= are Emacs's =previous-buffer= and =next-buffer=: they
step through the buffers this window has shown. Buffers whose names start
with =*= or a space are Emacs's own (=*Messages*=, =*Help*=, the home page)
rather than ones you opened, and =switch-to-prev-buffer-skip-regexp= tells
Emacs to step over them. The same option applies whenever Emacs picks a
buffer for a window by itself, for example after you kill the one it
showed, so what appears is something you were working on. When nothing
else is left, Emacs still shows one of its own buffers rather than nothing.

#+begin_src emacs-lisp
(setopt switch-to-prev-buffer-skip-regexp "\\`[ *]")

#+end_src

* Small helpers

Commands the leader menus use, and =rainbow-mode=, which colours colour
names in place.

#+begin_src emacs-lisp
(defun kittymacs-new-buffer (&optional frame)
  "Create an empty buffer; with FRAME (prefix argument), show it in a new frame."
  (interactive "P")
  (let ((buffer (generate-new-buffer "untitled")))
    (with-current-buffer buffer
      (funcall (default-value 'major-mode)))
    (if frame
        (display-buffer buffer '(display-buffer-pop-up-frame))
      (switch-to-buffer buffer))))

(defun kittymacs-copy-file-name ()
  "Show this buffer's file name and copy it to the kill ring."
  (interactive)
  (if-let* ((name (buffer-file-name)))
      (let ((short (abbreviate-file-name name)))
        (message "%s" short)
        (kill-new short))
    (user-error "This buffer is not visiting a file")))

(use-package rainbow-mode
  :ensure t
  :commands rainbow-mode)

(provide 'kittymacs-defaults)

#+end_src

* Try it

- Open a file, edit, wait five seconds: it is saved. =C-x C-s= is rarely needed.
- =M-x customize-variable RET fill-column=: the value persists in =var/etc/custom.el=.
- Split with =C-x 2=, then =C-c <left>= (winner) brings the old layout back.
- =M-`= toggles the last popup; =SPC [= and =SPC ]= cycle your own buffers.
