- Fonts, theme, mode line, icons and highlights:
  + Google Sans Code with Nerd Font icons when it is installed, the platform font otherwise;
  + by default the built-in Modus theme and Emacs's own mode line, with a light theme one toggle away (=SPC t t=);
  + with the =doom-look= feature, the Sonokai theme, tracked in this repository, and a compact mode line from =doom-modeline=;
  + icons in completion, Corfu and Dired that switch off automatically when the icon font is missing, so a fresh machine never shows boxes.
- Loads before anything is drawn, so the first frame already has the right font and colours; leans only on [[id:3fd783cd-deb8-48aa-bb44-0d9b16535365][the defaults chapter]].
- Four features live here, each behind a =when=: =icons=, =doom-look=, =ui-polish= and =focus-mode=, with their keys.
  + Without them the chapter still sets the fonts, spacing and tab bar, and loads a theme.
- The font and theme choices are the user's; the highlighting defaults are distilled from Lambda-Emacs by Colin McLear (=lem-setup-theme=, =-fonts=, =-faces=).

* What you can change

- Set these with =setopt= in =private.el=; the chapter reads them while it loads.
  + =kittymacs-font-family= :: the editing font, =GoogleSansCode Nerd Font=; the platform default if it is absent.
  + =kittymacs-font-size= :: the editing size in points, =14=.
  + =kittymacs-prose-font-family= :: the proportional font Org sets prose in, =Google Sans Flex=; the platform's sans if it is absent.
  + =kittymacs-nerd-font= :: the icon font, =Symbols Nerd Font Mono=.
  + =kittymacs-icons= :: =auto= (a graphical frame and an installed icon font), =t= for a terminal set up with a Nerd Font, or =nil= for no icons.
  + =kittymacs-theme= :: the dark theme, =doom-sonokai=; without =doom-look= a =doom-= theme gives way to the built-in =modus-vivendi=.
  + =kittymacs-light-theme= :: the other theme =SPC t t= toggles to, =doom-one-light=; without =doom-look= a =doom-= theme gives way to =modus-operandi=.
  + =kittymacs-line-numbers-in-programming= :: line numbers in programming buffers, =t=.

* Fonts

- The editing font is resolved by family, including the shorter name Windows registers for the same font (=GoogleSansCode NF=), then the plain font, =Google Sans Code=.
  + Older nixpkgs ships only the plain font; nothing is lost, since icons come from the icon font below, not the editing font.
- Icons come from a single patched font that =nerd-icons= maps onto its own code points.
  + Mapping only those ranges keeps ordinary Unicode in the editing font.
- Symbols fall back to a platform symbol font: Segoe UI Symbol, Symbola, Apple Symbols or Symbol, the first one installed.
- Prose has its own font, Google Sans Flex, the proportional counterpart of the editing font: it is the =variable-pitch= face, which [[id:8ff7e58e-c155-4513-99ae-3b2c3a6ab729][the Org chapter]] sets prose in.
  + Without it, =variable-pitch= keeps Emacs's own choice, the platform's sans, so a fresh machine still gets proportional prose.
- =fixed-pitch= is the editing font too.
  + Its default family is a generic =Monospace=, so code kept fixed inside proportional prose would otherwise change font.
- Neither face gets a height: both follow =default=, so =C-x C-+= grows prose and code together.
- Fonts are applied to every new frame, which matters when Emacs runs as a daemon.
- A little extra line spacing; =C-x C-+= grows the text 8% a step, about one point at the default size.

#+begin_src emacs-lisp
(defun kittymacs-resolve-font-family ()
  "Return the installed family for `kittymacs-font-family', or nil."
  (when (display-graphic-p)
    (seq-find (lambda (family) (find-font (font-spec :family family)))
              (if (equal kittymacs-font-family "GoogleSansCode Nerd Font")
                  (list kittymacs-font-family "GoogleSansCode NF" "Google Sans Code")
                (list kittymacs-font-family)))))

(defun kittymacs-resolve-prose-font-family ()
  "Return `kittymacs-prose-font-family' if it is installed, or nil."
  (when (and (display-graphic-p)
             (find-font (font-spec :family kittymacs-prose-font-family)))
    kittymacs-prose-font-family))

(defun kittymacs-icons-available-p ()
  "Return non-nil when Nerd Font icons should be rendered."
  (and (kittymacs-feature-p 'icons)
       (pcase kittymacs-icons
         ('t t)
         ('nil nil)
         ('auto (and (display-graphic-p)
                     (find-font (font-spec :family kittymacs-nerd-font))
                     t)))))

(defun kittymacs--apply-icon-font (&optional frame)
  "Map Nerd icon ranges to `kittymacs-nerd-font' in graphical FRAME."
  (with-selected-frame (or frame (selected-frame))
    (when (kittymacs-icons-available-p)
      (nerd-icons-set-font kittymacs-nerd-font (selected-frame)))))

(defun kittymacs--apply-font (&optional frame)
  "Apply the editing, prose, symbol and icon fonts to FRAME."
  (with-selected-frame (or frame (selected-frame))
    (when (display-graphic-p)
      (when-let* ((family (kittymacs-resolve-font-family)))
        (set-face-attribute 'default (selected-frame) :family family)
        (set-face-attribute 'fixed-pitch (selected-frame) :family family))
      (when-let* ((prose (kittymacs-resolve-prose-font-family)))
        (set-face-attribute 'variable-pitch (selected-frame) :family prose))
      (set-face-attribute 'default (selected-frame) :height (* 10 kittymacs-font-size))
      (when-let* ((symbols (seq-find (lambda (family) (find-font (font-spec :family family)))
                                     '("Segoe UI Symbol" "Symbola" "Apple Symbols" "Symbol"))))
        (set-fontset-font t 'symbol symbols nil))
      (kittymacs--apply-icon-font))))

(setopt line-spacing 0.1
        text-scale-mode-step 1.08)

(when (kittymacs-feature-p 'icons)
  (use-package nerd-icons
    :ensure t
    :demand t
    :custom
    (nerd-icons-font-family kittymacs-nerd-font)))

(add-hook 'after-setting-font-hook #'kittymacs--apply-icon-font)
(add-hook 'after-make-frame-functions #'kittymacs--apply-font)
(kittymacs--apply-font)

#+end_src

* Theme

- With =doom-look= off, as it is by default, the built-in Modus themes show: =modus-vivendi= and, on =SPC t t=, =modus-operandi=.
- With =doom-look= on, Sonokai shows, from a tracked port in =lisp/themes/=, so it does not depend on a package update.
- Loading a theme disables the previous one first, so themes never stack.
  + doom-themes' Org settings are reapplied after each load, while doom-themes is there.
- =SPC t t= toggles between =kittymacs-theme= and =kittymacs-light-theme=; =SPC t T= chooses any theme.
- Anything that must be recomputed when colours change hangs on Emacs's own =enable-theme-functions=.
- The theme loads by itself, not from doom-themes' =:config=, so this section works when doom-themes is absent.
  + A =doom-= theme needs that package, Sonokai's port too, which is what =kittymacs--theme-or-builtin= asks.
  + A theme that still fails to load is a warning, and the rest of the chapter loads.
- The =doom-look= feature gates the =doom-themes= form below and the =doom-modeline= one in [[*Mode line and tabs]], and nothing else has to change; [[file:../tests/kittymacs-theme-tests.el][the theme tests]] run the chapter without them.

#+begin_src emacs-lisp
(setopt custom-safe-themes t)
(add-to-list 'custom-theme-load-path
             (expand-file-name "themes/" (file-name-directory (or load-file-name buffer-file-name))))

(defun kittymacs--theme-or-builtin (theme builtin)
  "Return THEME, or BUILTIN when THEME needs doom-themes and that is not loaded."
  (if (and (string-prefix-p "doom-" (symbol-name theme))
           (not (featurep 'doom-themes)))
      builtin
    theme))

(defun kittymacs--default-theme ()
  "Return the theme to use for `kittymacs-theme'."
  (kittymacs--theme-or-builtin kittymacs-theme 'modus-vivendi))

(defun kittymacs--other-theme ()
  "Return the theme to use for `kittymacs-light-theme'."
  (kittymacs--theme-or-builtin kittymacs-light-theme 'modus-operandi))

(defun kittymacs-load-theme (theme)
  "Disable active themes and load THEME."
  (mapc #'disable-theme custom-enabled-themes)
  (load-theme theme t)
  (when (featurep 'doom-themes)
    (doom-themes-org-config)))

(defun kittymacs-toggle-theme ()
  "Toggle between `kittymacs-theme' and `kittymacs-light-theme'."
  (interactive)
  (kittymacs-load-theme (if (memq (kittymacs--default-theme) custom-enabled-themes)
                            (kittymacs--other-theme)
                          (kittymacs--default-theme))))

(keymap-set kittymacs-toggle-map "t" (cons "light/dark theme" #'kittymacs-toggle-theme))
(keymap-set kittymacs-toggle-map "T" (cons "choose theme" #'load-theme))

(when (kittymacs-feature-p 'doom-look)
  (use-package doom-themes
    :ensure t
    :custom
    (doom-themes-enable-bold t)
    (doom-themes-enable-italic t)))

(condition-case-unless-debug err
    (kittymacs-load-theme (kittymacs--default-theme))
  (error
   (display-warning 'kittymacs
                    (format "Theme %s did not load: %s"
                            (kittymacs--default-theme) (error-message-string err))
                    :error)))

* Mode line and tabs

- By default the frame has Emacs's own mode line.
- With =doom-look= off, the routine minor modes collapse into one =…=.
  + A new reader cannot act on =WK=, =ElDoc= or =Wrap=, and that list hid what they can act on.
  + Emacs's own =mode-line-collapse-minor-modes= does it, so this adds no package.
  + What stays visible changes what keys do or reports a problem: the Meow state, =overwrite-mode=, a keyboard macro in progress, Flymake's counts, and envrc.
  + envrc stays only while it has something to say: =none= hides, and =on=, =error= and =denied= show.
  + Clicking the =…= lists the hidden modes, and =SPC h m= describes every mode that is on.
  + A value set in =private.el= or Customize wins.
- With =doom-look= on, =doom-modeline= is compact and shows the Meow state; its icons follow =kittymacs-icons=.
  + Nothing else here refers to it, so turning the feature off is all it takes to get the built-in one back.
  + Its language version stays off in a remote buffer ([[id:8d3b7e15-6f42-4c09-a1e8-5b2d90c7f364][the guards]]): finding it searches the remote project, and it runs the local program, so it would be slow and wrong. The guard is here because only this declaration may name the package.
- The built-in tab bar appears once a second workspace exists and borrows the mode line's faces.
- =SPC t H= hides the current buffer's mode line with =hide-mode-line-mode=, handy for a screenshot or a presentation; pressing it again brings it back.

* The first words in the scratch buffer

- With =home-page= off, nothing else greets a new reader: the first frame is an empty =*scratch*=.
- A comment there says to press =SPC= for the menu and =SPC C o= to choose features.
- Only the first start shows it, so the text never replaces anything a person wrote:
  + a file at =kittymacs-scratch-file= means Emacs has started before, and [[id:3fd783cd-deb8-48aa-bb44-0d9b16535365][the defaults chapter]] restores that text;
  + clearing the comment stays cleared, because the empty buffer saves to that file too.
- A value set in =private.el= wins.
- Flyspell checks comments, and =SPC= is no word, so it would underline the first thing a reader sees.
  + =flyspell-incorrect-hook= lets one function accept what Flyspell found.
  + Only the pointer's own line in =*scratch*= passes, so =SPC= stays a misspelling everywhere else, and a dictionary gains nothing.
  + The hook stays on after a first start, because the kept comment comes back from the scratch file.

#+begin_src emacs-lisp
(defconst kittymacs--scratch-pointer ";; SPC opens the menu.  SPC C o chooses features."
  "The line that tells a new reader where the menu is.")

(unless (or (kittymacs-feature-p 'home-page)
            initial-scratch-message
            (file-exists-p kittymacs-scratch-file))
  (setq initial-scratch-message (concat kittymacs--scratch-pointer "\n\n")))

(defun kittymacs--scratch-pointer-word-p (start _end _corrections)
  "Return non-nil when the word at START is on the pointer's line in *scratch*.
A function on `flyspell-incorrect-hook': non-nil leaves the word unmarked."
  (and (equal (buffer-name) "*scratch*")
       (save-excursion
         (goto-char start)
         (equal (buffer-substring-no-properties (pos-bol) (pos-eol))
                kittymacs--scratch-pointer))))
(add-hook 'flyspell-incorrect-hook #'kittymacs--scratch-pointer-word-p)

#+end_src

* Check

- =SPC t t= flips to the light theme and back; colours never mix.
- =SPC t w= in an Org file hides everything but the text; =SPC t w= again brings it back.
- =SPC t H= hides only the mode line.
- =C-x C-+= grows the text one step; =C-x C-0= resets.
- =SPC f f=: icons beside the candidates, or none at all on a machine without the icon font.
- Set =kittymacs-icons= to =nil= in =private.el= to run without icon fonts.
- =just test-packages=: the verifier toggles the theme both ways and checks that Sonokai comes back alone, and that =doom-modeline-mode= is on.
- =just test-packages= and =just test-minimal=: =kittymacs-check-first-look= fails if the collapse follows anything but =doom-look=, or the =*scratch*= comment anything but =home-page=.
  + Batch =format-mode-line= returns nothing, so it reads the option that decides; look at a real frame for the text.
- =just test-minimal=: the same verifier checks that Modus comes back alone, and that neither doom package loaded.
  + The theme tests leave out doom-themes and doom-modeline, and check that the Modus themes load and toggle instead.
- =just test-packages=: where Hunspell has a dictionary, the theme tests run real Flyspell over =*scratch*=, and only a =SPC= outside the pointer gets marked.
