- Five small packages that extend [[id:3fd783cd-deb8-48aa-bb44-0d9b16535365][the defaults]].
- They live apart because the defaults load before =private.el= and host files, too early for anything to choose a package or leave it out.
  + So this module loads right after them, and every package here can be a choice in [[id:3f8a6c02-9d14-4b7e-a2c5-1e7d90b64f31][the catalogue]].
- The undo tree and whitespace cleanup are in the =minimal= profile; =window-picker=, =popups= and =color-names= each sit behind a =when=, with their keys.
- Distilled from Lambda-Emacs by Colin McLear: its =lem-setup-windows= and =-colors= modules.
- [[id:f1d045c2-e2dc-4514-ab17-dd982ed6be00][The frames chapter]] decides where popups appear.

* Whitespace

- =ws-butler= keeps whitespace tidy: it removes trailing whitespace only on lines you changed, so a commit never touches lines you did not edit.

#+begin_src emacs-lisp
(use-package ws-butler
  :ensure t
  :hook ((text-mode prog-mode) . ws-butler-mode))

#+end_src

* The undo tree :meow:
:PROPERTIES:
:ID: 808d7464-14c2-42c5-865e-c08e17141ae2
:END:

- After undoing past a fork, =SPC b u= draws the history as a tree (Vundo).
- Vundo's buffer starts in Motion state, so its own keys work; it has no =SPC m= menu.

| Key        | In the tree                |
|------------+----------------------------|
| =f=, =b=   | move along it              |
| =n=, =p=   | change branch              |
| =RET=      | keep the state under point |

#+begin_src emacs-lisp
(use-package vundo
  :ensure t
  :commands vundo
  :custom
  (vundo-glyph-alist vundo-unicode-symbols)
  (vundo-compact-display t)
  :config
  (with-eval-after-load 'meow
    (add-to-list 'meow-mode-state-list '(vundo-mode . motion))))

(keymap-set kittymacs-buffer-map "u" (cons "undo tree" #'vundo))

#+end_src

* Windows and popups

- =ace-window= jumps to a window by letter on =SPC w w=, and swaps two windows on =SPC w s=.
- Popper collects transient buffers under one toggle key:
  + =*Messages*=, =*Async Shell Command*=, any buffer ending in =Output*=, Help and compilation buffers;
  + grouped by directory, twenty lines high.

| Key     | Popper                              |
|---------+-------------------------------------|
| =M-`=   | show or hide the last popup         |
| =C-`=   | cycle through popups                |
| =C-M-`= | turn a buffer into a popup, or back |

** Window keys follow frames-only mode :decision:
:PROPERTIES:
:ID: 6f2c41d8-93a5-4e07-b1c2-8d5e70a4f913
:END:

- [[id:f1d045c2-e2dc-4514-ab17-dd982ed6be00][Frames-only mode]] gives each OS window one Emacs window, so a key that picks, swaps or pops up a window has little to act on while it is on.
  + One machine may run it and another not: a tiling window manager wants frames, while under [[id:86fcd506-34c8-476d-8903-acbef46275bf][EXWM]] Emacs arranges its own windows.
  + =SPC t f= turns it on and off in a running session, so the keys follow the mode itself, not the option it started from.
- So each key does the nearest useful thing while the mode is on, and its usual thing while it is off:

| Key       | Frames-only mode off      | Frames-only mode on                                     |
|-----------+---------------------------+---------------------------------------------------------|
| =SPC w w= | jump to a window by letter | jump to a frame by name                                |
| =SPC w s= | swap two windows          | says that the window manager arranges frames            |
| =M-`= and the other Popper keys | Popper | unbound, since Popper's display control is off then |

- The two =SPC w= keys check the mode as they run, so they never need rebinding.
- Popper's keys live in a keymap of their own whose switch follows the mode: =frames-only-mode-hook= sets it whenever the mode changes.
  + This chapter loads before the frames chapter, so the switch starts on and the frames chapter's start of the mode turns it off.

#+begin_src emacs-lisp
(defun kittymacs-frames-only-p ()
  "Return non-nil while frames-only mode is on."
  (bound-and-true-p frames-only-mode))

(when (kittymacs-feature-p 'window-picker)
  (use-package ace-window
    :ensure t
    :commands (ace-window ace-swap-window aw-flip-window))

  (defun kittymacs-window-jump ()
    "Jump to a window by letter, or to a frame by name in frames-only mode."
    (interactive)
    (if (kittymacs-frames-only-p)
        (call-interactively #'select-frame-by-name)
      (call-interactively #'ace-window)))

  (defun kittymacs-window-swap ()
    "Swap two windows; in frames-only mode, say that there are none to swap."
    (interactive)
    (if (kittymacs-frames-only-p)
        (user-error "Frames-only mode is on, so the window manager arranges frames; SPC t f turns it off")
      (call-interactively #'ace-swap-window)))

  (keymap-set kittymacs-window-map "w" (cons "jump to window" #'kittymacs-window-jump))
  (keymap-set kittymacs-window-map "s" (cons "swap windows" #'kittymacs-window-swap)))

(defvar kittymacs-popper-keys-on t
  "Non-nil while Popper's keys are bound: whenever frames-only mode is off.")

(defvar kittymacs-popper-keys-map (make-sparse-keymap)
  "Popper's keys, live while `kittymacs-popper-keys-on' is non-nil.")

(defun kittymacs--popper-keys-follow-frames ()
  "Turn Popper's keys off while frames-only mode is on, and on otherwise."
  (setq kittymacs-popper-keys-on (not (kittymacs-frames-only-p))))

(when (kittymacs-feature-p 'popups)
  (keymap-set kittymacs-popper-keys-map "M-`" #'popper-toggle)
  (keymap-set kittymacs-popper-keys-map "C-`" #'popper-cycle)
  (keymap-set kittymacs-popper-keys-map "C-M-`" #'popper-toggle-type)
  (add-to-list 'minor-mode-map-alist (cons 'kittymacs-popper-keys-on kittymacs-popper-keys-map))
  (add-hook 'frames-only-mode-hook #'kittymacs--popper-keys-follow-frames)
  (kittymacs--popper-keys-follow-frames)

  (use-package popper
    :ensure t
    :demand t
    :custom
    (popper-window-height 20)
    (popper-group-function #'popper-group-by-directory)
    (popper-reference-buffers
     '("\\*Messages\\*"
       "Output\\*$"
       "\\*Async Shell Command\\*"
       help-mode
       compilation-mode))
    :config
    (popper-mode 1)
    (popper-echo-mode 1)))

#+end_src

* Colour names

- =rainbow-mode= colours colour names in place; =SPC t r= turns it on in a buffer.

#+begin_src emacs-lisp
(when (kittymacs-feature-p 'color-names)
  (use-package rainbow-mode
    :ensure t
    :commands rainbow-mode)

  (keymap-set kittymacs-toggle-map "r" (cons "colour names" #'rainbow-mode)))

(provide 'kittymacs-basics)

#+end_src

* Check

- Add spaces to the end of a line you edited, wait to save: they are gone, and untouched lines keep theirs.
- Undo a few edits, make a new one, then =SPC b u=: the tree shows the fork.
- =SPC w w= with several windows in a frame: each gets a letter.
- =M-`= toggles the last popup.
- =SPC t r= in a buffer that names a colour: the name shows in that colour.
