* What this gives you

*Eshell* is a shell written in Lisp: it runs ordinary programs, but =cd=, =ls= and
friends are Lisp, so you can call Emacs commands from the prompt (=ff file.txt=
opens a file) and complete with the same machinery as everywhere else. What it
cannot do is draw a full-screen program, so it hands those to [[file:34-terminal.org][the terminal]] —
=htop=, =less= and =git log= open there and behave. Tramp opens files on remote
machines over SSH as if they were local.

Programs such as =git log= and =man= send long output through a /pager/ like
=less=, which waits for keys and redraws the screen. In Eshell or =M-x shell=
the output lands in an ordinary Emacs buffer that you can already scroll and
search, so the pager only gets in the way. Emacs 30's =comint-pager= tells
those shells, and only them, to set =PAGER=cat= for the programs they start;
Eshell honours the same option. A real terminal from [[file:34-terminal.org][the terminal chapter]]
keeps your usual pager, because there =less= works as it does anywhere else.

* The environment on Linux and macOS

A graphical Emacs started from a launcher does not run your shell's
profile, so =PATH= can be wrong. =exec-path-from-shell= copies the
variables from your shell: =PATH= and =MANPATH=, the locale, and the two
variables the =nix= commands read. On Linux it asks a plain non-interactive
shell, which reads =~/.zshenv= or =$BASH_ENV=. On macOS it asks a login shell,
because that is where the system's =path_helper= and Homebrew's =shellenv=
line in =~/.zprofile= run; the startup chapter already put Homebrew on
=exec-path= so this import only refines it.

Two platforms keep the environment Emacs inherited, and the =:if= line means
the package is not even installed there. On Windows the importer would ask
PowerShell to evaluate POSIX shell syntax, which it cannot, and Windows
programs inherit a correct environment anyway. Android is excluded for the
opposite reason: the import would succeed, and that is the problem.
=/system/bin/sh= evaluates the POSIX syntax quite happily and reports a =PATH=
that has never heard of Termux, replacing the entries [[file:30-platform.org][the platform chapter]]
has just added.

#+begin_src emacs-lisp
(use-package exec-path-from-shell
  :ensure t
  :if (not (memq system-type '(windows-nt android)))
  :custom
  (exec-path-from-shell-variables '("PATH" "MANPATH" "LANG" "NIX_PATH" "NIX_PROFILES"))
  (exec-path-from-shell-arguments (and (eq system-type 'darwin) '("-l")))
  :config
  (when (or window-system (daemonp))
    (exec-path-from-shell-initialize)))

#+end_src

* Eshell

History and the last-directory ring persist under =var/etc/eshell/=.
Completion ignores case and cycles. Programs that need a terminal run in one,
because [[file:34-terminal.org][the terminal chapter]] turns on
=ghostel-eshell-visual-command-mode=. The prompt shows the directory, the Git
branch when there is one, and a =λ= on its own line so long paths do not
squeeze your command.

#+begin_src emacs-lisp
(defvar kittymacs-eshell-dir (expand-file-name "eshell/" kittymacs-etc-dir)
  "Directory for Eshell history, aliases and the directory ring.")

(setopt eshell-directory-name kittymacs-eshell-dir
        eshell-history-file-name (expand-file-name "history" kittymacs-eshell-dir)
        eshell-last-dir-ring-file-name (expand-file-name "lastdir" kittymacs-eshell-dir)
        eshell-aliases-file (expand-file-name "alias" kittymacs-eshell-dir)
        eshell-buffer-maximum-lines 20000
        eshell-scroll-to-bottom-on-input 'all
        eshell-scroll-to-bottom-on-output 'all
        eshell-list-files-after-cd nil
        eshell-cmpl-ignore-case t
        eshell-cmpl-cycle-completions t
        eshell-history-size 10000
        eshell-hist-ignoredups t
        eshell-glob-case-insensitive t
        eshell-error-if-no-glob t
        eshell-destroy-buffer-when-process-dies t
        eshell-banner-message ""
        eshell-highlight-prompt t
        eshell-prompt-regexp "^λ ")

(with-eval-after-load 'em-term
  (dolist (command '("htop" "top" "less" "more" "vim" "nano" "ssh" "tail"))
    (add-to-list 'eshell-visual-commands command))
  (add-to-list 'eshell-visual-subcommands '("git" "log" "diff" "show")))

(defun kittymacs--eshell-git-branch ()
  "Return the current Git branch for the prompt, or nil."
  (when (and (not (file-remote-p default-directory))
             (locate-dominating-file default-directory ".git"))
    (car (vc-git-branches))))

(defun kittymacs-eshell-prompt ()
  "A two-line prompt: directory and branch, then λ."
  (let ((branch (kittymacs--eshell-git-branch)))
    (concat "\n"
            (propertize (abbreviate-file-name (eshell/pwd)) 'face 'font-lock-constant-face)
            (when branch (propertize (format " (%s)" branch) 'face 'font-lock-comment-face))
            "\n"
            (propertize "λ" 'face 'font-lock-keyword-face)
            (propertize " " 'face 'default))))
(setopt eshell-prompt-function #'kittymacs-eshell-prompt)

#+end_src

Aliases are Lisp-defined so they are versioned with this file. =ff= opens
a file, =d= a directory in Dired, =gs= Magit status, =up= a parent
directory. =z= jumps to any directory you have visited, with completion.

#+begin_src emacs-lisp
(defvar kittymacs-eshell-aliases
  '(("g" "git --no-pager $*")
    ("gs" "magit-status")
    ("gd" "git diff --color $*")
    ("gl" "git log --oneline -20")
    ("l" "ls $*")
    ("la" "ls -la $*")
    ("ll" "ls -lah $*")
    ("d" "dired $1")
    ("ff" "find-file $1")
    ("e" "find-file $1")
    ("fr" "consult-recent-file")
    ("bb" "consult-buffer")
    ("pp" "project-switch-project")
    ("up" "eshell-up $1")
    ("q" "exit")
    ("x" "exit"))
  "Eshell aliases defined in Lisp.")

(with-eval-after-load 'em-alias
  (advice-add #'eshell-write-aliases-list :override #'ignore)
  (setq eshell-command-aliases-list (append eshell-command-aliases-list kittymacs-eshell-aliases)))

(defun eshell/z (&optional regexp)
  "Change to a previously visited directory chosen with completion.
With REGEXP, go to the most recent directory matching it."
  (let ((dirs (delete-dups (mapcar #'abbreviate-file-name (ring-elements eshell-last-dir-ring)))))
    (eshell/cd (if regexp
                   (eshell-find-previous-directory regexp)
                 (completing-read "Directory: " dirs nil t)))))

(defun kittymacs-eshell-clear ()
  "Clear the Eshell buffer."
  (interactive)
  (let ((inhibit-read-only t))
    (erase-buffer)
    (eshell-send-input)))

(defun kittymacs-eshell-project ()
  "Open an Eshell for the current project, or for this directory."
  (interactive)
  (require 'eshell)
  (let* ((root (if-let* ((project (project-current))) (project-root project) default-directory))
         (name (file-name-nondirectory (directory-file-name root)))
         (eshell-buffer-name (format "*eshell: %s*" name))
         (default-directory root))
    (eshell)))

(defun kittymacs--eshell-setup ()
  "Per-buffer Eshell settings."
  (keymap-local-set "C-l" #'kittymacs-eshell-clear)
  (setq-local imenu-generic-expression '(("Prompt" "^λ \\(.*\\)" 1)))
  (hl-line-mode -1)
  (visual-line-mode 1))
(add-hook 'eshell-mode-hook #'kittymacs--eshell-setup)

(use-package eshell-syntax-highlighting
  :ensure t
  :after eshell
  :config
  (eshell-syntax-highlighting-global-mode 1))

(use-package eshell-up
  :ensure t
  :commands eshell-up
  :config
  (defalias 'eshell/up #'eshell-up))

(use-package esh-help
  :ensure t
  :after eshell
  :config
  (setup-esh-help-eldoc))

(use-package pcmpl-args :ensure t :after eshell)

* Meow in shells

Shells start in Insert state: the keys belong to the prompt, and =SPC= types
a space. Press =ESC= to enter Normal state and use the selection grammar on
the output; the leader is available there, and =SPC m= offers the shell's
own menu. =C-c C-SPC= reaches the leader without leaving Insert.

#+begin_src emacs-lisp
(with-eval-after-load 'meow
  (dolist (entry '((eshell-mode . insert) (shell-mode . insert) (term-mode . insert)))
    (add-to-list 'meow-mode-state-list entry)))

(kittymacs-define-localleader 'eshell-mode
  "c" (cons "clear" #'kittymacs-eshell-clear)
  "h" (cons "history" #'consult-history)
  "d" (cons "directory" #'consult-dir)
  "p" (cons "previous prompt" #'eshell-previous-prompt)
  "n" (cons "next prompt" #'eshell-next-prompt)
  "i" (cons "insert" #'meow-insert)
  "?" (cons "menu" #'casual-eshell-tmenu))

(provide 'kittymacs-shell)

#+end_src

* Try it

- =SPC o s= opens an Eshell for this project; =SPC o e= opens a real terminal.
- =M-x eshell=, type =ff init.el=: the file opens. =z= then pick a directory.
- Type =htop= in Eshell: it opens in a terminal buffer and works.
- =ESC= in Eshell, select some output with =x=, =y= copies it; =i= goes back to typing.
