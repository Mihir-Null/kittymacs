#+TITLE: The SPC tree
#+FILETAGS: :keys:
#+STARTUP: overview
#+PROPERTY: header-args:emacs-lisp :tangle ../lisp/kittymacs-keys.el :eval never :comments no :padline no :mkdirp yes

- Every group directly under =SPC=, in one place, so you can see the tree without reading each chapter.
- The tables list keys from every chapter; the code here binds only what no feature owns.
  + A key that belongs to a feature is in that feature's chapter, so a feature that is off has no keys.
  + What stays here runs Emacs's own commands, or a command of a module that always loads.
- The vocabulary follows Spacemacs and Doom, which most Meow and Evil users already know:
  + a letter for each area;
  + the same letter twice for the most common action in that area.
- Leans on [[id:e5942eb0-4389-447d-9317-d9178adcaaae][the leader]] for the mechanism and the empty groups.
  + [[id:a1607a41-b741-428a-9de3-c16e7c8d3ecc][The editing chapter]] explains when =SPC= is live; [[file:../lisp/keybindings.org][the cheat sheet]] prints the tree on one page.

* How to read and change the tree

- Each group is a keymap that [[id:e5942eb0-4389-447d-9317-d9178adcaaae][the leader]] defines, empty.
- A definition of the form =(cons "label" #'command)= is an ordinary Emacs menu item: the label is what which-key prints.
- To add a key, use =keymap-set= on the group map or on =kittymacs-leader-map= itself.
  + In the chapter of the feature it belongs to, or in =private.el= inside its =after-init-hook= function: =private.el= loads before the chapters.
- =SPC u= is a group reserved for your own keys.

#+begin_src emacs-lisp :tangle no
(keymap-set kittymacs-user-map "g" (cons "magit status" #'magit-status))
#+end_src

* Seeing the next keys

- which-key is built into Emacs.
- It pops up the next keys at the top of the frame after a short pause (0.45 s); =C-h= inside any prefix shows them at once.

#+begin_src emacs-lisp
(setopt which-key-idle-delay 0.45
        which-key-idle-secondary-delay 0.05
        which-key-show-early-on-C-h t
        which-key-side-window-location 'top
        which-key-side-window-max-height 0.5)
(which-key-mode 1)

#+end_src

* Projects, version control, windows, workspaces

| Prefix  | Group           | Doubled key             | Also                                                                          |
|---------+-----------------+-------------------------+-------------------------------------------------------------------------------|
| =SPC p= | project         | =p= open in a workspace | every =C-x p= key, =G= Magit status, =C= recompile, =E= direnv                |
| =SPC j= | jump            | =j= to character (Avy)  | =l= line, =w= word, =s= symbol                                                |
| =SPC v= | version control | (=s= status)            | =d= diff, =l= log, =b= blame, =c= commit, =?= all commands                    |
| =SPC w= | windows         | =w= jump to window      | =n= new frame, =k= close frame, =h= / =v= split, =u= / =U= undo / redo layout |
| =SPC W= | workspaces      | (=TAB= switch)          | =s= switch or create, =o= open project, =d= close                             |

- Windows are frames here: =SPC w n= makes a new OS window.
  + =SPC w h= and =SPC w v= are bound to Emacs's own split commands, which [[id:f1d045c2-e2dc-4514-ab17-dd982ed6be00][the frames chapter]] turns into frame creation while frames-only mode is on, so they make a new OS window too.
  + With the mode off (=SPC t f=) they split the current frame.
- Only =SPC w w= and =SPC w s= need a package, so the rest of =SPC w= stays here.

* Check

- =SPC= in a Normal-state buffer, then wait: which-key lists the groups by label at the top of the frame.
- =SPC f f= finds a file; =SPC b b= switches buffer: the doubled key is the common action.
- =SPC p f= in a project: Emacs's own =project-find-file=, inherited from =C-x p=.
- =SPC /= or =SPC h l=: Emacs's help view of the whole tree, plus this buffer's =SPC m= menu.
- =i=, then =C-c C-SPC=: the same tree from Insert state.
- =just test-packages=: the verifier fails if any key under =SPC= runs something that is not a command, and checks =SPC l e=, =SPC s l=, =SPC h ?= and =SPC h h=.
