#+TITLE: Org-roam: scoped linked notes
#+FILETAGS: :notes:
#+STARTUP: overview
#+PROPERTY: header-args:emacs-lisp :tangle ../lisp/kittymacs-org-roam.el :eval never :comments no :padline no :mkdirp yes

- Linked notes under =SPC n=, one graph at a time: your personal notes and each project's documentation are separate graphs with separate indexes, so a search from a project file never turns up your diary.
- Leans on [[id:afa6b7fd-742a-4c15-86a6-32e3e8027b0e][the platform chapter]] for the personal graph's folder, [[id:3fd783cd-deb8-48aa-bb44-0d9b16535365][the defaults chapter]] for the cache, [[id:e5942eb0-4389-447d-9317-d9178adcaaae][the leader]] for =SPC m= and [[id:f1d045c2-e2dc-4514-ab17-dd982ed6be00][the frames chapter]] for where notes open; [[id:53ad53ed-155f-47dc-973d-7be18de2893c][the keys chapter]] binds =SPC n=.
- The inbox and agenda of [[id:8ff7e58e-c155-4513-99ae-3b2c3a6ab729][the Org chapter]] are unaffected: they keep their own files and templates.
- kittymacs' own chapters are a project graph: [[id:7edccfdc-3c38-489a-bc9e-4c002b432ab4][the conventions]] show it in use.
- Read [[*One graph at a time]] first; the rest follows from it.

* One graph at a time :concept:
:PROPERTIES:
:ID: bf28bf5d-a667-4ea9-afa5-9a80072be8b6
:END:

- Every =SPC n= command works on the current buffer's graph:

| Key       | Does                                                  |
|-----------+-------------------------------------------------------|
| =SPC n f= | find a note                                           |
| =SPC n i= | insert a link to one                                  |
| =SPC n c= | capture a new one                                     |
| =SPC n b= | show which notes link to one                          |
| =SPC n s= | bring the index up to date; =C-u SPC n s= rebuilds it |
| =SPC n t= | find a note by choosing a tag first                   |
| =SPC n T= | list every tag with its notes                         |

- A graph is a folder of Org files plus its index, a SQLite database kept by Org-roam, the package underneath.
  + =org-roam-directory= names the folder, =org-roam-db-location= the database file.
- Upstream expects one global pair; this chapter lets a buffer have its own.
- Two kinds of graph:
  + the /personal graph/ is =kittymacs-org-roam-directory=, by default the Org directory of [[id:afa6b7fd-742a-4c15-86a6-32e3e8027b0e][the platform chapter]];
  + a /project graph/ is a repository whose =.dir-locals.el= says so ([[*Project graphs]]).

* Indexing on demand, not at startup :decision:
:PROPERTIES:
:ID: 5110d6d4-9701-4a67-8913-698477cd0461
:END:

- Nothing here scans notes or opens a database at startup.
  + Upstream's =org-roam-db-autosync-mode= stays off: switching it on rebuilds the whole index on the spot.
- The first =SPC n s= in a graph builds its index; after that, saving a note updates its entry.
  + =SPC n s= is needed again only after changes outside Emacs: edits, renames and deletions.
- The graph commands need an Emacs built with SQLite; without it they say so, and ordinary Org editing works as before.

* Where a graph's index lives :decision:
:PROPERTIES:
:ID: a35554bc-3310-4f65-9226-0254223eadc7
:END:

- Every database lives outside its graph, in =org-roam/= under =kittymacs-cache-dir=.
  + Project checkouts never contain generated files.
  + Read-only graphs can still be indexed.
- A database's file name is a hash of the graph's /real/ path:
  + =file-truename= resolves symbolic links;
  + on a file system that ignores letter case (the default on macOS and Windows) the path is also lower-cased.
- So two spellings of one folder, such as =~/notes= and a symbolic link to it, share one database; two worktrees of one repository are different folders with different databases.
- An alias =file-truename= cannot see through, such as an NTFS junction on Windows or a bind mount, looks like another folder and gets its own cache.
  + That costs a second index, not correctness; if it matters, open the graph through one path.
- =kittymacs--org-roam-root= is that resolution.
  + It runs once, when a buffer's graph is decided ([[*Which graph a buffer uses]]); its paths are then used as they are, so no SQL query pays to resolve them again.
- =kittymacs-org-roam-db-path= is public so you can compute a database path yourself, for example to open it with the =sqlite3= program.
- The last two forms give upstream's variables global values describing the personal graph, before Org-roam loads.
  + =defvar= does nothing to a variable that already has a value, so an =org-roam-directory= set in =private.el= stays.
  + Setting =kittymacs-org-roam-directory= (with =setopt=, in =private.el=) is better: it also gets resolved.

#+begin_src emacs-lisp
;;; kittymacs-org-roam.el --- Scoped linked notes -*- lexical-binding: t; -*-
;; Generated from literate/71-org-roam.org; edit the Org source, then tangle.

;;; Code:

(require 'cl-lib)
(require 'org)
(require 'org-id)
(require 'kittymacs-leader)

;; Defined by the defaults and platform chapters, which init.el loads first.
(defvar kittymacs-cache-dir)
(defvar kittymacs-org-directory)

(defgroup kittymacs-org-roam nil
  "Linked notes, one graph at a time."
  :group 'kittymacs)

(defcustom kittymacs-org-roam-directory kittymacs-org-directory
  "Root of the personal Org-roam graph.
The chapter reads it while it loads, so set it with `setopt' in private.el."
  :type 'directory
  :group 'kittymacs-org-roam)

(defun kittymacs--org-roam-root (directory)
  "Return DIRECTORY as an absolute directory name with links resolved."
  (file-name-as-directory (file-truename (expand-file-name directory))))

(defun kittymacs-org-roam-db-path (root)
  "Return the database file for the graph at ROOT, inside the user cache.
The name is a hash of ROOT's real path, lower-cased on a file system
that ignores case, so every spelling of one directory shares one file."
  (let ((identity (kittymacs--org-roam-root root)))
    (when (file-name-case-insensitive-p identity)
      (setq identity (downcase identity)))
    (expand-file-name (concat (secure-hash 'sha256 identity) ".sqlite")
                      (expand-file-name "org-roam/" kittymacs-cache-dir))))

(defvar org-roam-directory (kittymacs--org-roam-root kittymacs-org-roam-directory))
(defvar org-roam-db-location (kittymacs-org-roam-db-path org-roam-directory))

#+end_src

* Which graph a buffer uses

- A buffer's /scope/ is a list of three values: the graph's root, its database, and the regular expressions that keep files out of it ([[*Which files are notes]]).
- =kittymacs--org-roam-scope= decides it for the =SPC n= commands, in this order:
  1. A graph already set in the buffer, remembered by the variable =kittymacs--org-roam-graph=.
  2. A graph named by the buffer's own variables: the project flag ([[*Project graphs]]), or a buffer-local =org-roam-directory=.
     + Its database is a buffer-local =org-roam-db-location= if any, otherwise the cache path for that root.
  3. The personal graph.
- Before returning it, the function checks what a command needs: SQLite, a root that exists, and a database outside the root.
  + A command failing a check stops with a message and changes nothing: it never creates a graph folder or an empty database for a missing folder.
  + The same check protects =C-u SPC n s=, which deletes the database before rebuilding it.

** Project graphs :concept:
:PROPERTIES:
:ID: f70b8ad9-3c6c-4260-9b95-86b27ea8d985
:END:

- A repository becomes a graph of its own with a =.dir-locals.el= at its root. EmptyNet ships exactly this one:

#+begin_src emacs-lisp :tangle no
((nil . ((kittymacs-org-roam-project . t)
         (kittymacs-org-roam-excluded-directories . ("secrets" "tools" "web" ".github")))))
#+end_src

- kittymacs' own checkout has the same kind of file, leaving out =var/=, =tests/=, =tools/=, =lisp/= and =.github/= ([[id:7edccfdc-3c38-489a-bc9e-4c002b432ab4][the conventions]]).
- =kittymacs-org-roam-project= says "the folder holding this file is a graph root".
  + Emacs already knows that folder: applying directory locals, it records them in =dir-local-variables-alist=, and =dir-locals-find-file= returns the folder whose =.dir-locals.el= it read.
  + The database is the cache path for that root; add =org-roam-db-location= to the same file to choose another.
- =kittymacs-org-roam-excluded-directories= replaces the default exclusions for this graph only.
- Both are declared safe for their types (a boolean, a list of strings): Emacs applies them without asking, and nothing in the file is evaluated.
  + An Emacs without kittymacs does not know them: the first time it opens a file there it asks whether to apply them; =i= ignores them for good. They do nothing in that Emacs either way.
- Emacs reads only the nearest =.dir-locals.el= above a file.
  + A subfolder with its own hides the root's: its files leave the project graph unless that file repeats the flag, which makes the subfolder a graph of its own.
- A project may instead set =org-roam-directory= and =org-roam-db-location= directly in its directory locals, as upstream documents.
  + That still works, through rule 2 of [[*Which graph a buffer uses]].
  + Emacs asks before applying those two: upstream does not declare them safe.
  + Write the directory as its real absolute path: Org-roam reads the value in files it opens by itself.

** Setting and restoring a buffer's graph

- =kittymacs--org-roam-set-scope= writes a scope into a buffer:
  + it sets the three upstream variables buffer-locally, so Org-roam's own functions agree with this chapter's;
  + in an Org buffer it adds the save hook of [[*Keeping the index current]].
- Buffer-local variables do not last: every major mode starts by clearing them, and so does reverting a file.
- =kittymacs--org-roam-restore= puts the graph back.
  + It runs from =hack-local-variables-hook=, which Emacs runs after applying a file's local and directory-local variables: when a file is visited, whenever a major mode starts in it, and after a revert.
  + So it always sees the project flag.
- In an Org buffer it first decides the graph afresh: the buffer's own variables, then the personal graph if the file lies inside it.
- Otherwise, and in any buffer that is not Org, it restores the graph set before, if any.
  + So a note =SPC n f= opened from a graph stays in that graph, and the backlinks panel keeps its graph.
  + A note never given a graph belongs to none; its saves touch no database.
- The same hook runs in the buffers Org-roam opens by itself to read notes during a sync, because upstream calls =hack-local-variables= there.
  + So a project's notes are read into its database even in a sync started with Org-roam's own =M-x org-roam-db-sync=.
- =kittymacs--org-roam-graph= is /permanent-local/: it survives the clearing, as a restore needs.
  + A file's own variables are asked first, so its value is still replaced when they name a different graph: editing =.dir-locals.el= and reverting a note moves the note to the new graph.

#+begin_src emacs-lisp
(defcustom kittymacs-org-roam-project nil
  "Non-nil in a directory's .dir-locals.el to make that directory a graph root."
  :type 'boolean
  :safe #'booleanp
  :group 'kittymacs-org-roam)

(defcustom kittymacs-org-roam-excluded-directories '(".git" ".cache" "cache" "caches")
  "Folder names whose contents are never notes, at any depth of a graph.
A project graph sets its own list in its .dir-locals.el."
  :type '(repeat string)
  :safe #'list-of-strings-p
  :group 'kittymacs-org-roam)

(defvar org-roam-file-exclude-regexp)

(defvar-local kittymacs--org-roam-graph nil
  "This buffer's graph as a list (ROOT DB EXCLUDE), or nil.")
(put 'kittymacs--org-roam-graph 'permanent-local t)

(defun kittymacs--org-roam-project-root ()
  "Return the directory whose .dir-locals.el set `kittymacs-org-roam-project'."
  (when (alist-get 'kittymacs-org-roam-project dir-local-variables-alist)
    (let ((found (dir-locals-find-file (or buffer-file-name default-directory))))
      (if (consp found) (car found) found))))

(defun kittymacs--org-roam-named-graph ()
  "Return the graph that this buffer's own variables name, or nil."
  (when-let* ((directory (or (kittymacs--org-roam-project-root)
                             (and (local-variable-p 'org-roam-directory)
                                  org-roam-directory))))
    (let ((root (kittymacs--org-roam-root directory)))
      (list root
            (if (local-variable-p 'org-roam-db-location)
                (expand-file-name org-roam-db-location)
              (kittymacs-org-roam-db-path root))
            (kittymacs--org-roam-exclusions kittymacs-org-roam-excluded-directories)))))

(defun kittymacs--org-roam-personal-graph ()
  "Return the personal graph, from the global values of its variables."
  (list (kittymacs--org-roam-root (default-value 'org-roam-directory))
        (expand-file-name (default-value 'org-roam-db-location))
        (kittymacs--org-roam-exclusions
         (default-value 'kittymacs-org-roam-excluded-directories))))

(defun kittymacs--org-roam-scope ()
  "Return the graph for a command in this buffer, or explain why there is none."
  (unless (sqlite-available-p)
    (user-error "Org-roam needs an Emacs built with SQLite support"))
  (let ((scope (or kittymacs--org-roam-graph
                   (kittymacs--org-roam-named-graph)
                   (kittymacs--org-roam-personal-graph))))
    (pcase-let ((`(,root ,db) scope))
      (unless (file-directory-p root)
        (user-error "Org-roam graph does not exist: %s" root))
      (when (file-in-directory-p db root)
        (user-error "Org-roam database %s is inside its graph; see kittymacs-org-roam-db-path"
                    db)))
    scope))

(defun kittymacs--org-roam-set-scope (scope)
  "Make SCOPE this buffer's graph, for these commands and for Org-roam's own."
  (pcase-let ((`(,root ,db ,exclude) scope))
    (setq-local kittymacs--org-roam-graph scope
                org-roam-directory root
                org-roam-db-location db
                org-roam-file-exclude-regexp exclude))
  (when (derived-mode-p 'org-mode)
    (add-hook 'after-save-hook #'kittymacs--org-roam-save nil t)))

(defun kittymacs--org-roam-restore ()
  "Give this buffer its graph again after its local variables were cleared."
  (when-let* ((scope (or (and (derived-mode-p 'org-mode)
                              (or (kittymacs--org-roam-named-graph)
                                  (and buffer-file-name
                                       (file-in-directory-p buffer-file-name
                                                            org-roam-directory)
                                       (kittymacs--org-roam-personal-graph))))
                         kittymacs--org-roam-graph)))
    (kittymacs--org-roam-set-scope scope)))

#+end_src

* Which files are notes

- Upstream's =org-roam-file-p= decides whether a file is a note: it must lie under the root, have an extension from =org-roam-file-extensions=, and not match =org-roam-file-exclude-regexp=.
  + That last option, a regular expression or a list of them tested against the path relative to the root, is this chapter's extension point.
- =kittymacs--org-roam-exclusions= turns a list of folder names into one more regular expression, added to upstream's own list (by default, Org's attachment folder).
  + The expression matches a folder name as a whole path component, at any depth: with ="cache"= it excludes =cache/a.org= and =notes/cache/b.org= but not =cached.org=.
  + =default-toplevel-value= reads the global value even while a command has bound it, so the list never grows by repeating this chapter's expression.
- Each scope carries its own list and sets it buffer-locally, so every graph has its own exclusions; the personal graph's list comes from the global value of =kittymacs-org-roam-excluded-directories=.
- The default excludes Git's folder and cache folders, which is what a personal notes folder usually contains.
  + Change it for the personal graph with =setopt= in =private.el=; a project sets its list in its =.dir-locals.el=.
- Upstream finds a graph's files with =find=, =fd= or =rg= when one is installed, much faster than walking the folders in Lisp, then filters them through =org-roam-file-p=: the exclusions apply however the files were found.
- Those tools follow symbolic links: a link inside a graph that points outside it brings its target into the graph.
  + That is your choice: a link includes a file on purpose; leaving it out keeps the file out.

#+begin_src emacs-lisp
(defun kittymacs--org-roam-exclusions (directories)
  "Return Org-roam's exclusion regexps plus one matching any of DIRECTORIES.
The new regexp matches a whole folder name at any depth of a path that
is relative to the graph root, which is what `org-roam-file-p' tests."
  (append (ensure-list (default-toplevel-value 'org-roam-file-exclude-regexp))
          (and directories
               (list (concat "\\(?:\\`\\|/\\)" (regexp-opt directories) "/")))))

#+end_src

* Keeping the index current

- =kittymacs--org-roam-call= runs a piece of Org-roam with a scope in effect.
- Setting the three upstream variables in the current buffer is not enough: Org-roam does part of its work in buffers of its own, which see the /global/ values.
  + It opens a note that is not already open in a hidden buffer to read it.
  + It fills temporary buffers for previews.
- A =let= binding changes the global value only where the variable is not buffer-local, so the function binds the variables twice with =cl-progv= (which binds a list of variables to a list of values):
  1. once from a temporary buffer, where they are global;
  2. once in the buffer the command started in.
- Upstream keeps one open database connection per root, in =org-roam-db--connection=, looked up by the root alone.
  + So every buffer of one graph must agree on its database: two databases for one root in one session would quietly share whichever connection opened first.
  + The scope rules ensure that: a root always gets the same cache path unless its own directory locals name another.
- =kittymacs--org-roam-save= runs after a note in a graph is saved and updates its entry.
  + Org-roam records the file name it is given; a sync records real paths, because it lists files under the resolved root.
  + So the function binds =buffer-file-name= to the real path while it runs: a note opened through a symbolic link is recorded under the name a sync would use, not a second time under the link's.
- =kittymacs-org-roam-sync= (=SPC n s=) brings the database up to date; a prefix argument deletes it first.
  + It then copies every node's ID and file into Org's own ID index, =org-id-locations=.
  + That index is separate from Org-roam's and knows nothing about graphs; recording each graph's IDs there lets an =id:= link reach a note in another graph ([[*Links across graphs]]).

** Links across graphs :concept:
:PROPERTIES:
:ID: 0299807f-6a1e-4445-b1c6-1c629d83a677
:END:

- An =id:= link may point at a note in another graph.
  + Org follows it with =org-id-find=; Org-roam puts its own lookup in front of that function with advice, so Org first asks the current graph's database.
  + When the ID is not there, Org's own index answers, so every graph should be synced once.
  + Opening the note gives its buffer the destination's graph, by the rules of [[*Setting and restoring a buffer's graph]].
- Backlinks stay within a graph: the source graph's database records the outgoing link, but not the destination note or the other links to it.
- IDs must be unique across all your graphs.
- When the current graph cannot be used (no SQLite, or the graph's root does not exist), upstream's lookup would fail with an error or create an empty database for a missing folder, breaking ordinary Org links.
  + =kittymacs--org-roam-lookup-p= answers "not here" then, so Org's own index answers alone.

#+begin_src emacs-lisp
(defun kittymacs--org-roam-call (scope function)
  "Call FUNCTION with SCOPE in effect, also in buffers Org-roam opens itself."
  (let ((variables '(org-roam-directory org-roam-db-location org-roam-file-exclude-regexp))
        (origin (current-buffer)))
    (with-temp-buffer
      (cl-progv variables scope
        (with-current-buffer origin
          (cl-progv variables scope
            (funcall function)))))))

(defun kittymacs--org-roam-save ()
  "Update this note's entry in its graph's database, under its real file name."
  (let ((buffer-file-name (file-truename buffer-file-name)))
    (when (and (sqlite-available-p) (org-roam-file-p))
      (kittymacs--org-roam-call kittymacs--org-roam-graph #'org-roam-db-update-file))))

(defun kittymacs-org-roam-sync (&optional force)
  "Bring this graph's database up to date and record its IDs for Org.
With a prefix argument FORCE, delete the database and build it again."
  (interactive "P")
  (kittymacs--org-roam-call
   (kittymacs--org-roam-scope)
   (lambda ()
     (org-roam-db-sync force)
     (dolist (row (org-roam-db-query [:select [id file] :from nodes]))
       (org-id-add-location (car row) (cadr row)))
     (org-id-locations-save))))

(defun kittymacs--org-roam-lookup-p (&rest _)
  "Whether Org-roam can answer an ID lookup in this buffer's graph."
  (and (sqlite-available-p) (file-directory-p org-roam-directory)))

#+end_src

* Capture into the graph you started from

- =SPC n c= always captures; =SPC n f= and =SPC n i= capture when you type a title that is not a note yet.
  + Project graphs do not do the second: their find and insert offer only existing notes, so a typo in a repository's documentation never becomes a new file.
- Before capturing, the command checks the root is writable and shows it.
- Your =org-roam-capture-templates= decide which file in the graph receives the note, as upstream documents.
  + A template writing outside the graph is your choice, like a link.
  + If the file's folder does not exist yet, Emacs asks before creating it when the capture is saved.
- A capture happens in two halves:
  1. the first runs inside the command: Org opens the target file, inserts the template and shows a capture buffer, so the command's scope is still in effect;
  2. the second, =C-c C-c=, runs whenever you finish, from whatever buffer is current, long after the command has returned; Org saves the target file then, and that save must update the graph the capture started in.
- So the first half writes the scope into the buffers themselves:
  + the command binds =kittymacs--org-roam-capture-scope= while it runs;
  + Org turns on =org-capture-mode= in the capture buffer at the end of that half;
  + its hook =kittymacs--org-roam-capture-mode= sees the binding and sets the scope in the capture buffer and in the file's buffer behind it, the capture buffer's /base buffer/.
- The save when you finish then updates that graph, whichever buffer you were in.
- Captures started any other way, such as the Org chapter's inbox capture, find the variable unbound and are left alone.

#+begin_src emacs-lisp
(defvar kittymacs--org-roam-capture-scope nil
  "The graph of the command now starting an Org-roam capture, or nil.
Only `kittymacs--org-roam-capture-node' binds it, while Org sets up the
capture; `kittymacs--org-roam-capture-mode' reads it.")

(defun kittymacs--org-roam-capture-mode ()
  "Give a capture started from a SPC n command the graph of that command.
Set it in the capture buffer and in the file buffer behind it, so the
save that finishes the capture updates that graph's database."
  (when kittymacs--org-roam-capture-scope
    (kittymacs--org-roam-set-scope kittymacs--org-roam-capture-scope)
    (with-current-buffer (buffer-base-buffer)
      (kittymacs--org-roam-set-scope kittymacs--org-roam-capture-scope))))

(defun kittymacs--org-roam-capture-node (scope node &optional props)
  "Capture NODE into the graph SCOPE, passing PROPS to Org-roam."
  (unless (file-writable-p (car scope))
    (user-error "Org-roam capture root is read-only: %s" (car scope)))
  (message "Org-roam capture destination: %s" (car scope))
  (kittymacs--org-roam-call
   scope (lambda ()
           (let ((kittymacs--org-roam-capture-scope scope))
             (org-roam-capture- :node node :props props)))))

#+end_src

* Finding, linking and backlinks

- The commands read a note with upstream's =org-roam-node-read=, inside the scope, with the graph's root in the prompt.
  + Completion may switch buffers while you choose, so each command remembers where it started (the buffer, or for =SPC n i= the exact position) and returns there before acting.
- =SPC n f= opens the note in a buffer given the command's graph, then lets =org-roam-node-open= show it, following the frame policy of [[id:f1d045c2-e2dc-4514-ab17-dd982ed6be00][the frames chapter]].
- =SPC n i= inserts an =id:= link at the remembered position.
  + As with upstream's insert, selected text is kept: it starts the prompt, and the link replacing it shows the same words. Selecting "the build cache" and choosing a note links those words to it.
  + Without a region the link shows the note's title.
  + It also runs =org-roam-post-node-insert-hook=.
- =SPC n b= shows the backlinks panel in a side window on the right of the current frame, a third of its width, one panel per graph.
  + It is about the note at point in an Org buffer; elsewhere it asks for one.
  + Upstream redraws the panel on every refresh, first switching its major mode on again, which clears every buffer-local variable.
  + The panel's graph survives in the permanent =kittymacs--org-roam-graph=; =kittymacs--org-roam-restore= on =org-roam-mode-hook= puts the upstream variables back before the sections query the database.
  + Upstream's own permanent =org-roam-buffer-current-directory= and =org-roam-buffer-current-node= say which note the panel is about.

** What this chapter asks of Org-roam

- The =use-package= block below is the whole connection to Org-roam beyond ordinary function calls: four hooks and one piece of advice.

- =hack-local-variables-hook= (Emacs) :: =kittymacs--org-roam-restore= gives a buffer its graph back after its local variables apply, in notes you open and in the buffers Org-roam opens by itself.
- =org-roam-mode-hook= (Org-roam) :: the same function restores the panel's graph each time the panel is redrawn.
- =org-capture-mode-hook= (Org) :: =kittymacs--org-roam-capture-mode= hands a capture its graph.
- =kill-emacs-hook= (Emacs) :: upstream's =org-roam-db--close-all= closes every open database when Emacs exits.
  + Upstream adds this itself only with =org-roam-db-autosync-mode= on, which this chapter leaves off.
- =org-roam-id-find= (Org-roam) :: gets =kittymacs--org-roam-lookup-p= as =:before-while= advice: this chapter's function runs first, upstream's only if it returns non-nil.
  + Upstream adds its lookup to every =org-id-find= with no option to skip it when the graph cannot be used; the advice adds that.
- Org-roam's own commands, such as =M-x org-roam-node-find=, keep working in any buffer with that buffer's graph, because the graph is stored in upstream's own variables.

(defun kittymacs--org-roam-read (scope &optional require-match initial filter)

REQUIRE-MATCH allows only existing nodes.  FILTER, a function of a node,
offers only the nodes for which it returns non-nil."

           (org-roam-node-read initial filter nil require-match

  "Whether SCOPE is a graph other than the personal one."
  (not (file-equal-p (car scope) (default-value 'org-roam-directory))))

  "Show NODE, an existing note of the graph SCOPE, in a buffer given that graph."
  (with-current-buffer (find-file-noselect (org-roam-node-file node))

  "Find a note in this graph; a project graph offers only existing notes."
  (interactive)
  (let* ((scope (kittymacs--org-roam-scope))
         (origin (current-buffer))
         (node (kittymacs--org-roam-read scope (kittymacs--org-roam-project-p scope))))
    (with-current-buffer origin
      (if (org-roam-node-file node)
          (kittymacs--org-roam-open scope node)

(defun kittymacs-org-roam-insert ()
  "Insert an ID link to a note of this graph where the command started.
The active region's text is the prompt's input and the link's description."
  (interactive)
  (let* ((scope (kittymacs--org-roam-scope))
         (origin (point-marker))
         (region (when (use-region-p) (cons (copy-marker (region-beginning))
                                          (copy-marker (region-end)))))
         (text (when region
                 (org-link-display-format
                  (buffer-substring-no-properties (car region) (cdr region)))))
         (node (kittymacs--org-roam-read scope (kittymacs--org-roam-project-p scope) text))
         (description (or text (org-roam-node-formatted node))))
    (unwind-protect
        (with-current-buffer (marker-buffer origin)
          (goto-char origin)
          (if (org-roam-node-id node)
              (progn
                (when region (delete-region (car region) (cdr region)))
                (insert (org-link-make-string (concat "id:" (org-roam-node-id node))
                                              description))
                (run-hook-with-args 'org-roam-post-node-insert-hook
                                    (org-roam-node-id node) description))
            (kittymacs--org-roam-capture-node
             scope node (append (list :finalize 'insert-link
                                      :link-description description)
                                (when region (list :region region))))))
      (set-marker origin nil)
      (deactivate-mark))))

** Find by tag, and the tag index

- =SPC n t= asks for a tag, then offers only the notes carrying it.
  + The tag list is every tag in the graph with its number of notes: the quickest way to see what tags a graph has.
- =SPC n T= writes an Org buffer with a heading per tag and, under it, a link to every note carrying it.
  + A file note is listed under its file tags.
  + A heading note is listed only under the tags its file note lacks, so a page tagged =machine= appears once under =machine=, not once per heading.
  + The buffer is given the graph, so =RET= on a link opens the note.
- Both read the index: after editing notes outside Emacs, =SPC n s= first.

#+begin_src emacs-lisp
(defun kittymacs--org-roam-tag-counts (scope)
  "Return the tags of the graph SCOPE as (TAG . NOTES) pairs, sorted by tag."
  (kittymacs--org-roam-call
   scope (lambda ()
           (mapcar (lambda (row) (cons (car row) (cadr row)))
                   (org-roam-db-query [:select [tag (funcall count *)] :from tags
                                       :group-by tag :order-by [(asc tag)]])))))

(defun kittymacs--org-roam-read-tag (scope)
  "Read a tag of the graph SCOPE; the list says how many notes carry each."
  (let ((counts (or (kittymacs--org-roam-tag-counts scope)
                    (user-error "No tags in %s; SPC n s indexes the graph" (car scope)))))
    (completing-read
     (format "Tag (%s): " (car scope))
     (lambda (string predicate action)
       (if (eq action 'metadata)
           `(metadata
             (annotation-function
              . ,(lambda (tag)
                   (let ((notes (alist-get tag counts nil nil #'equal)))
                     (format "  %d note%s" notes (if (= notes 1) "" "s"))))))
         (complete-with-action action counts string predicate)))
     nil t)))

(defun kittymacs-org-roam-find-by-tag ()
  "Find a note of this graph by choosing one of the graph's tags first."
  (interactive)
  (let* ((scope (kittymacs--org-roam-scope))
         (origin (current-buffer))
         (tag (kittymacs--org-roam-read-tag scope))
         (node (kittymacs--org-roam-read
                scope t nil (lambda (node) (member tag (org-roam-node-tags node))))))
    (with-current-buffer origin
      (kittymacs--org-roam-open scope node))))

(defun kittymacs--org-roam-tagged-notes (scope)
  "Return the tags of the graph SCOPE with the notes listed under each.
The value is a list of (TAG . NOTES), sorted by tag; a note is a list
\(ID TITLE FILE LEVEL), file notes first.  A file note is listed under
its file tags, a heading note only under tags its file note lacks."
  (let ((rows (kittymacs--org-roam-call
               scope (lambda ()
                       (org-roam-db-query
                        [:select [tags:tag nodes:id nodes:title nodes:file nodes:level]
                         :from tags :inner-join nodes :on (= tags:node-id nodes:id)
                         :order-by [(asc tags:tag) (asc nodes:file) (asc nodes:pos)]]))))
        (file-tags (make-hash-table :test #'equal))
        groups)
    (pcase-dolist (`(,tag ,_ ,_ ,file ,level) rows)
      (when (zerop level) (puthash (cons file tag) t file-tags)))
    (pcase-dolist (`(,tag ,id ,title ,file ,level) rows)
      (unless (and (> level 0) (gethash (cons file tag) file-tags))
        (push (list id title file level) (alist-get tag groups nil nil #'equal))))
    (sort (mapcar (lambda (group)
                    ;; File notes first; `sort' is stable, so the rest keep
                    ;; the order of their files and positions.
                    (cons (car group)
                          (sort (nreverse (cdr group))
                                (lambda (a b) (and (zerop (nth 3 a)) (> (nth 3 b) 0))))))
                  groups)
          (lambda (a b) (string< (car a) (car b))))))

(defun kittymacs-org-roam-tag-index ()
  "List this graph's tags in an Org buffer, each with links to its notes."
  (interactive)
  (let* ((scope (kittymacs--org-roam-scope))
         (groups (or (kittymacs--org-roam-tagged-notes scope)
                     (user-error "No tags in %s; SPC n s indexes the graph" (car scope))))
         (root (abbreviate-file-name (car scope)))
         (buffer (get-buffer-create (format "*org-roam tags: %s*" root))))
    (with-current-buffer buffer
      (erase-buffer)
      (org-mode)
      (kittymacs--org-roam-set-scope scope)
      (insert (format "#+title: Tags in %s\n\n" root))
      (pcase-dolist (`(,tag . ,notes) groups)
        (insert (format "* %s (%d)\n" tag (length notes)))
        (pcase-dolist (`(,id ,title ,file ,_) notes)
          (insert "- " (org-link-make-string (concat "id:" id) title)
                  " · " (file-relative-name file (car scope)) "\n")))
      (set-buffer-modified-p nil)
      (goto-char (point-min)))
    (pop-to-buffer buffer)))
