* One graph at a time

=SPC n f= finds a note, =SPC n i= inserts a link to one, =SPC n c= captures
a new one, =SPC n b= shows which notes link to one, and =SPC n s= brings the
index up to date. Each of them works on /one graph/: the graph that the
current buffer belongs to.

A graph is a folder of Org files together with an index of them. Org-roam,
the package underneath, keeps the index in a SQLite database and names the
two halves with two variables: =org-roam-directory= is the folder and
=org-roam-db-location= is the database file. Upstream expects one global
pair. This chapter lets a buffer have its own pair, so your personal notes
and a project's documentation stay separate graphs with separate indexes,
and a search from a project file never turns up your diary.

There are two kinds of graph. The /personal graph/ is
=kittymacs-org-roam-directory=, which defaults to the Org directory of [[file:30-platform.org][the
platform chapter]]. A /project graph/ is a repository whose =.dir-locals.el=
says it is one, as described below. The inbox and agenda of [[file:70-org.org][the Org chapter]]
are not affected: they keep their own files and templates.

Nothing here scans notes or opens a database at startup, and upstream's
=org-roam-db-autosync-mode= stays off, because switching it on rebuilds the
whole index on the spot. The first =SPC n s= in a graph builds its index.
After that, saving a note updates that note's entry, and =SPC n s= is only
needed after changes made outside Emacs: edits, renames and deletions. The
graph commands need an Emacs built with SQLite; without it they say so, and
ordinary Org editing works as before.

* Paths and identity

Every database lives outside its graph, in =org-roam/= under
=kittymacs-cache-dir=. A project checkout therefore never contains a
generated file, and a read-only checkout can still be indexed.

The database's file name is a hash of the graph's /real/ path.
=file-truename= resolves symbolic links, and on a file system that ignores
the case of letters (the default on macOS and Windows) the path is also
lower-cased. Two spellings of one folder, such as =~/notes= and a symbolic
link to it, therefore share one database, while two worktrees of the same
repository are different folders with different databases. An alias that
=file-truename= cannot see through, such as an NTFS junction on Windows or
a bind mount, looks like a different folder and gets a cache of its own.
That costs a second index, not correctness; open the graph through one path
if it matters to you.

=kittymacs--org-roam-root= is that resolution. It runs once, when a buffer's
graph is decided (next section); the paths it returns are then used as they
are, so no SQL query pays for resolving them again.
=kittymacs-org-roam-db-path= is public so you can compute a database path
yourself, for example to open it with the =sqlite3= program.

The last two forms give upstream's variables their global values, which
describe the personal graph, before Org-roam loads. =defvar= does nothing
to a variable that already has a value, so if =private.el= set
=org-roam-directory= itself, that value stays; setting
=kittymacs-org-roam-directory= is the better way, because it also gets
resolved.

;; Defined by the defaults and platform chapters, which init.el loads first.
(defvar kittymacs-cache-dir)
(defvar kittymacs-org-directory)

(defgroup kittymacs-org-roam nil
  "Linked notes, one graph at a time."
  :group 'kittymacs)

(defcustom kittymacs-org-roam-directory kittymacs-org-directory
  "Root of the personal Org-roam graph.
The chapter reads it while it loads, so set it with `setopt' in private.el."
  :type 'directory
  :group 'kittymacs-org-roam)

(defun kittymacs--org-roam-root (directory)
  "Return DIRECTORY as an absolute directory name with links resolved."
  (file-name-as-directory (file-truename (expand-file-name directory))))

(defun kittymacs-org-roam-db-path (root)
  "Return the database file for the graph at ROOT, inside the user cache.
The name is a hash of ROOT's real path, lower-cased on a file system
that ignores case, so every spelling of one directory shares one file."
  (let ((identity (kittymacs--org-roam-root root)))
    (when (file-name-case-insensitive-p identity)
      (setq identity (downcase identity)))
    (expand-file-name (concat (secure-hash 'sha256 identity) ".sqlite")
                      (expand-file-name "org-roam/" kittymacs-cache-dir))))

(defvar org-roam-directory (kittymacs--org-roam-root kittymacs-org-roam-directory))
(defvar org-roam-db-location (kittymacs-org-roam-db-path org-roam-directory))

#+end_src

* Scope: which graph a buffer uses

A buffer's /scope/ is a list of three values: the graph's root, its
database, and the list of regular expressions that keep files out of it
(the next section explains that list). =kittymacs--org-roam-scope= decides
it for the =SPC n= commands, in this order:

1. A graph already set in the buffer, which the variable
   =kittymacs--org-roam-graph= remembers.
2. A graph named by the buffer's own variables: the project flag below, or
   a buffer-local =org-roam-directory=. The database is a buffer-local
   =org-roam-db-location= if there is one, and otherwise the cache path for
   that root.
3. The personal graph.

Before returning it, the function checks what a command needs: SQLite, a
root that exists, and a database outside the root. A command that fails one
of these stops with a message and changes nothing, so it never creates a
graph folder or an empty database for a folder that is not there. The same
check protects =C-u SPC n s=, which deletes the database before rebuilding
it.

** Project graphs

A repository becomes a graph of its own with a =.dir-locals.el= at its
root. EmptyNet ships exactly this one:

#+begin_src emacs-lisp :tangle no
((nil . ((kittymacs-org-roam-project . t)
         (kittymacs-org-roam-excluded-directories . ("secrets" "tools" "web" ".github")))))
#+end_src

=kittymacs-org-roam-project= says "the folder holding this file is a graph
root". Emacs already knows which folder that is: when it applies directory
locals it records them in =dir-local-variables-alist=, and
=dir-locals-find-file= returns the folder whose =.dir-locals.el= it read.
The database is the cache path for that root; add =org-roam-db-location= to
the same file to choose another. =kittymacs-org-roam-excluded-directories=
replaces the default exclusions for this graph only.

Both variables are declared safe for their types, a boolean and a list of
strings, so Emacs applies them without asking, and nothing in the file is
evaluated. An Emacs without kittymacs does not know them: the first time it
opens a file there it asks whether to apply them, and answering =i=
ignores them for good. They do nothing in that Emacs either way.

Emacs reads only the nearest =.dir-locals.el= above a file. A subfolder with
its own =.dir-locals.el= hides the root's, so its files leave the project
graph unless that file repeats the flag, and then the subfolder is a graph
of its own.

A project may instead set =org-roam-directory= and =org-roam-db-location=
directly in its directory locals, which is the arrangement upstream
documents. That keeps working through the second rule above. Emacs asks
before applying those two, because upstream does not declare them safe, and
the directory should be written as its real absolute path, since Org-roam
reads the value in files it opens by itself.

** Setting and restoring a buffer's graph

=kittymacs--org-roam-set-scope= writes a scope into a buffer: it sets the
three upstream variables buffer-locally, so Org-roam's own functions agree
with ours, and in an Org buffer it adds the save hook of the indexing
section.

Buffer-local variables do not last: every major mode starts by clearing
them, and so does reverting a file. =kittymacs--org-roam-restore= puts the
graph back. It runs from =hack-local-variables-hook=, which Emacs runs
after it has applied a file's local and directory-local variables: when a
file is visited, whenever a major mode starts in it, and after a revert. So
it always sees the project flag. For an Org buffer it first decides the
graph afresh: the buffer's own variables, then the personal graph if the
file lies inside it. When neither applies, and for any buffer that is not
Org, it restores the graph that was set before, if there was one. That is
how a note that =SPC n f= opened from a graph stays in that graph, and how
the backlinks panel keeps its graph. A note that was never given a graph
belongs to none, and its saves touch no database.

The same hook runs in the buffers Org-roam opens by itself to read notes
during a sync, because upstream calls =hack-local-variables= there. A
project's notes are therefore read into the project's database even when
the sync was started with Org-roam's own =M-x org-roam-db-sync=.

=kittymacs--org-roam-graph= is /permanent-local/: it survives the clearing,
which a restore needs. Because a file's own variables are asked first, its
value is still replaced when they name a different graph, so editing
=.dir-locals.el= and reverting a note moves the note to the new graph.

#+begin_src emacs-lisp
(defcustom kittymacs-org-roam-project nil
  "Non-nil in a directory's .dir-locals.el to make that directory a graph root."
  :type 'boolean
  :safe #'booleanp
  :group 'kittymacs-org-roam)

(defcustom kittymacs-org-roam-excluded-directories '(".git" ".cache" "cache" "caches")
  "Folder names whose contents are never notes, at any depth of a graph.
A project graph sets its own list in its .dir-locals.el."
  :type '(repeat string)
  :safe #'list-of-strings-p
  :group 'kittymacs-org-roam)

(defvar org-roam-file-exclude-regexp)

(defvar-local kittymacs--org-roam-graph nil
  "This buffer's graph as a list (ROOT DB EXCLUDE), or nil.")
(put 'kittymacs--org-roam-graph 'permanent-local t)

(defun kittymacs--org-roam-project-root ()
  "Return the directory whose .dir-locals.el set `kittymacs-org-roam-project'."
  (when (alist-get 'kittymacs-org-roam-project dir-local-variables-alist)
    (let ((found (dir-locals-find-file (or buffer-file-name default-directory))))
      (if (consp found) (car found) found))))

(defun kittymacs--org-roam-named-graph ()
  "Return the graph that this buffer's own variables name, or nil."
  (when-let* ((directory (or (kittymacs--org-roam-project-root)
                             (and (local-variable-p 'org-roam-directory)
                                  org-roam-directory))))
    (let ((root (kittymacs--org-roam-root directory)))
      (list root
            (if (local-variable-p 'org-roam-db-location)
                (expand-file-name org-roam-db-location)
              (kittymacs-org-roam-db-path root))
            (kittymacs--org-roam-exclusions kittymacs-org-roam-excluded-directories)))))

(defun kittymacs--org-roam-personal-graph ()
  "Return the personal graph, from the global values of its variables."
  (list (kittymacs--org-roam-root (default-value 'org-roam-directory))
        (expand-file-name (default-value 'org-roam-db-location))
        (kittymacs--org-roam-exclusions
         (default-value 'kittymacs-org-roam-excluded-directories))))

(defun kittymacs--org-roam-scope ()
  "Return the graph for a command in this buffer, or explain why there is none."
  (unless (sqlite-available-p)
    (user-error "Org-roam needs an Emacs built with SQLite support"))
  (let ((scope (or kittymacs--org-roam-graph
                   (kittymacs--org-roam-named-graph)
                   (kittymacs--org-roam-personal-graph))))
    (pcase-let ((`(,root ,db) scope))
      (unless (file-directory-p root)
        (user-error "Org-roam graph does not exist: %s" root))
      (when (file-in-directory-p db root)
        (user-error "Org-roam database %s is inside its graph; see kittymacs-org-roam-db-path"
                    db)))
    scope))

(defun kittymacs--org-roam-set-scope (scope)
  "Make SCOPE this buffer's graph, for these commands and for Org-roam's own."
  (pcase-let ((`(,root ,db ,exclude) scope))
    (setq-local kittymacs--org-roam-graph scope
                org-roam-directory root
                org-roam-db-location db
                org-roam-file-exclude-regexp exclude))
  (when (derived-mode-p 'org-mode)
    (add-hook 'after-save-hook #'kittymacs--org-roam-save nil t)))

(defun kittymacs--org-roam-restore ()
  "Give this buffer its graph again after its local variables were cleared."
  (when-let* ((scope (or (and (derived-mode-p 'org-mode)
                              (or (kittymacs--org-roam-named-graph)
                                  (and buffer-file-name
                                       (file-in-directory-p buffer-file-name
                                                            org-roam-directory)
                                       (kittymacs--org-roam-personal-graph))))
                         kittymacs--org-roam-graph)))
    (kittymacs--org-roam-set-scope scope)))

#+end_src

* Membership: which files are notes

Upstream decides whether a file is a note with =org-roam-file-p=: the file
must lie under the root, have an extension from =org-roam-file-extensions=,
and not match =org-roam-file-exclude-regexp=, a regular expression or a list
of them that is tested against the path relative to the root. That last
option is the extension point this chapter uses.

=kittymacs--org-roam-exclusions= turns a list of folder names into one more
regular expression and adds it to upstream's own list, which by default
holds Org's attachment folder. The expression matches a folder name as a
whole path component, at any depth: with ="cache"= it excludes =cache/a.org=
and =notes/cache/b.org= but not =cached.org=. Because each scope carries its
own list and sets it buffer-locally, every graph has its own exclusions,
and the personal graph's list comes from the global value of
=kittymacs-org-roam-excluded-directories=.

The default excludes Git's folder and cache folders, which is what a
personal notes folder usually contains. To change it for the personal graph,
set the option with =setopt= in =private.el=; a project sets its list in its
=.dir-locals.el=.

Upstream finds a graph's files with =find=, =fd= or =rg= when one is
installed, which is much faster than walking the folders in Lisp, and then
filters the result through =org-roam-file-p=, so the exclusions apply however
the files were found. Those tools follow symbolic links, so a link inside a
graph that points outside it brings the file it points to into the graph.
That is your choice to make: a link is the way to include a file on
purpose, and leaving it out is the way to keep a file out.

#+begin_src emacs-lisp
(defun kittymacs--org-roam-exclusions (directories)
  "Return Org-roam's exclusion regexps plus one matching any of DIRECTORIES.
The new regexp matches a whole folder name at any depth of a path that
is relative to the graph root, which is what `org-roam-file-p' tests."
  (append (ensure-list (default-toplevel-value 'org-roam-file-exclude-regexp))
          (and directories
               (list (concat "\\(?:\\`\\|/\\)" (regexp-opt directories) "/")))))

#+end_src

=default-toplevel-value= reads the global value even while a command below
has bound it, so the list never grows by repeating our own expression.

* Indexing: sync, saves and links

=kittymacs--org-roam-call= runs a piece of Org-roam with a scope in effect.
Setting the three upstream variables in the current buffer is not enough,
because Org-roam does part of its work in buffers of its own: it opens a
note that is not already open in a hidden buffer to read it, and fills
temporary buffers for previews. Those buffers see the /global/ values. A
=let= binding changes the global value only where the variable is not
buffer-local, so the function binds the variables twice with =cl-progv=,
which binds a list of variables to a list of values: once from a temporary
buffer, where they are global, and once in the buffer the command started
in.

Upstream also keeps one open database connection per root, in
=org-roam-db--connection=, and looks it up by the root alone. Every buffer of
one graph must therefore agree on its database; two databases for the same
root in one session would quietly share whichever connection opened first.
The scope rules above make them agree: a root always gets the same cache
path unless its own directory locals name another.

=kittymacs--org-roam-save= runs after a note in a graph is saved and updates
that note's entry. Org-roam records the file name it is given, and a sync
records real paths, because it lists files under the resolved root. The
function therefore binds =buffer-file-name= to the real path while it runs,
so a note opened through a symbolic link is recorded under the same name a
sync would use, not a second time under the link's.

=kittymacs-org-roam-sync= brings the database up to date, deleting it first
when given a prefix argument. It then copies every node's ID and file into
Org's own ID index, =org-id-locations=. That index is separate from
Org-roam's and knows nothing about graphs; recording each graph's IDs there
is what lets an =id:= link reach a note in another graph (see below).

** Links across graphs

An =id:= link may point at a note in another graph. Org follows it with
=org-id-find=, and Org-roam places its own lookup in front of that function
with advice, so Org first asks the current graph's database. When the ID is
not there, Org's own index answers, which is why every graph should be synced
once. Opening the note there gives its buffer the destination's graph, by
the rules above. Backlinks stay within a graph: the source graph's database
records the outgoing link, but not the destination note or the other links
to it. IDs must be unique across all your graphs.

When the current graph cannot be used, because Emacs has no SQLite or the
graph's root does not exist, upstream's lookup would fail with an error or
create an empty database for a folder that is not there, and ordinary Org
links would break with it. =kittymacs--org-roam-lookup-p= answers "not here"
in that case, so Org's own index answers alone.

#+begin_src emacs-lisp
(defun kittymacs--org-roam-call (scope function)
  "Call FUNCTION with SCOPE in effect, also in buffers Org-roam opens itself."
  (let ((variables '(org-roam-directory org-roam-db-location org-roam-file-exclude-regexp))
        (origin (current-buffer)))
    (with-temp-buffer
      (cl-progv variables scope
        (with-current-buffer origin
          (cl-progv variables scope
            (funcall function)))))))

(defun kittymacs--org-roam-save ()
  "Update this note's entry in its graph's database, under its real file name."
  (let ((buffer-file-name (file-truename buffer-file-name)))
    (when (and (sqlite-available-p) (org-roam-file-p))
      (kittymacs--org-roam-call kittymacs--org-roam-graph #'org-roam-db-update-file))))

(defun kittymacs-org-roam-sync (&optional force)
  "Bring this graph's database up to date and record its IDs for Org.
With a prefix argument FORCE, delete the database and build it again."
  (interactive "P")
  (kittymacs--org-roam-call
   (kittymacs--org-roam-scope)
   (lambda ()
     (org-roam-db-sync force)
     (dolist (row (org-roam-db-query [:select [id file] :from nodes]))
       (org-id-add-location (car row) (cadr row)))
     (org-id-locations-save))))

(defun kittymacs--org-roam-lookup-p (&rest _)
  "Whether Org-roam can answer an ID lookup in this buffer's graph."
  (and (sqlite-available-p) (file-directory-p org-roam-directory)))

#+end_src

* Capture

=SPC n c= always captures, and =SPC n f= and =SPC n i= capture when you type
a title that is not a note yet. Project graphs do not do the second: their
find and insert offer only existing notes, so a typo in a repository's
documentation never becomes a new file. Before a capture starts, the command
checks that it can write to the root and shows the root it will write into.
Which file inside the graph receives the note is decided by your
=org-roam-capture-templates=, as upstream documents; a template that writes
outside the graph is your choice, like a link. When the file's folder does
not exist yet, Emacs asks before creating it when the capture is saved.

A capture happens in two halves. The first half runs inside the command:
Org opens the target file, inserts the template and shows a capture buffer,
so the command's scope is still in effect. The second half, =C-c C-c=, runs
whenever you finish, from whatever buffer happens to be current, long after
the command has returned. Org saves the target file then, and that save must
update the graph the capture started in.

So the scope is written into the buffers themselves during the first half.
The command binds =kittymacs--org-roam-capture-scope= while it runs. Org
turns on =org-capture-mode= in the capture buffer at the end of that first
half, and its hook =kittymacs--org-roam-capture-mode= sees the binding and
sets the scope in the capture buffer and in the file's buffer behind it,
the capture buffer's /base buffer/. The save when you finish updates that
graph, whichever buffer you were in. Captures started any other way, such
as the inbox capture of the Org chapter, find the variable unbound and are
left alone.

#+begin_src emacs-lisp
(defvar kittymacs--org-roam-capture-scope nil
  "The graph of the command now starting an Org-roam capture, or nil.
Only `kittymacs--org-roam-capture-node' binds it, while Org sets up the
capture; `kittymacs--org-roam-capture-mode' reads it.")

(defun kittymacs--org-roam-capture-mode ()
  "Give a capture started from a SPC n command the graph of that command.
Set it in the capture buffer and in the file buffer behind it, so the
save that finishes the capture updates that graph's database."
  (when kittymacs--org-roam-capture-scope
    (kittymacs--org-roam-set-scope kittymacs--org-roam-capture-scope)
    (with-current-buffer (buffer-base-buffer)
      (kittymacs--org-roam-set-scope kittymacs--org-roam-capture-scope))))

(defun kittymacs--org-roam-capture-node (scope node &optional props)
  "Capture NODE into the graph SCOPE, passing PROPS to Org-roam."
  (unless (file-writable-p (car scope))
    (user-error "Org-roam capture root is read-only: %s" (car scope)))
  (message "Org-roam capture destination: %s" (car scope))
  (kittymacs--org-roam-call
   scope (lambda ()
           (let ((kittymacs--org-roam-capture-scope scope))
             (org-roam-capture- :node node :props props)))))

#+end_src

* The panel and the commands

The commands read a note with upstream's =org-roam-node-read=, inside the
scope, with the graph's root in the prompt. Completion may switch buffers
while you choose, so each command remembers where it started, the buffer or
for =SPC n i= the exact position, and goes back there before acting.

=SPC n f= opens the note in a buffer that has been given the command's
graph, then lets =org-roam-node-open= show it, which follows the frame
policy of [[file:45-frames.org][the frames chapter]]. =SPC n i= inserts an =id:= link at the
remembered position and replaces the active region, if there is one, just
as upstream's insert does. It also runs =org-roam-post-node-insert-hook=.

=SPC n b= shows the backlinks panel in a side window of the current frame,
one panel per graph. Upstream draws the panel's contents again on every
refresh and starts by switching its major mode on again, which clears every
buffer-local variable. The panel's graph survives in the permanent
=kittymacs--org-roam-graph=, and =kittymacs--org-roam-restore= on
=org-roam-mode-hook= puts the upstream variables back before the sections
query the database. Upstream's own permanent =org-roam-buffer-current-directory=
and =org-roam-buffer-current-node= say which note the panel is about.

** What this chapter asks of Org-roam

The =use-package= block at the end is the whole connection to Org-roam
beyond ordinary function calls. It adds four hooks and one piece of advice:

- =hack-local-variables-hook= (Emacs) restores a buffer's graph after its
  local variables are applied, in notes you open and in the buffers
  Org-roam opens by itself.
- =org-roam-mode-hook= (Org-roam) restores the panel's graph each time the
  panel is redrawn.
- =org-capture-mode-hook= (Org) hands a capture its graph.
- =kill-emacs-hook= closes every open database when Emacs exits, with
  upstream's =org-roam-db--close-all=. Upstream adds this itself only when
  =org-roam-db-autosync-mode= is switched on, and this chapter leaves that
  mode off.
- =org-roam-id-find= gets =kittymacs--org-roam-lookup-p= as =:before-while=
  advice, which runs our function first and upstream's only if ours returns
  non-nil. Upstream adds its lookup to every =org-id-find= and offers no
  option to skip it when the graph cannot be used, which is what the advice
  adds.

Org-roam's own commands, such as =M-x org-roam-node-find=, keep working in
any buffer and use that buffer's graph, because the graph is stored in
upstream's own variables.

** Meow in the panel

The panel is a special buffer, so it starts in Motion state, and =SPC m= in
it offers refresh, sync and find.

#+begin_src emacs-lisp
(defun kittymacs--org-roam-read (scope &optional require-match)
  "Read a node of the graph SCOPE; REQUIRE-MATCH allows only existing ones."
  (kittymacs--org-roam-call
   scope (lambda ()
           (org-roam-node-read nil nil nil require-match
                               (format "Node (%s): " (car scope))))))

(defun kittymacs--org-roam-project-p (scope)
  "Whether SCOPE is a graph other than the personal one."
  (not (file-equal-p (car scope) (default-value 'org-roam-directory))))

(defun kittymacs-org-roam-find ()
  "Find a note in this graph; a project graph offers only existing notes."
  (interactive)
  (let* ((scope (kittymacs--org-roam-scope))
         (origin (current-buffer))
         (node (kittymacs--org-roam-read scope (kittymacs--org-roam-project-p scope))))
    (with-current-buffer origin
      (if (org-roam-node-file node)
          (progn
            (with-current-buffer (find-file-noselect (org-roam-node-file node))
              (kittymacs--org-roam-set-scope scope))
            (org-roam-node-open node nil t))
        (kittymacs--org-roam-capture-node scope node '(:finalize find-file))))))

(defun kittymacs-org-roam-insert ()
  "Insert an ID link to a note of this graph where the command started."
  (interactive)
  (let* ((scope (kittymacs--org-roam-scope))
         (origin (point-marker))
         (region (when (use-region-p) (cons (copy-marker (region-beginning))
                                          (copy-marker (region-end)))))
         (node (kittymacs--org-roam-read scope (kittymacs--org-roam-project-p scope))))
    (unwind-protect
        (with-current-buffer (marker-buffer origin)
          (goto-char origin)
          (if (org-roam-node-id node)
              (progn
                (when region (delete-region (car region) (cdr region)))
                (insert (org-link-make-string (concat "id:" (org-roam-node-id node))
                                              (org-roam-node-title node)))
                (run-hook-with-args 'org-roam-post-node-insert-hook
                                    (org-roam-node-id node) (org-roam-node-title node)))
            (kittymacs--org-roam-capture-node
             scope node (append (list :finalize 'insert-link
                                      :link-description (org-roam-node-title node))
                                (when region (list :region region))))))
      (set-marker origin nil)
      (deactivate-mark))))

(defun kittymacs-org-roam-capture ()
  "Capture a note into this graph, showing where it will go."
  (interactive)
  (let* ((scope (kittymacs--org-roam-scope))
         (origin (current-buffer))
         (node (kittymacs--org-roam-read scope)))
    (with-current-buffer origin
      (kittymacs--org-roam-capture-node scope node '(:finalize find-file)))))

(defun kittymacs-org-roam-backlinks ()
  "Show the notes of this graph that link to a note, in a side panel."
  (interactive)
  (let* ((scope (kittymacs--org-roam-scope))
         (node (or (and (derived-mode-p 'org-mode) (org-roam-node-at-point))
                   (kittymacs--org-roam-read scope t)))
         (buffer (get-buffer-create
                  (format "*org-roam: %s*" (substring (secure-hash 'sha256 (car scope)) 0 12)))))
    (with-current-buffer buffer
      (setq-local kittymacs--org-roam-graph scope
                  org-roam-buffer-current-directory (car scope)
                  org-roam-buffer-current-node node)
      (org-roam-buffer-render-contents))
    (display-buffer-in-side-window buffer '((side . right) (window-width . 0.33)))))

* Try it

- =SPC n s= in any buffer builds the personal graph's index; =SPC n f=
  then offers its notes, and typing a new title captures one.
- Open a file in a repository with the project =.dir-locals.el= above and
  press =SPC n f=: the prompt shows the repository's root, and only its
  notes are offered.
- In a note, =SPC n b= opens the backlinks panel; =SPC m g= in the panel
  refreshes it.
- =C-u SPC n s= rebuilds a graph's index from nothing.
