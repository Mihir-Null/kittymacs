- Emacs is self-documenting; this chapter makes that documentation nicer to read and easier to reach.
  + =C-h k= then a key says what it does; =C-h f= and =C-h v= describe a function or variable.
  + Helpful makes those pages richer, Info manuals get colour, and Casual gives the built-in tools menus.
- Leans on [[id:e5942eb0-4389-447d-9317-d9178adcaaae][the leader]] for its =SPC m= menus; the leader's help menu, =SPC h=, is in [[id:53ad53ed-155f-47dc-973d-7be18de2893c][the keys chapter]]; [[id:42b02bb4-ea68-4981-b427-35705bf162f4][the completion chapter]] supplies =C-h B= and the manual search.
- Distilled from Lambda-Emacs by Colin McLear (=lem-setup-help=).

* Help windows and help at point

- A help window takes focus when it opens.
- Help at point appears in the echo area after 0.1 s of idle, for Flymake diagnostics.
- Emacs does not ask for confirmation before visiting a file or buffer that does not exist yet.

#+begin_src emacs-lisp
;;; kittymacs-help.el --- Help, Info and menus -*- lexical-binding: t; -*-
;; Generated from literate/62-help.org; edit the Org source, then tangle.

;; Distilled from Lambda-Emacs by Colin McLear (GPL-3.0-or-later).

;;; Code:

(require 'kittymacs-defaults)
(require 'kittymacs-leader)

(setopt confirm-nonexistent-file-or-buffer nil
        help-window-select t
        help-at-pt-timer-delay 0.1
        help-at-pt-display-when-idle '(flymake-diagnostic))

#+end_src

* Richer help pages: Helpful

- Helpful takes over the standard describe commands through =remap=, so the usual =C-h= keys keep working and show more: the source, examples and references.
- =elisp-demos= injects worked examples into those pages.
- =info-colors= makes manuals readable.
- Two extra keys: =C-h C-l= finds a library's source, =C-h C-c= shows its commentary.

#+begin_src emacs-lisp
(use-package helpful
  :ensure t
  :bind (([remap display-local-help] . helpful-at-point)
         ([remap describe-function] . helpful-callable)
         ([remap describe-variable] . helpful-variable)
         ([remap describe-symbol] . helpful-symbol)
         ([remap describe-key] . helpful-key)
         ([remap describe-command] . helpful-command)
         ("C-h C-l" . find-library)
         ("C-h C-c" . finder-commentary)))

(use-package elisp-demos
  :ensure t
  :after helpful
  :config
  (advice-add 'helpful-update :after #'elisp-demos-advice-helpful-update))

(use-package info-colors
  :ensure t
  :hook (Info-selection . info-colors-fontify-node))

#+end_src

* Transient menus

- Magit, Casual and a few other packages draw their menus with Transient.
- Its levels, values and history files go under the cache.
- The menu opens in a dedicated side window at the top, so it never replaces the buffer you are looking at; =other-window= skips it.
- Key conflicts are reported, and the menu is always fixed-pitch so its columns line up.

#+begin_src emacs-lisp
(use-package transient
  :ensure nil
  :defer t
  :custom
  (transient-levels-file (expand-file-name "transient/levels.el" kittymacs-cache-dir))
  (transient-values-file (expand-file-name "transient/values.el" kittymacs-cache-dir))
  (transient-history-file (expand-file-name "transient/history.el" kittymacs-cache-dir))
  (transient-detect-key-conflicts t)
  (transient-force-fixed-pitch t)
  (transient-display-buffer-action '(display-buffer-in-side-window
                                     (side . top)
                                     (dedicated . t)
                                     (inhibit-same-window . t)
                                     (window-parameters (no-other-window . t)))))

#+end_src

* See what you press: keycast

- While the grammar is new, =SPC t k= shows each key you press and the command it ran in the header line.
- =SPC t K= keeps a log buffer instead.
- Typing collapses to "Typing..." and mouse movement is dropped, so the display stays readable.

#+begin_src emacs-lisp
(use-package keycast
  :ensure t
  :commands (keycast-header-line-mode keycast-log-mode keycast-tab-bar-mode)
  :config
  (dolist (input '(self-insert-command org-self-insert-command))
    (add-to-list 'keycast-substitute-alist `(,input "." "Typing...")))
  (dolist (event '(mouse-event-p mouse-movement-p mwheel-scroll))
    (add-to-list 'keycast-substitute-alist `(,event nil))))

#+end_src

* Menus for the built-ins: Casual

- Casual gives Emacs's own tools a Transient menu of everything they can do.
- Each menu is on =?= in that mode's =SPC m= menu, on =C-o= in the mode's own map (Casual's convention), or on both:

| Where          | Modes                                                      |
|----------------+------------------------------------------------------------|
| both           | Dired, Info, ibuffer, compilation                          |
| =C-o= only     | calc, isearch, bookmarks, the regexp builder               |
| =SPC m ?= only | the agenda, Eshell, and the Help, Org and Emacs Lisp modes |

- The =SPC m ?= entries for ibuffer and compilation are here; Info's and Help's are in [[*Meow in help buffers]]; the rest live with their packages.
- =SPC c m= opens the general editing menu from any buffer.

#+begin_src emacs-lisp
(use-package casual
  :ensure t
  :defer t)

(with-eval-after-load 'calc (keymap-set calc-mode-map "C-o" #'casual-calc-tmenu))
(with-eval-after-load 'isearch (keymap-set isearch-mode-map "C-o" #'casual-isearch-tmenu))
(with-eval-after-load 're-builder (keymap-set reb-mode-map "C-o" #'casual-re-builder-tmenu))
(with-eval-after-load 'bookmark (keymap-set bookmark-bmenu-mode-map "C-o" #'casual-bookmarks-tmenu))
(with-eval-after-load 'ibuffer (keymap-set ibuffer-mode-map "C-o" #'casual-ibuffer-tmenu))
(with-eval-after-load 'dired (keymap-set dired-mode-map "C-o" #'casual-dired-tmenu))
(with-eval-after-load 'info (keymap-set Info-mode-map "C-o" #'casual-info-tmenu))
(with-eval-after-load 'compile (keymap-set compilation-mode-map "C-o" #'casual-compile-tmenu))

(kittymacs-define-localleader 'ibuffer-mode
  "?" (cons "menu" #'casual-ibuffer-tmenu))

(kittymacs-define-localleader 'compilation-mode
  "?" (cons "menu" #'casual-compile-tmenu))

#+end_src

* Meow in help buffers :meow:
:PROPERTIES:
:ID: e455cddf-3cd2-47b3-8e0a-68f5f34d67cd
:END:

- Help, Helpful and Info buffers start in Motion state: their own keys work, plus =j=/=k= and the leader.
- Their =SPC m= menus label the navigation keys those modes already have, so =SPC m= in an Info buffer shows how to move around the manual.

| =SPC m= | Info          | Help        | Helpful            |
|---------+---------------+-------------+--------------------|
| =n=     | next node     |             |                    |
| =p=     | previous node |             |                    |
| =u=     | up            |             | update             |
| =t=     | top           |             |                    |
| =d=     | directory     |             |                    |
| =g=     | go to node    |             |                    |
| =i=     | index         | Info        |                    |
| =s=     | search        | source      | source (reference) |
| =m=     | menu          |             |                    |
| =l=     | back          | back        |                    |
| =r=     | forward       | forward     |                    |
| =?=     | Casual menu   | Casual menu |                    |

- Helpful's menu is defined once Helpful loads.

#+begin_src emacs-lisp
(kittymacs-define-localleader 'Info-mode
  "n" (cons "next node" #'Info-next)
  "p" (cons "previous node" #'Info-prev)
  "u" (cons "up" #'Info-up)
  "t" (cons "top" #'Info-top-node)
  "d" (cons "directory" #'Info-directory)
  "g" (cons "go to node" #'Info-goto-node)
  "i" (cons "index" #'Info-index)
  "s" (cons "search" #'Info-search)
  "m" (cons "menu" #'Info-menu)
  "l" (cons "back" #'Info-history-back)
  "r" (cons "forward" #'Info-history-forward)
  "?" (cons "menu" #'casual-info-tmenu))

(kittymacs-define-localleader 'help-mode
  "l" (cons "back" #'help-go-back)
  "r" (cons "forward" #'help-go-forward)
  "s" (cons "source" #'help-view-source)
  "i" (cons "info" #'help-goto-info)
  "?" (cons "menu" #'casual-help-tmenu))

(with-eval-after-load 'helpful
  (kittymacs-define-localleader 'helpful-mode
    "u" (cons "update" #'helpful-update)
    "s" (cons "source" #'helpful-visit-reference)))

(provide 'kittymacs-help)
;;; kittymacs-help.el ends here
#+end_src

* Check

- =C-h k SPC f f=: Helpful describes =find-file= and names the key you pressed.
- =C-h f mapcar=: the page includes a worked example from =elisp-demos=.
- =C-h B= in any buffer: every key that works right now, searchable.
- =C-h i= opens the manuals, in colour; =SPC m= there shows how to move.
- =SPC t k=, then type: the header line shows each key and its command.
- In Dired, =C-o= or =SPC m ?=: Casual's menu opens in a window at the top.
- =just test-packages=: the startup verifier replays a real startup with the installed packages and fails on any warning.
