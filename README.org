- A user-friendly, batteries-included, opinionated Emacs configuration built around [[https://github.com/meow-edit/meow][Meow]]'s grammar: select, extend, act, with visual hints and tooltips.
- It is (meant to be) for Meow what Doom and evil-collection are for Evil:
  + a real =SPC= leader instead of Meow's keypad, which stays as an option;
  + a labelled menu for every major mode under =SPC m=;
  + integrations for the most popular packages;
  + everything discoverable through which-key and =C-h=.
- New editing surfaces are OS windows, so your window manager arranges them.
- The whole configuration is a literate Org-roam wiki (thank you, Donald Knuth): every chapter in [[file:literate/index.org][literate/]] explains one part of the editor, shows the Lisp that configures it, and says why.

* Install

- Needs GNU Emacs 30.1 or later (developed on 31.1).
- Clone into your init directory, or point Emacs at the clone:

#+begin_src sh
git clone https://github.com/Mihir-Null/kittymacs.git ~/.emacs.d
emacs --init-directory=/path/to/kittymacs     # or this, anywhere
#+end_src

- The first start installs the Lisp packages it needs into =var/elpa/=.
  + The terminal, [[https://github.com/dakra/ghostel][ghostel]], downloads its small native module the first time you open a terminal, not at startup.
- Emacs verifies GNU ELPA's signed index with =gpg=; without a native =gpg= the check is skipped.
  + Linux: usually present. macOS: =brew install gnupg=. Windows: [[https://gpg4win.org/][Gpg4win]], which the startup file puts first, because the =gpg= Git for Windows ships cannot verify anything for Emacs.
- Yours to install; the configuration checks for each and degrades quietly without it:
  + language servers, =ripgrep=, =fd=, Git;
  + a spell checker (=hunspell=; on Windows most simply from MSYS2);
  + =python3=, which Treemacs uses to colour directories by Git status;
  + [[https://www.nerdfonts.com/][Symbols Nerd Font Mono]] for icons; the editing font is Google Sans Code if present, else the platform default.
- On macOS, [[file:literate/90-nix.org][the Nix flake]] installs Emacs and all of them in one =darwin-rebuild=; Homebrew works too. On Windows, MSYS2 or WSL is the easiest source.

* Where things are

| Path                        | Holds                                                                  |
|-----------------------------+------------------------------------------------------------------------|
| =early-init.el=, =init.el=   | the only files Emacs reads on its own; generated                       |
| =literate/=                 | the chapters: edit these                                               |
| =lisp/=                     | generated modules (=kittymacs-*.el=), cheat sheet, themes, =private.el= |
| =flake.nix=, =nix/=          | generated: nix-darwin and Home Manager modules, dev shell, example hosts |
| =tools/tangle.el=           | the builder                                                            |
| =justfile=                  | the recipes: tangle, check, test, update                               |
| =tests/=                    | the test suites and the startup verifier                               |
| =var/=                      | packages, caches, =custom.el=; ignored by Git                          |

- Startup is a flat, ordered list of =require=​s in =init.el=, one per chapter.
- Packages are declared where they are used, with =use-package … :ensure t=.
- Machine-specific settings go in =lisp/private.el= (=SPC C p= creates it from the example); it is loaded once, early, and ignored by Git.

* Make it your own

1. Edit a chapter: prose and code block together.
2. Tangle and check:

#+begin_src sh
just tangle      # chapters -> early-init.el, init.el, lisp/, flake.nix, nix/
just check       # tangle-check, doc-test, test: needs only Emacs
#+end_src

3. Restart Emacs, and commit the chapter with its generated file.

- Inside Emacs, =SPC C t= tangles and =SPC C k= checks, each in a clean Emacs.
- Startup never tangles, so a clone works without a build step.
- [[file:literate/80-maintenance.org][The maintenance chapter]] explains the loop, the builder and every recipe; [[file:literate/conventions.org][the conventions]] say how a chapter is written; [[file:ARCHITECTURE.md][ARCHITECTURE.md]] records the design and its decisions.

* Verify

| Recipe               | Needs              | Checks                                                                   |
|----------------------+--------------------+--------------------------------------------------------------------------|
| =just check=         | Emacs              | chapters match generated files; pages follow the conventions; builder, platform and Tree-sitter tests |
| =just install=       | Emacs, network     | a batch start that installs the packages into =var/elpa=                 |
| =just compile=       | installed packages | every module byte-compiles                                               |
| =just test-packages= | installed packages | the leader and Org-roam tests, and the startup verifier                  |
| =just frames-test=   | a display          | frame policy, in a graphical Emacs                                       |
| =just nix-check=     | Nix                | the generated Nix lints, the flake and both example hosts evaluate       |

- The platform tests bind =system-type= to each operating system in turn, so the macOS, Windows, Linux and Android branches all run on any machine.
- The verifier copies the configuration to a temporary directory, forbids package installation, starts it in the order of a real startup and fails on any warning.
  + It checks that =private.el= and =custom.el= overrides survive, every module loads, every =SPC= key runs a command, the dashboard buttons and theme toggle work, and every =SPC= row of the cheat sheet matches the live keymap.
- [[file:.github/workflows/ci.yml][GitHub Actions]] runs all but the frame tests on every push: Emacs 30.1 and 31.1 on Linux, informational macOS and Windows runs, and the Nix job; a weekly run reinstalls without the package cache to catch upstream breakage.
- =nix develop= gives a shell with Emacs, =just= and the Nix linters.

* Windows notes :windows:
:PROPERTIES:
:ID: d260f0d9-a331-42e1-bf09-698642e80960
:END:

- With =HOME= unset, Windows Emacs resolves =~= to =AppData/Roaming=, so a =.emacs.d= in your profile folder is not found.
  + Point it at the clone with a directory junction from =AppData/Roaming/.emacs.d=, or use =--init-directory=.
  + Never recursively delete a junction or its target.
- PowerShell is the default shell; =SPC o m= opens an MSYS2 UCRT64 shell when MSYS2 is at =C:/msys64/= (else set =kittymacs-msys2-root=).
- The terminal talks to ConPTY directly; no POSIX helper is needed.

* macOS notes :macos:
:PROPERTIES:
:ID: 913ae2ad-ef0c-4be6-add8-987fcae2898e
:END:

- Emacs from the Dock has no shell =PATH=: the startup file puts the Nix profiles and Homebrew on =exec-path=, and the shells chapter imports your login environment.
- Option is Meta, Command is Super: =⌘C=, =⌘V=, =⌘S=, =⌘Z=, =⌘⇧Z= do what you expect; the right Option still types accented characters. =kittymacs-macos-modifiers= changes them.
- =⌘Q= closes the frame while others remain, and quits from the last one.
- Deleting moves to the Trash, through =trash= when installed, so Finder's Put Back works.
- The title bar follows the theme; =SPC f o= reveals the file in Finder; Dired uses GNU =ls= as =gls= when installed.
- The policy is one section of [[file:literate/30-platform.org][the platform chapter]]; nix-darwin is in [[file:literate/90-nix.org][the Nix chapter]].

* Android notes :android:
:PROPERTIES:
:ID: 484c6ab3-dbaa-405c-b73f-fc5f9dc0ac80
:END:

- Two ways, alternatives rather than layers:

| | The Android port (=org.gnu.emacs=) | nix-on-droid |
|-+------------------------------------+--------------|
| =system-type= | =android=: its own branches apply | =gnu/linux=: an ordinary Linux Emacs in a PRoot |
| External programs | from [[https://termux.dev][Termux]], built with a matching =sharedUserId= | from Nix, inside the PRoot |
| Terminal | Eshell; ghostel's module cannot load | ghostel |
| Graphical | natively | through [[https://github.com/termux/termux-x11][Termux:X11]] |
| Cost | no terminal; tools need paired Termux | PRoot overhead |

- On the port:
  + the shell is =/system/bin/sh=, Dired lists with =ls-lisp=, and =frames-only-mode= is off, since a frame there is a task-switcher entry (=kittymacs-frames-only= brings it back on a tablet);
  + Termux is discovered, not assumed: without it, everything needing an external program switches itself off and Emacs still starts (=kittymacs-termux-root= moves the search);
  + with a keyboard, =Alt= is Meta and =C-SPC= reaches Emacs, so the leader works;
  + on-screen keyboards edit the buffer directly ("text conversion"), which suits Insert state only, so conversion follows Meow's state (=kittymacs-android-modal-text-conversion=);
  + the volume keys quit without a keyboard (=kittymacs-android-volume-keys= gives them back).
- The two cannot be combined: Nix store paths exist only inside the PRoot, and the apps are different users. [[file:literate/90-nix.org][The Nix chapter]] explains.

* Linked notes

- =SPC n=: find (=f=), insert (=i=), capture (=c=), backlinks (=b=), sync (=s=), find by tag (=t=), tag index (=T=); each works on the current buffer's graph.
- Typing =#decision= at the find prompt keeps only notes tagged =decision=.
- The personal graph defaults to the Org directory; a repository becomes a graph of its own with a =.dir-locals.el= at its root, as this one does:

#+begin_src emacs-lisp
((nil . ((kittymacs-org-roam-project . t)
         (kittymacs-org-roam-excluded-directories . ("var" "tests" "tools" "lisp" ".github")))))
#+end_src

- Each graph's index is a SQLite database in the user cache, outside the graph, so Emacs needs SQLite.
- Sync once per graph; startup never scans notes, and saving a note updates its entry; =C-u SPC n s= rebuilds from nothing.
- [[file:literate/71-org-roam.org][The Org-roam chapter]] explains how a buffer's graph is chosen, exclusions and capture.
