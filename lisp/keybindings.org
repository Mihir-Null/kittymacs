#+TITLE: kittymacs keys and commands
#+OPTIONS: toc:2 num:nil
#+STARTUP: showall

This is the offline cheat sheet. Everything here is a real key binding, so
=C-h k= followed by the key explains it, =SPC /= lists the leader for the
current buffer, and which-key shows the next keys after a short pause.
The startup check verifies every =SPC= row below against the live keymap.

* The three things to learn first

1. =SPC SPC= runs any command by name. Type a few letters of what you want.
2. =SPC= then a letter opens a group; wait for which-key, or press =C-h=.
3. =ESC= gets you back to Normal state; =i= starts typing again.

* Meow in one minute

Meow is *select, then act*. In Normal state:

| Key   | Selects                                           |
|-------+---------------------------------------------------|
| =w= / =W= | word / symbol                                     |
| =x=     | line                                              |
| =o=     | block (paragraph, or what the mode calls a block) |
| =,= / =.= | inside / around a thing: =(= =[= ={= ="= =w= =l=              |
| =f= / =t= | to a character                                    |
| =v=     | visit: search and select                          |
| =e= / =b= | extend by word forward / back                     |
| =0=–=9= | one of the numbered hints Meow shows              |

| Key   | Acts on the selection            |
|-------+----------------------------------|
| =d= / =s= | delete / kill (cut)              |
| =c=     | change: delete and start typing  |
| =y= / =p= | copy / paste                     |
| =r=     | replace with the clipboard       |
| =u= / =U= | undo / undo inside the selection |
| =i= / =a= | type before / after              |
| =A= / =I= | open a line below / above        |

=M-x meow-tutor= teaches the rest interactively.

* States

| Mode line | State  | Where                                                                       |
|-----------+--------+-----------------------------------------------------------------------------|
| =N=         | Normal | text buffers; keys select and act                                           |
| =I=         | Insert | typing; =ESC= leaves                                                          |
| =M=         | Motion | Dired, Magit, Help, Info, the agenda: the mode's own keys, plus =j= =k= and =SPC= |
| =B=         | Beacon | multiple cursors; see the tutor                                             |

Shells and terminals start in Insert. =C-c C-SPC= opens the leader from Insert
state. In a terminal, =ESC= freezes the output so the grammar works on it and
=i= thaws it; while a full-screen program such as =vim= or =htop= is running,
=ESC= goes to that program instead, and =SPC m ESC= changes its mind.

* The localleader: SPC m

=SPC m= is different in every major mode. Examples:

| Mode         | SPC m = then | Does                                 |
|--------------+--------------+--------------------------------------|
| any code     | =c= / =r=        | compile / recompile                  |
| any code     | =e=            | choose a problem to jump to          |
| Emacs Lisp   | =e= / =d= / =b=    | eval last sexp / defun / buffer      |
| Org          | =t= / =s= / =d=    | todo state / schedule / deadline     |
| Org          | =a= / =c=        | agenda / capture                     |
| Dired        | =c= / =r= / =d=    | copy / rename / delete               |
| Dired        | =y= / =p=        | copy to clipboard / paste here       |
| Magit        | =s= / =u= / =c=    | stage / unstage / commit             |
| Terminal     | =c= / =i=        | freeze and copy / type again         |
| Terminal     | =h=            | the shell's own history              |
| Treemacs     | =f= / =d= / =r=    | new file / new directory / rename    |
| Eshell       | =h=            | search history                       |
| Info         | =i= / =s=        | index / search                       |
| any of these | =?=            | a menu of everything the mode can do |
#+TBLFM: $2=SPC m= then
